# NOIP 普及组 / CSP-J 复赛历年真题汇总 (1995–2025)

## 四、 考察频次与重点知识点分布统计

根据历年试题分析，NOIP普及组/CSP-J复赛考察的内容可总结为以下模块：

1. **基础模拟与语法（T1/T2）：**
   * 数组、字符串处理、结构体多关键字排序。
   * 基础数学逻辑（向上取整、GCD/LCM、质数判定、二进制拆分）。
2. **数据结构（T2/T3）：**
   * 栈与队列（表达式求值、单调栈/单调队列）。
   * 哈希表、二叉树遍历与构建。
   * 优先队列（堆）。
3. **算法思想（T2/T3/T4）：**
   * **贪心策略**：滑动窗口、区间合并、双指针。
   * **搜索算法**：DFS 剪枝、BFS 广度优先搜索、记忆化搜索。
   * **动态规划 (DP)**：0/1背包、完全背包、LIS (最长上升子序列)、网格图 DP、区间 DP。
   * **图论**：最短路 (Dijkstra)、拓扑排序、同余/奇偶分层图。
