# CSP-J 字符串处理与大模拟完全指南

## 1. 字符串读入的坑
在 C++ 中，混用 `cin` 和 `getline` 非常容易出错，因为 `cin` 会在输入流中留下换行符 `\n`，导致 `getline` 读入空串。
**解决方案**：
```cpp
int n;
std::cin >> n;
std::cin.ignore(); // 丢弃换行符
// 或者 getchar();
std::string s;
std::getline(std::cin, s);
```

## 2. 大模拟 (Simulation)
**核心要义**：按题意行事，不涉及复杂算法，考查代码实现能力、边界处理及模块化。

### 2.1 应对策略
1. **纸上谈兵**：先在草稿纸上画出流程图，枚举所有边界条件。
2. **模块化设计 (封装)**：将独立功能封装为函数，主函数保持逻辑清晰。千万不要写几百行的 `main`。
3. **断言与日志**：在复杂逻辑分支中使用 `#include <cassert>` 进行防御性编程。
4. **数组与常量**：使用常量数组简化方向移动判断。

