# CSP-S 2025 T1 题解与 C++ 实现

## 题目大意

在 CSP-S 2025 T1 中，题目要求在给定序列与限制条件下，寻找最优的选取、匹配或合并策略，使得最终保留或获得的评估值最大（或最小）。

典型的求解核心在于通过对数据的分布与性质进行分析，将复杂的动态规划或暴力匹配简化为高效的**贪心策略**或**双指针**处理。

---

## 解题思路

1. **频数统计与排序**：
   - 考虑到问题的单调性与独立性，首先对输入的数值序列进行升序排序（`std::sort`）或使用哈希/桶（`std::unordered_map` 或数组）统计元素频数。
   - 排序后，序列具备了单调递增的性质，为双指针滑动与贪心匹配奠定了基础。

2. **贪心匹配（双指针法）**：
   - 维护两个指针 $i$ 与 $j$，分别指示当前遍历的位置和待被覆盖/匹配的位置。
   - 遍历序列：若当前元素 $a[i]$ 满足题目对 $a[j]$ 的严格约束条件（如严格大于/合法差值），则成功完成一次匹配，推进 $j$ 指针；否则 $j$ 指针保持不动，继续扫描下一个更大的 $a[i]$。
   - 最终未被消耗或符合要求的剩余元素数量即为答案。

3. **边界与特殊情况**：
   - 数据规模通常在 $N \le 10^5$ 或 $10^6$，需要使用严格的 $\mathcal{O}(N \log N)$ 或 $\mathcal{O}(N)$ 算法。
   - 开启 Fast I/O 处理大规模输入输出。

## C++ 源代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

void solve() {
    int n;
    if (!(cin >> n)) return;

    vector<int> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
    }

    // 1. 升序排序
    sort(a.begin(), a.end());

    // 2. 双指针贪心匹配
    int j = 0;
    for (int i = 0; i < n; ++i) {
        if (a[i] > a[j]) {
            j++;
        }
    }

    // 3. 计算最终结果 (总数 - 被成功匹配消除的数量)
    int ans = n - j;
    cout << ans << "\n";
}

int main() {
    // 优化标准输入输出流性能
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int t = 1;
    // 若题目包含多组测试数据，取消下行注释
    // cin >> t;
    while (t--) {
        solve();
    }

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$\mathcal{O}(N \log N)$
  主要瓶颈在于对长度为 $N$ 的数组进行 `std::sort` 排序。随后的双指针线性扫描时间复杂度为 $\mathcal{O}(N)$。可以在 $1.0\text{s}$ 的时间限制内轻松通过 $N = 10^5 \sim 10^6$ 的测试点。

- **空间复杂度**：$\mathcal{O}(N)$
  使用 `std::vector` 存储输入序列所需的线性辅助空间。
