# CSP-J 2024 T4 接龙 (chain) C++ 题解

## 题目概述

小 A 和小 B 等 $n$ 位同学在玩接龙游戏。共有 $n$ 个词条，第 $i$ 个词条包含 $l_i$ 个单词。
游戏共进行 $r$ 轮：
1. 第 1 轮必须由拿着包含数字 `1` 词条的人开头，且选择的连续子序列长度介于 $2$ 到 $k$ 之间。
2. 第 $r$ 轮接龙的起始数字必须等于第 $r-1$ 轮接龙的结尾数字。
3. 接龙时不能连续两轮使用同一个人的词条。

给出 $q$ 组询问 $(r_j, c_j)$，判断是否能在第 $r_j$ 轮接龙结束时，最后一个数字恰好为 $c_j$。

---

## 解题思路（动态规划 / 划窗优化）

我们可以定义 DP 状态：
- $dp[r][v]$ 表示在第 $r$ 轮接龙结束时，数字 $v$ 是否可达，以及到达 $v$ 的词条提供者情况。
  - $dp[r][v] = 0$：表示第 $r$ 轮无法以数字 $v$ 结尾。
  - $dp[r][v] = i$ ($i > 0$)：表示第 $r$ 轮可以以数字 $v$ 结尾，且**只能**由第 $i$ 个人的词条接出来。
  - $dp[r][v] = -1$：表示第 $r$ 轮可以以数字 $v$ 结尾，且可以由**至少两个不同的人**的词条接出来。

### 状态转移

对于第 $r$ 轮，遍历每个人 $i$ 的词条 $S_i$：
- 若位置 $j$ 的数字 $S_i[j]$ 能够作为本轮接龙的起点，需要满足第 $r-1$ 轮中数字 $S_i[j]$ 可达，且上一轮**不是由第 $i$ 个人接出的**（即 $dp[r-1][S_i[j]] == -1$ 或 $dp[r-1][S_i[j]] 
eq i$ 且 $>0$）。
- 连续子序列长度在 $[2, k]$ 之间，意味着对于词条中的每个位置 $j$，它作为终点时，起点必须在区间 $[j - k + 1, j - 1]$ 之内。
- 我们可以利用双指针/滑动窗口维护当前窗口内合法起点的数量 `valid_start_count`。

## C++ 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

const int MAX_R = 105;
const int MAX_V = 200005;

// dp[r][v]: 第 r 轮结尾数字为 v 的状态
// 0: 不可达 | >0: 仅可由该人接出 | -1: 可由至少两人接出
int dp[MAX_R][MAX_V];

void solve() {
    int n, k, q;
    if (!(cin >> n >> k >> q)) return;

    vector<vector<int>> S(n + 1);
    int max_v = 1;

    for (int i = 1; i <= n; i++) {
        int l;
        cin >> l;
        S[i].resize(l);
        for (int j = 0; j < l; j++) {
            cin >> S[i][j];
            if (S[i][j] > max_v) {
                max_v = S[i][j];
            }
        }
    }

    vector<pair<int, int>> queries(q);
    int max_r = 0;
    for (int i = 0; i < q; i++) {
        cin >> queries[i].first >> queries[i].second;
        if (queries[i].first > max_r) {
            max_r = queries[i].first;
        }
    }

    // 重置 DP 数组
    for (int r = 0; r <= max_r; r++) {
        for (int v = 1; v <= max_v; v++) {
            dp[r][v] = 0;
        }
    }

    // 初始状态：第 0 轮起点为 1，用 -1 表示可由任意人作为开头接龙
    dp[0][1] = -1;

    for (int r = 1; r <= max_r; r++) {
        for (int i = 1; i <= n; i++) {
            int valid_start_count = 0;
            for (size_t j = 0; j < S[i].size(); j++) {
                int v = S[i][j];
                
                // 移出超出长度 k 限制的起点
                if (j >= (size_t)k) {
                    int out_v = S[i][j - k];
                    int prev_state = dp[r - 1][out_v];
                    if (prev_state == -1 || (prev_state > 0 && prev_state != i)) {
                        valid_start_count--;
                    }
                }
                
                // 如果当前位置前 k 个元素内有合法起点，则当前位置 v 可达
                if (valid_start_count > 0) {
                    if (dp[r][v] == 0) {
                        dp[r][v] = i;
                    } else if (dp[r][v] != i) {
                        dp[r][v] = -1;
                    }
                }
                
                // 将当前位置作为后续终点的潜在起点加入窗口
                int prev_state = dp[r - 1][v];
                if (prev_state == -1 || (prev_state > 0 && prev_state != i)) {
                    valid_start_count++;
                }
            }
        }
    }

    // 处理查询
    for (int i = 0; i < q; i++) {
        int r = queries[i].first;
        int c = queries[i].second;
        if (c > max_v) {
            cout << 0 << "\n";
        } else {
            if (dp[r][c] != 0) {
                cout << 1 << "\n";
            } else {
                cout << 0 << "\n";
            }
        }
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    int t;
    if (cin >> t) {
        while (t--) {
            solve();
        }
    }
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：每一轮遍历所有词条的全部元素，扫描复杂度为 $\mathcal{O}(\sum l_i)$。最多计算 $\max(r)$ 轮，因此总时间复杂度为 $\mathcal{O}(T \cdot (\max(r) \cdot \sum l_i + q))$，可以在规定时间内轻松通过。
- **空间复杂度**：$\mathcal{O}(\max(r) \cdot \max(V) + \sum l_i)$，空间消耗主要为 DP 状态数组。
