# CSP-J 2021 普及组 T4：小熊的果篮 (fruit)

## 题目描述
小熊的水果店里摆放着一排共 $n$ 个水果。每个水果只可能是苹果或桔子，从左到右依次用正整数 $1, 2, \dots, n$ 编号。连续排在一起的同一种水果称为一个“块”。小熊要把这一排水果挑到若干个果篮里，具体方法如下：

每次都把每一个“块”中最左边的水果同时挑出，组成一个果篮。挑出之后，剩下的水果按原先的顺序组成一排。继续执行这个步骤，直到所有水果都被挑完。你需要输出每个果篮里包含的水果的编号。

## 输入格式
第一行，包含一个正整数 $n$，表示水果的数量。
第二行，包含 $n$ 个空格隔开的整数，其中第 $i$ 个数表示编号为 $i$ 的水果的种类，$0$ 代表苹果，$1$ 代表桔子。

## 输出格式
输出若干行。
第 $i$ 行表示第 $i$ 次挑出的水果组成的果篮。从小到大排序输出该果篮中所有水果的编号，每两个编号之间用一个空格分隔。

## 样例说明
### 样例输入
```text
12
1 1 0 0 1 1 1 0 1 1 0 0
```

### 样例输出
```text
1 3 5 8 9 11
2 4 6 12
7
10
```

### 样例解释
第一轮挑出了编号为 1, 3, 5, 8, 9, 11 的水果。
剩下编号为 2, 4, 6, 7, 10, 12 的水果，其中 2 是桔子，4 是苹果，6, 7 是桔子，10 是苹果，12 是苹果。
第二轮挑出了编号为 2, 4, 6, 12 的水果。
剩下编号为 7, 10 的水果，其中 7 是桔子，10 是苹果。
第三轮挑出了编号为 7 的水果。
剩下编号为 10 的水果，是苹果。
第四轮挑出了编号为 10 的水果。全部水果被挑完。

## 数据范围
- 对于 $10\%$ 的数据，$n \le 5$。
- 对于 $30\%$ 的数据，$n \le 1000$。
- 对于 $70\%$ 的数据，$n \le 50000$。
- 对于 $100\%$ 的数据，$n \le 2 \times 10^5$。

## 题目分析与解题思路
本题需要模拟小熊挑选水果的过程。由于每次都会从每个“块”中取走第一个元素，且取走后相邻的同类水果可能会合并为一个新的“块”，直接用数组暴力模拟会导致 $O(n^2)$ 的时间复杂度，在 $n=2\times10^5$ 时会超时。

为了高效解决，我们可以采用 **集合（`std::set`）** 来维护两种水果的位置。
1. 使用两个 `set<int> s[2]`，分别存储当前剩余苹果（0）和桔子（1）的编号。
2. 每一轮挑选时，我们要找的是交替出现的块的首个元素。
3. 我们可以通过 `lower_bound` 快速找到大于当前挑选位置的下一个不同种类的水果编号。
4. 找到后，将其记录到答案中，并从相应的 `set` 中删除，然后将要寻找的水果种类取反，继续往后寻找，直到本轮找不到更多的块。
5. 重复上述操作直到两个 `set` 都为空。

因为 `set` 中的插入和删除操作以及 `lower_bound` 查找的时间复杂度都是 $O(\log n)$，所有水果总共被删除一次，因此总体时间复杂度为 $O(n \log n)$，足以通过 $100\%$ 的数据点。

## C++ 参考代码
```cpp
#include <iostream>
#include <set>
#include <vector>

using namespace std;

int main() {
    // 优化输入输出速度
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n;
    if (!(cin >> n)) return 0;
    
    set<int> s[2]; // s[0]存苹果的下标，s[1]存桔子的下标
    for (int i = 1; i <= n; i++) {
        int type;
        cin >> type;
        s[type].insert(i);
    }
    
    while (!s[0].empty() || !s[1].empty()) {
        vector<int> ans;
        int cur_type = -1;
        
        // 确定本轮第一个抓取的水果种类
        if (s[0].empty()) cur_type = 1;
        else if (s[1].empty()) cur_type = 0;
        else cur_type = (*s[0].begin() < *s[1].begin()) ? 0 : 1;
        
        int pos = 0;
        while (true) {
            // 在当前种类的水果中，寻找第一个下标大于 pos 的水果
            auto it = s[cur_type].lower_bound(pos);
            if (it == s[cur_type].end()) {
                break; // 后面没有这种水果了，本轮结束
            }
            
            ans.push_back(*it);
            pos = *it;
            s[cur_type].erase(it); // 将该水果从集合中移除
            
            cur_type ^= 1; // 切换要找的水果种类 (0变1，1变0)
        }
        
        // 输出本轮挑选出的水果编号
        for (int i = 0; i < ans.size(); i++) {
            cout << ans[i] << (i == ans.size() - 1 ? "" : " ");
        }
        cout << "\n";
    }
    
    return 0;
}
```
