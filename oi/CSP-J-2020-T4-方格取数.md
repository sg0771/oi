# 表格测试

| 对比维度 | NOIP 2000 | CSP-J 2020 |
| :---- | :---- | :---- |
| 行走方式          | 从左上角走到右下角，只能向下或向右走，一共走两次，取走格子里的数     | 从左上角走到右下角，每一步可以向上、向下或向右走，只走一次，不能重复经过格子     |
| 核心解法          | 多线程DP (四维)同时模拟两条路径，用状态 f[i<sub>1</sub>][j<sub>1</sub>][i<sub>2</sub>][j<sub>2</sub>] 来表示两个人分别走到 (i<sub>1</sub>,j<sub>1</sub>) 和 (i<sub>2</sub>,j<sub>2</sub>) 时的最大和。     | 分层DP (三维)因为可以上下走，需要记录从哪个方向来的状态，避免走回头路。通常用 dp[i][j][0/1/2] 表示从不同方向到达 (i,j) 的最大值     |
| 数据规模与范围     | N <= 10，方格内数字为正整数。数据规模较小，因此四维DP的 O(N^4) 复杂度是可以接受的。     | n, m <= 1000，方格内数字可能为负数。数据规模更大，需要 O(n*m) 的高效解法，同时初始化时要考虑负无穷，避免被负数路径干扰     |


💡 为什么解法差异这么大？
这背后的核心区别在于路径是否允许“反向”行走。

NOIP 2000版中，一个人只能单向（向下或向右）行走。两条路径如果在某点相遇，那么后续路径完全重合，只需要计算一次该点的数值。这种“同步性”是四维DP能够成立的关键。

CSP-J 2020版中，小熊可以向上走，这意味着它可能在某一列内先向下再向上，形成“迂回”路线。处理这种“走回头路”的可能性，就需要在按列处理时，分别从上到下和从下到上计算两次，确保每个格子都能从列内所有方向获得最优值。

总的来说，两道题虽然同名，但本质是两道完全不同的题目。2000年的题更侧重于多线程协作与状态同步，而2020年的题则考验对非传统移动方式下动态规划状态设计的理解。

## -------------------------------------------------------------


这道题是经典动态规划（DP）的进阶版，关键在于处理“可以向上走”这个条件，避免出现“后效性”。

题目要求小熊从左上角 (1,1) 走到右下角 (n,m)，每次可以向上、向下或向右走一格，且不能重复经过格子，求路径上整数之和的最大值 。

## 核心解题思路

最常见的解法是对每一列进行动态规划。因为虽然上下都可以走，但列号是单调增加的（只能向右走），我们可以把列作为“阶段”，在每一列内部处理上下的移动。

具体来说，用 dp[i][j][0] 和 dp[i][j][1] 两个状态来记录到达 (i, j) 时的最大值：

dp[i][j][0]：从上方或左方到达该点的最大值。

dp[i][j][1]：从下方或左方到达该点的最大值。

状态转移方式如下（按列进行）：

先处理从左侧转移：这是所有路径进入当前列的第一步。

从上一列同一行的最优值直接向右走一格，公式为 best_from_left = max(dp[i][j-1][0], dp[i][j-1][1]) + a[i][j]。

再处理从上到下转移：表示在当前列内向下走。

从上方的格子走下来，dp[i][j][0] = max( best_from_left, dp[i-1][j][0] + a[i][j] )。

最后处理从下到上转移：表示在当前列内向上走。

从下方的格子走上去，dp[i][j][1] = max( best_from_left, dp[i+1][j][1] + a[i][j] )。

合并本列结果：对于每个格子 (i, j)，最终的最优值就是 max(dp[i][j][0], dp[i][j][1])。

## 关键注意事项
因为格子里的整数可以是负数，所以在初始化所有 dp 数组时，必须设为一个非常小的数（如 -1e18），而不是 0 。

## 参考代码
以下代码展示了按列处理的 DP 思路，先读入整个方格，再逐列进行状态转移。

~~~~cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;
const long long NEG_INF = -1e18;
int n, m;
long long a[MAXN][MAXN];
long long dp[MAXN][MAXN][2]; // dp[i][j][0]: 从上或左来, dp[i][j][1]: 从下或左来

int main() {
    scanf("%d %d", &n, &m);
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            scanf("%lld", &a[i][j]);
        }
    }

    // 初始化所有dp值为极小值
    for (int i = 0; i <= n + 1; i++) {
        for (int j = 0; j <= m + 1; j++) {
            dp[i][j][0] = dp[i][j][1] = NEG_INF;
        }
    }

    // 起点初始化
    dp[1][1][0] = dp[1][1][1] = a[1][1];

    // 按列进行动态规划
    for (int j = 1; j <= m; j++) {
        // 1. 从上到下转移 (先处理从左侧进入)
        for (int i = 1; i <= n; i++) {
            if (j != 1) {
                // 从左侧进入本列格子(i, j)
                long long from_left = max(dp[i][j-1][0], dp[i][j-1][1]) + a[i][j];
                dp[i][j][0] = max(dp[i][j][0], from_left);
                dp[i][j][1] = max(dp[i][j][1], from_left);
            }
            // 从上往下走
            if (i != 1 && dp[i-1][j][0] != NEG_INF) {
                dp[i][j][0] = max(dp[i][j][0], dp[i-1][j][0] + a[i][j]);
            }
        }

        // 2. 从下到上转移
        for (int i = n; i >= 1; i--) {
            // 从下往上走
            if (i != n && dp[i+1][j][1] != NEG_INF) {
                dp[i][j][1] = max(dp[i][j][1], dp[i+1][j][1] + a[i][j]);
            }
            // 对本列格子(i, j)，从下和从上来的结果取最优，作为本格最终dp值
            // 这个最终值会被下一列使用
            dp[i][j][0] = max(dp[i][j][0], dp[i][j][1]);
            dp[i][j][1] = max(dp[i][j][0], dp[i][j][1]);
        }
    }

    // 终点(n, m)的答案
    printf("%lld\n", max(dp[n][m][0], dp[n][m][1]));
    return 0;
}
~~~
