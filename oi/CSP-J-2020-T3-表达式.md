## 一道关于逻辑表达式和表达式树的综合题。

这道题的核心要求是：给定一个由 &（与）、|（或）、!（非）构成的后缀逻辑表达式，以及每个变量的初始值，对于多个独立的询问（每次翻转一个变量的值），快速求出整个表达式的新值。

关键在于避免每次询问都重新计算整个表达式，需要通过“短路求值”的思路来判断每个变量是否会影响最终结果。

## 核心算法与思路
标准的解法是构建表达式树并进行“影响”标记。思路可以分为三步：

构建表达式树（后缀表达式转二叉树）

根据后缀表达式构建一棵二叉树。其中，叶子节点是变量（x1, x2...），非叶子节点是运算符（&, |, !）。

因为后缀表达式天然适合用栈处理，遇到操作数就压栈，遇到运算符就弹出操作数作为子节点，构建新节点后再压栈，最终栈顶就是树的根。

## 计算原表达式的值

从根节点开始，通过一次DFS（深度优先搜索）递归计算每个子树的值，得到整个表达式最初的值 original_val。

标记“决定性”变量（利用短路性质）

这是最巧妙的步骤。我们需要判断改变哪个变量会让整个表达式的值翻转。

核心逻辑：从根节点向下递归“染色”或“标记”。如果一个节点（子树）的值无法决定其父节点的值，那么它就不会影响最终结果。

### 具体规则如下：

#### 非运算 (!)：
! 运算的结果直接取决于其子节点，所以任何影响子节点的变量都会影响 ! 运算的结果，需要继续向下递归标记。

#### 或运算 (|)：

如果左子节点的值为 0，说明表达式 0 | right 的结果完全由 right 决定，因此 right 子树内的变量是决定性的，需要递归标记 right。

如果右子节点的值为 0，同理，需要递归标记 left。

如果某子节点值为 1，则 1 | anything 恒为 1，该子节点对结果无影响，停止标记。

#### 与运算 (&)：

如果左子节点的值为 1，表达式 1 & right 的结果由 right 决定，需要递归标记 right。

如果右子节点的值为 1，需要递归标记 left。

如果某子节点值为 0，则 0 & anything 恒为 0，该子节点对结果无影响，停止标记。

#### 回答询问

对于每个询问的变量 xi，检查它是否被标记为“决定性变量”。

如果是，那么翻转它的值会使表达式结果翻转，答案是 !original_val。

如果不是，那么翻转它对表达式无影响，答案是 original_val。

## 参考代码思路
下面的代码演示了从字符串构建树、计算值、标记影响到回答询问的完整流程。

~~~cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 1e6 + 5;
int n, q, cnt;
int val[MAXN];       // 存储每个节点的值，叶子节点存变量值
int lc[MAXN], rc[MAXN]; // 左右孩子编号，-1表示无
int op[MAXN];        // 节点类型: 0变量, 1为!, 2为&, 3为|
bool is_important[MAXN]; // 标记变量是否影响结果
int var_node[MAXN];  // 变量x_i对应的节点编号
stack<int> stk;

// 递归计算原表达式的值
int dfs_calc(int u) {
    if (op[u] == 0) return val[u]; // 叶子节点直接返回
    int l_val = dfs_calc(lc[u]);
    if (op[u] == 1) return val[u] = !l_val;
    int r_val = dfs_calc(rc[u]);
    if (op[u] == 2) return val[u] = l_val & r_val; // &
    if (op[u] == 3) return val[u] = l_val | r_val; // |
}

// 递归标记决定性变量
void dfs_mark(int u) {
    if (op[u] == 0) { // 如果是变量，标记为重要
        is_important[u] = true;
        return;
    }
    if (op[u] == 1) { // !运算，子节点必定影响结果
        dfs_mark(lc[u]);
    } else if (op[u] == 2) { // & 运算
        if (val[lc[u]] == 1) dfs_mark(rc[u]); // 1 & right, right是关键
        if (val[rc[u]] == 1) dfs_mark(lc[u]); // left & 1, left是关键
    } else if (op[u] == 3) { // | 运算
        if (val[lc[u]] == 0) dfs_mark(rc[u]); // 0 | right, right是关键
        if (val[rc[u]] == 0) dfs_mark(lc[u]); // left | 0, left是关键
    }
}

int main() {
    string s;
    getline(cin, s); // 读取整行表达式
    // 1. 解析表达式并建树
    int node_cnt = 0;
    for (int i = 0; i < s.size(); i++) {
        if (s[i] == ' ') continue;
        if (s[i] == 'x') {
            int num = 0;
            i++; // 跳过'x'
            while (i < s.size() && isdigit(s[i])) {
                num = num * 10 + (s[i] - '0');
                i++;
            }
            i--; // 循环外层会i++，这里回退一位
            node_cnt++;
            op[node_cnt] = 0;
            var_node[num] = node_cnt;
            stk.push(node_cnt);
        } else if (s[i] == '!') {
            node_cnt++;
            op[node_cnt] = 1;
            int child = stk.top(); stk.pop();
            lc[node_cnt] = child;
            stk.push(node_cnt);
        } else if (s[i] == '&') {
            node_cnt++;
            op[node_cnt] = 2;
            int r = stk.top(); stk.pop();
            int l = stk.top(); stk.pop();
            lc[node_cnt] = l;
            rc[node_cnt] = r;
            stk.push(node_cnt);
        } else if (s[i] == '|') {
            node_cnt++;
            op[node_cnt] = 3;
            int r = stk.top(); stk.pop();
            int l = stk.top(); stk.pop();
            lc[node_cnt] = l;
            rc[node_cnt] = r;
            stk.push(node_cnt);
        }
    }
    int root = stk.top();

    // 2. 读取变量个数和初始值
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        int x;
        scanf("%d", &x);
        val[var_node[i]] = x;
    }

    // 3. 计算原表达式的值并标记决定性变量
    int original_res = dfs_calc(root);
    dfs_mark(root);

    // 4. 回答询问
    scanf("%d", &q);
    while (q--) {
        int x;
        scanf("%d", &x);
        if (is_important[var_node[x]]) {
            printf("%d\n", !original_res);
        } else {
            printf("%d\n", original_res);
        }
    }
    return 0;
}
~~~
