# CSP-J 2022 T4 上升点数 题解与C++实现

## 题目概述

**题目名称**：上升点数 (Point)  
**来源**：CSP-J 2022 第二轮 T4  
**时间限制**：1.0s  
**空间限制**：512MB  

### 问题描述
在一个二维平面笛卡尔坐标系中，给定 $n$ 个互不相同的整点。你可以额外自由地添加最多 $k$ 个整点。  

一个由若干个整点构成的点序列被称为**严格上升序列**，当且仅当对于序列中任意相邻的两个点 $P_i(x_i, y_i)$ 和 $P_{i+1}(x_{i+1}, y_{i+1})$，均满足：
1. $x_{i+1} = x_i + 1$ 且 $y_{i+1} = y_i$ （向右移动一步），或者
2. $x_{i+1} = x_i$ 且 $y_{i+1} = y_i + 1$ （向上移动一步）。

现在允许你添加最多 $k$ 个整点，请求出能够构成的**最长严格上升序列**包含的点数（包括给定的原有点和新添加的点）。

---

## 解题思路分析

### 1. 概念转化
题目要求的上升序列只能向右或向上移动。也就是说，对于两个给定的原有点 $A(x_1, y_1)$ 和 $B(x_2, y_2)$，如果能从 $A$ 走到 $B$，必须满足：
* $x_2 \ge x_1$ 且 $y_2 \ge y_1$。

从 $A$ 走到 $B$ 所需要的总步数为曼哈顿距离：
$$dist(A, B) = (x_2 - x_1) + (y_2 - y_1)$$

在这段路径中，除了起点 $A$ 和终点 $B$ 外，中间共有 $dist(A, B) - 1$ 个中间位置。如果我们在中间不经过其他已给出的原有点，那么连接 $A$ 和 $B$ 所需要**额外自由添加的点数**为：
$$cost(A, B) = (x_2 - x_1) + (y_2 - y_1) - 1$$

### 2. 动态规划设计 (DP)

我们可以通过**动态规划**来求解此问题。

#### 状态定义
首先将给定的 $n$ 个点按照坐标进行排序（以 $x$ 为第一关键字升序，以 $y$ 为第二关键字升序）。排序后，若 $i < j$，则点 $j$ 不可能走到点 $i$，符合 DP 的无后效性。

定义状态 $dp[i][j]$：
* 表示以第 $i$ 个**给定原有点**为结尾，且**恰好使用了 $j$ 个额外自由点**时，能达到的最长严格上升序列的**点数**。

#### 状态转移方程
对于当前点 $i$ ($1 \le i \le n$)，我们可以枚举它前面的每一个原有点 $p$ ($1 \le p < i$)：
* 只有当 $x_i \ge x_p$ 且 $y_i \ge y_p$ 时，点 $p$ 才能到达点 $i$。
* 从点 $p$ 走到点 $i$ 需要消耗额外点数 $c = (x_i - x_p) + (y_i - y_p) - 1$。
* 如果当前剩余可用的自由点数量 $j \ge c$，则可以从 $dp[p][j - c]$ 转移过来：
$$dp[i][j] = \max(dp[i][j], dp[p][j - c] + c + 1)$$

* **初始状态与边界条件**：
  * 对于任意点 $i$ 和自由点数 $j$ ($0 \le j \le k$)，初始化 $dp[i][j] = j + 1$。
  * 含义是：即使前面不连接任何给定的点，仅以点 $i$ 为基础，在其前面添加 $j$ 个自由点，也能构成长度为 $j + 1$ 的序列。

* **最终答案**：
  * 遍历所有 $i \in [1, n]$ 和 $j \in [0, k]$，以点 $i$ 结尾且使用 $j$ 个自由点后，剩余可自由支配的自由点数量为 $k - j$。这些剩余的自由点可以随意放置在序列的头部或尾部。
  * 因此，最终答案为：
    $$ans = \max_{1 \le i \le n, 0 \le j \le k} (dp[i][j] + (k - j))$$

---

## 复杂度分析

- **时间复杂度**：
  - 点的排序：$\mathcal{O}(n \log n)$。
  - DP 转移：共有 $n$ 个点，每个点遍历前驱 $n$ 个点，对于每个点对枚举自由点数 $k$。
  - 总时间复杂度为 $\mathcal{O}(n^2 \cdot k)$。
  - 在本题数据范围 $n \le 500, k \le 100$ 下，$n^2 \cdot k = 500^2 \times 100 = 2.5 \times 10^7$，可以在 1.0 秒内轻松通过。

- **空间复杂度**：
  - 数组 $dp[505][105]$ 占用的内存空间微乎其微，空间复杂度为 $\mathcal{O}(n \cdot k)$。

## C++ 完整代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

// 定义点结构体
struct Point {
    int x, y;
    
    // 按照 x 升序排序，若 x 相同则按 y 升序排序
    bool operator<(const Point& other) const {
        if (x != other.x) return x < other.x;
        return y < other.y;
    }
};

int dp[505][105];

int main() {
    // 优化标准输入输出流
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    if (!(cin >> n >> k)) return 0;

    vector<Point> pts(n);
    for (int i = 0; i < n; ++i) {
        cin >> pts[i].x >> pts[i].y;
    }

    // 1. 将原有点按坐标升序排序
    sort(pts.begin(), pts.end());

    int max_len = 0;

    // 2. 动态规划
    for (int i = 0; i < n; ++i) {
        // 初始状态：只选点 i，并在前面直接铺设 j 个自由点
        for (int j = 0; j <= k; ++j) {
            dp[i][j] = j + 1;
        }

        // 枚举点 i 之前的原有点 p
        for (int p = 0; p < i; ++p) {
            // 只有当 p 在 i 的左下方（或同行/同列）时才能到达
            if (pts[i].x >= pts[p].x && pts[i].y >= pts[p].y) {
                // 连接 p 和 i 所需要添加的额外自由点数量
                int cost = (pts[i].x - pts[p].x) + (pts[i].y - pts[p].y) - 1;

                // 枚举在点 i 处累计使用的自由点数 j
                for (int j = cost; j <= k; ++j) {
                    dp[i][j] = max(dp[i][j], dp[p][j - cost] + cost + 1);
                }
            }
        }

        // 统计以点 i 结尾，使用 j 个自由点时的最大点数（加上剩余未使用的 k - j 个自由点）
        for (int j = 0; j <= k; ++j) {
            max_len = max(max_len, dp[i][j] + (k - j));
        }
    }

    // 输出最终答案
    cout << max_len << "
";

    return 0;
}
```
