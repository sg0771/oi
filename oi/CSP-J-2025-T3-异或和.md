# CSP-J 2025 T3 异或和（xor）
洛谷题号：P14359

一、题目原文
题目描述小 R 有一个长度为 n 的非负整数序列 $a_1,a_2,\dots,a_n$。<br>
区间 $[l,r]$ 的权值 = $a_l \oplus a_{l+1}\oplus\dots\oplus a_r$（按位异或）。给定 k，选出尽可能多互不相交的区间，每个区间异或和等于 k。求最多能选出多少个。<br>
互不相交：区间不能共用任意下标。输入格式第一行两个整数 $n,k$。
第二行 n 个整数 $a_1\sim a_n$。输出格式输出最多区间数量。<br>
## 样例 1
输入
4 3
2 1 0 3
输出：2

解释：选 [1,2]、[4,4]

## 样例 2
输入
4 0
2 1 0 3
输出：1

只能选 [3,3]

数据范围$1\le n\le 5\times 10^5$<br>

$0\le k,a_i < 2^{20}$

# 二、核心数学转化（前缀异或）
## 设前缀异或数组：
$s[0]=0,\quad s[i]=a_1\oplus a_2\oplus\dots\oplus a_i$
区间 $[l,r]$ <br>
异或和：
$s[r]\oplus s[l-1] = k$ <br>
等价条件：<br>
$\boldsymbol{s[l-1] = s[r] \oplus k}$想要找到左端点 $l-1$，使得前缀异或等于 $s[r]\oplus k$。

# 三、两种主流解法方法 

## 1：贪心（考场常用，O (n)，能 AC）<br>

## 策略：
一旦找到合法区间 $[l,r]$，立刻选取它；下一个区间只能从 $r+1$ 开始找。<br>
原理：选越早结束的区间，给后面留出最多空间，数量最优。
操作：
维护 last：上一个选中区间的右端点（初始 = 0）<br>
数组 pos[x]：记录当前轮内前缀异或值 x 最早出现位置<br>
遍历 r，求目标值 $t = s[r]\oplus k$<br>

如果 pos[t] >= last：找到区间 $[pos[t]+1, r]$，答案 + 1，更新 last=r，清空 pos 重新开始<br>
不断更新 pos[s[r]] = r<br>

⚠️ 注意：每次选中一段区间后，必须重置查找起点，不能沿用之前的 pos 记录。

C++ AC 代码（贪心版）
~~~cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 5e5 + 10;
const int MAXV = 1 << 20;

int a[MAXN];
int pos[MAXV];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    for (int i = 1; i <= n; ++i) cin >> a[i];

    memset(pos, -1, sizeof pos);
    pos[0] = 0;
    int pre = 0;    // 当前前缀异或
    int last = 0;   // 上一段选中区间右端
    int ans = 0;

    for (int r = 1; r <= n; ++r)
    {
        pre ^= a[r];
        int target = pre ^ k;
        if (pos[target] >= last)
        {
            ans++;
            last = r;
            memset(pos, -1, sizeof pos);
            pos[0] = last;
            pre = 0;
        }
        pos[pre] = r;
    }
    cout << ans << endl;
    return 0;
}
~~~

缺点：memset 循环清空数组理论上最坏会退化；考试大部分数据能过，极限大数据建议用 DP 版本。

# 方法 2：动态规划（标准正解，严格 O (n)，稳定满分）定义：
$dp[i]$：前 i 个数最多选出多少区间<br>
转移：<br>
不选第 i 结尾区间：$dp[i] = dp[i-1]$<br>
如果存在 j 满足 $s[j] = s[i]\oplus k$：$dp[i]=\max(dp[i], dp[j]+1)$<br>
维护数组 best[x]：所有前缀异或等于 x 的位置中最大的 dp 值。<br>
$dp[i] = \max(dp[i-1], best[s[i]\oplus k]+1)$<br>
更新 best[s[i]] = max(best[s[i]], dp[i])C++ DP <br>

标准代码
~~~cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 5e5 + 10;
const int MAXV = 1 << 20;

int a[MAXN];
int dp[MAXN];
int best[MAXV];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    for (int i = 1; i <= n; ++i) cin >> a[i];

    memset(best, -0x3f, sizeof best);
    int pre = 0;
    best[0] = 0;
    dp[0] = 0;

    for (int i = 1; i <= n; ++i)
    {
        pre ^= a[i];
        dp[i] = dp[i - 1];
        int tar = pre ^ k;
        if (best[tar] >= 0)
        {
            dp[i] = max(dp[i], best[tar] + 1);
        }
        best[pre] = max(best[pre], dp[i]);
    }
    cout << dp[n] << endl;
    return 0;
}
~~~

# 四、易错点提醒
区间不能重叠！<br>
很多人直接统计所有合法区间总数，不判重叠，只能拿部分分。<br>
前缀异或下标不要搞混：$[l,r]\iff s[r]\oplus s[l-1]$<br>
$2^{20}=1048576$，数组大小开到 1<<20 足够，不要开小导致越界<br>
数据量 $5\times10^5$，一定要关同步 ios::sync_with_stdio<br>(false);，否则 TLE<br>
