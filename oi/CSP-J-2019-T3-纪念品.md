# CSP-J 2019 普及组 T3：纪念品 (Souvenir) 题解与分析

## 1. 题目核心题意
你有 $M$ 枚金币，有 $T$ 天时间，每天有 $N$ 种纪念品，你预先知道了这 $N$ 种纪念品在未来 $T$ 天里的每天的价格。
你可以在任何一天用金币买入纪念品，也可以在任何一天卖出纪念品换回金币。并且，**同一天内可以先卖出再买入，也可以买入多个同一种纪念品**。
求 $T$ 天结束后，你最多能持有多少枚金币？

*(注：根据题目数据范围设定，任意时刻金币数不会超过 10000)*

---

## 2. 算法分析与核心思想

很多人看到这道题会觉得情况非常复杂：一件物品可以第1天买第3天卖，也可以第2天买第5天卖，状态难以统一。

但这里有一个极其核心的**贪心思想与等价转换**：
> **“第 $i$ 天买入，第 $j$ 天卖出” 完全等价于 “第 $i$ 天买入，第 $i+1$ 天卖出，然后第 $i+1$ 天立刻再买回来，第 $i+2$ 天卖出……一直到第 $j$ 天卖出”。**

基于这个等价转换，我们可以把这 $T$ 天的跨度，**拆解成 $T-1$ 个相互独立的“1天交易期”**。

在每一个“1天交易期”（比如第 $k$ 天到第 $k+1$ 天）中，我们面临的选择可以完美映射到**完全背包问题**的模型中：
* **背包容量**：你当前拥有的所有金币数量 $M$。
* **物品重量**：第 $k$ 天该纪念品的价格 $P_{k, i}$（你需要花费的金币）。
* **物品价值（利润）**：第 $k+1$ 天的价格减去第 $k$ 天的价格，即 $P_{k+1, i} - P_{k, i}$。注意：只有当明天涨价时（利润 $>0$ ），这件物品才有价值，否则直接忽略。
* **选择规则**：同一种物品你可以买无数件，这就是完全背包。

所以，这道题的本质就是：**跑 $T-1$ 遍完全背包。**

---

## 3. 状态转移方程

对于第 $k$ 天，设 `dp[j]` 表示用 $j$ 枚金币去投资，在今天这天内能赚取的**最大利润**。

$$dp[j] = \max(dp[j], dp[j - P_{k, i}] + P_{k+1, i} - P_{k, i})$$

其中：
*   $P_{k, i}$ 是物品 $i$ 今天的价格 (重量)。
*   $P_{k+1, i} - P_{k, i}$ 是物品 $i$ 卖到明天的净利润 (价值)。
*   每次外层循环过完一天后，把今天赚到的最大利润加到总本金中：$M = M + dp[M]$，再进入下一天的计算。

## 4. C++ 标准代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <cstring>

using namespace std;

// p[i][j] 表示第 i 天第 j 种纪念品的价格
int p[105][105]; 
// dp[j] 表示用 j 个金币在某一天能赚取的最大利润
int dp[10005]; 

int main() {
    int t, n, m;
    // 输入天数 t，物品数 n，初始金币 m
    cin >> t >> n >> m;
    
    for (int i = 1; i <= t; ++i) {
        for (int j = 1; j <= n; ++j) {
            cin >> p[i][j];
        }
    }

    // 遍历每一天（最后一天不需要买入，所以遍历到 t-1）
    for (int i = 1; i < t; ++i) {
        // 每天开始时，将 dp 数组清零
        memset(dp, 0, sizeof(dp)); 
        
        // 遍历每一种纪念品（相当于遍历背包物品）
        for (int j = 1; j <= n; ++j) {
            // 如果明天价格比今天高（有利润才考虑）
            if (p[i+1][j] > p[i][j]) {
                int cost = p[i][j];                    // 成本 (重量)
                int profit = p[i+1][j] - p[i][j];      // 利润 (价值)
                
                // 完全背包：正序遍历容量，从 cost 一直到当前拥有的总金币 m
                for (int k = cost; k <= m; ++k) {
                    dp[k] = max(dp[k], dp[k - cost] + profit);
                }
            }
        }
        // 今天的交易结束后，把赚到的最大利润加入本金，作为明天的启动资金
        m += dp[m]; 
    }

    // 输出最终剩下的金币数量
    cout << m << endl;
    return 0;
}
```

## 5. 复杂度分析
*   **时间复杂度**：$O(T \times N \times M_{max})$。其中 $T$ 为天数（$\le 100$），$N$ 为物品数（$\le 100$），$M_{max}$ 为最大拥有的金币数（根据题意不会超过 $10000$）。总运算次数大约在 $10^8$ 级别以内，对于 1 秒的时限来说可以通过。
*   **空间复杂度**：$O(T \times N + M_{max})$。二维数组用于存放每一天的价格表，一维 $DP$ 数组用于完全背包的状态压缩存储。空间占用极小，完全符合题目要求。
