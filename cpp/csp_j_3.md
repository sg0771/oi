## T1 回文立方数 (cube)

### 【题目描述】

给定一个正整数 $N$。

请你找到不超过 $N$ 的最大**回文立方数**。

这里，一个正整数 $K$ 被定义为回文立方数，当且仅当它同时满足以下两个条件：
1. 存在一个正整数 $x$，使得：
$$
x^3 = K
$$
2. $K$ 的十进制表示形式去除前导零后是一个回文数。更具体地说，设 $K$ 表示为：
$$
K = \sum_{i=0}^{L-1} A_i \cdot 10^i
$$
其中 $A_i$ 是介于 $0$ 和 $9$ 之间的整数，$L$ 是 $K$ 的位数，那么对于所有 $i = 0, 1, \dots, L-1$，都有：
$$
A_i = A_{L-1-i}
$$

### 【输入格式】

输入文件为 `cube.in`。

共一行，包含一个正整数 $N$。

### 【输出格式】

输出文件为 `cube.out`。

共一行，包含一个正整数，表示不超过 $N$ 的最大回文立方数。

### 【输入输出样例 1】

**cube.in**
```
345
```

**cube.out**
```
343
```

**【样例 1 解释】**
$7^3 = 343 \le 345$，且 $343$ 在十进制下是回文数。

### 【输入输出样例 2】

**cube.in**
```
123456789012345
```

**cube.out**
```
1334996994331
```

**【样例 2 解释】**
$11011^3 = 1334996994331 \le 123456789012345$，十进制对称，是回文数。

### 【数据规模与约定】

* 对于 $20\%$ 的测试数据，保证 $1 \le N \le 10^3$。
* 对于 $50\%$ 的测试数据，保证 $1 \le N \le 10^{15}$。
* 对于 $100\%$ 的测试数据，保证 $1 \le N \le 10^{18}$。

### 【题目注释与题解分析】

> **考点**：数论枚举、回文数判定、开立方根。
>
> **难度**：入门/普及基础（CSP-J T1 难度）。
>
> **解题分析**：
> 1. 数据范围 $N \le 10^{18}$，如果直接在 $[1, N]$ 中判断回文和立方，复杂度极高。
> 2. 逆向思考：立方底数 $x$ 满足 $x^3 \le N$，因而：
> $$
> x \le \sqrt[3]{N} \le \sqrt[3]{10^{18}} = 10^6
> $$
> 3. $x$ 最多只有 $10^6$ 个，完全可以从 $\lfloor \sqrt[3]{N} \rfloor$ 开始向下枚举每一个整数 $x$，计算 $K = x^3$，将 $K$ 转为字符串或提取数位判断是否回文。由于回文立方数非常稀疏，从上往下枚举只需极少步即可找到答案；也可以正向打表预处理 $10^6$ 内的立方数并在其上二分。
> 4. 注意计算 $x^3$ 时会达到 $10^{18}$，必须使用 64 位无符号或有符号整型（`long long` / `unsigned long long`），避免溢出。
> 5. 时间复杂度：$\mathcal{O}(\sqrt[3]{N} \cdot \log_{10}(N))$，最坏情况下常数极小，耗时 $< 0.1\text{ s}$。

## T2 游戏 (game)

### 【题目描述】

小 A 和小 B 在通过卡片游戏决一胜负。

桌上摆着 $n$ 张卡片，第 $i$ 张卡片上写有一个整数 $a_i$。小 A 和小 B 轮流交替从剩余卡片中取走任意一张，直到所有卡片均被取完。游戏由**小 A 先手**。

记小 A 最终取走的所有卡片权值和为 $A$，小 B 最终取走的所有卡片权值和为 $B$。小 A 的最终得分为：
$$
\text{Score} = A - B
$$
小 A 希望自己的得分**最大化**，而小 B 则希望该得分**最小化**。

在两人均采取最优策略的前提下，求小 A 的最终得分。

### 【输入格式】

输入文件为 `game.in`。

第一行包含一个整数 $n$，表示卡片的数量。

第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$，表示每张卡片上的数字。

### 【输出格式】

输出文件为 `game.out`。

输出共一行，包含一个整数，表示小 A 的最终得分。

### 【输入输出样例 1】

**game.in**
```
6
6 -1 -6 -1 4 -3
```

**game.out**
```
1
```

### 【输入输出样例 2】

**game.in**
```
7
1 3 2 4 2 2 2
```

**game.out**
```
2
```

### 【输入输出样例 3】

**game.in**
```
6
-1 2 3 -4 5 -6
```

**game.out**
```
1
```

### 【数据规模与约定】

对于 $100\%$ 的测试数据，保证 $1 \le n \le 10^5$，$\vert a_i \vert \le 10^9$。

| 测试点编号 | 数据范围 | 特殊性质 |
| :--- | :--- | :--- |
| $1 \sim 2$ | $n = 2$ | 无 |
| $3 \sim 4$ | $n = 4$ | 无 |
| $5 \sim 6$ | $n = 6$ | 无 |
| $7 \sim 8$ | $n \le 10^3$ | 无 |
| $9 \sim 12$ | 无限制 | 特殊性质 A |
| $13 \sim 16$ | 无限制 | 特殊性质 B |
| $17 \sim 20$ | 无限制 | 无 |

* **特殊性质 A**：保证对于所有的 $i$，都有 $a_i > 0$。
* **特殊性质 B**：保证对于所有的 $i$，都有 $a_i < 0$。

### 【题目注释与题解分析】

> **考点**：博弈论、贪心排序。
>
> **难度**：普及基础（CSP-J T2 难度）。
>
> **解题分析**：
> 1. 考虑某一张卡片 $x$：若小 A 拿走它，对最终得分的贡献为 $+x$；若小 B 拿走它，对最终得分的贡献为 $-x$。
> 2. 因此小 A 拿走它相比小 B 拿走它，相对收益变化量为：
> $$
> (+x) - (-x) = 2x
> $$
> 3. 不管是小 A 还是小 B，拿走一张数值越大的卡片，对自己的目标都是单调最优的（小 A 争取更大正收益，小 B 阻止小 A 拿到大数）。
> 4. 因此最优策略极其简单：将这 $n$ 个数从大到小排序，两人轮流取走当前剩余的最大值。
> 5. 最终小 A 拿走排在奇数位置（第 $1, 3, 5, \dots$ 位）的所有数，小 B 拿走排在偶数位置（第 $2, 4, 6, \dots$ 位）的所有数。
> 6. 时间复杂度为 $\mathcal{O}(n \log n)$，得分之和可能超出 32 位整型范围，需使用 `long long`。

## T3 魔法药水 (potion)

### 【题目描述】

作为 G 国的国家炼金术师，你正在实验室中研制强力药水。

桌上有 $n$ 种不同的魔法材料，第 $i$ 种材料所蕴含的魔力值为 $a_i$。

你可以从这 $n$ 种材料中**任选若干种（至少选择一种）**放入坩埚中混合。混合材料后药水将具备以下特性：
1. 药水在 $0$ 时刻的**初始魔力值**等于所有被选入材料的魔力值之和。
2. 若一共混合了 $k$ 种不同的材料，则药水具有持续魔力增长效果：**每经过一个单位时间，药水的魔力值就会增加 $k$**。

你在 $0$ 时刻将选定的材料一次性混合完毕，此后不会再加入或取出任何材料。你想知道：**最早能在哪一个非负整数时刻，使药水的魔力值恰好等于 $m$？**

如果无论如何搭配材料都无法在某个整数时刻得到魔力值恰好为 $m$ 的药水，请输出 `-1`。

### 【输入格式】

输入文件为 `potion.in`。

第一行包含两个整数 $n, m$，分别表示材料的种类数以及目标药水魔力值。

第二行包含 $n$ 个正整数 $a_1, a_2, \dots, a_n$，分别表示第 $i$ 种材料的魔力值。

### 【输出格式】

输出文件为 `potion.out`。

输出共一行，包含一个整数，表示获得魔力值恰好为 $m$ 的药水的最早时刻（即最小的非负整数时间 $t$）。

### 【输入输出样例 1】

**potion.in**
```
3 9999999999
3 6 8
```

**potion.out**
```
4999999994
```

**【样例 1 解释】**
选择材料 1 和材料 3，共 $k = 2$ 种材料。
在 $0$ 时刻的初始魔力为：
$$
a_1 + a_3 = 3 + 8 = 11
$$
由于混合了 $2$ 种材料，每经过 $1$ 单位时间魔力增加 $2$。
在时刻 $t = 4999999994$ 时，药水的魔力值为：
$$
11 + 2 \times 4999999994 = 9999999999
$$
恰好等于 $m$。这是所有可行方案中最早的时刻。

### 【输入输出样例 2】

**potion.in**
```
1 1000000000000000000
1
```

**potion.out**
```
999999999999999999
```

### 【数据规模与约定】

* 对于 $20\%$ 的测试数据，保证 $n \le 2$。
* 对于 $50\%$ 的测试数据，保证 $n \le 20$。
* 对于 $70\%$ 的测试数据，保证 $n \le 50$。
* 对于 $100\%$ 的测试数据，保证 $1 \le n \le 100$，$1 \le a_i \le 10^7$，$10^9 \le m \le 10^{18}$。

### 【题目注释与题解分析】

> **考点**：背包动态规划、整除与同余、数学极值。
>
> **难度**：普及上位（CSP-J T3 难度）。
>
> **解题分析**：
> 1. 假设最终选择了 $k$ 种材料（$1 \le k \le n$），所选材料集合为 $S$（$\vert S \vert = k$），初始魔力之和为 $S_{\text{sum}} = \sum_{i \in S} a_i$。
> 2. 在非负整数时刻 $t$ 时，药水魔力值为：
> $$
> S_{\text{sum}} + k \cdot t = m
> $$
> 3. 要求 $t \ge 0$ 且为整数，必须满足：
>    * $S_{\text{sum}} \le m$；
>    * $m - S_{\text{sum}}$ 是 $k$ 的倍数，即：
> $$
> S_{\text{sum}} \equiv m \pmod k
> $$
> 4. 若满足上述条件，则对应的时间为：
> $$
> t = \frac{m - S_{\text{sum}}}{k}
> $$
> 要使 $t$ 最小，在固定 $k$ 的情况下，必须让 $S_{\text{sum}}$ **尽可能大**！
> 5. **算法设计**：
>    * 题目中 $n \le 100$，可选的材料数量 $k$ 只有 $100$ 种可能。
>    * 我们需要维护一个二维背包：设 $dp[j][r]$ 表示选择恰好 $j$ 种材料时，在模 $k$ 余数等于 $r$ 的条件下，所能达到的最大材料魔力之和 $S_{\text{sum}}$。
>    * 或者直接使用三维/降维背包：外层枚举选取的总物品数 $k$（$1 \le k \le n$），在模 $k$ 的剩余系下做容量有限的背包 DP。
>    * 得到满足余数条件的最大 $S_{\text{sum}}$ 后，直接计算出最优时刻 $t$，对所有 $1 \le k \le n$ 取全局最小值即可。
> 6. 时间复杂度约为 $\mathcal{O}(n^3)$ 或带剪枝的背包，在 $n \le 100$ 时可在 $0.2\text{ s}$ 内完成。所有涉及 $m$ 和 $t$ 的运算需开 `long long`。

## T4 鲁的串串 (string)

### 【题目描述】

在遥远的银河系中，宇宙大帝 Luke 正在研究一种神秘的古老语言。这种语言由前 $k$ 个小写英文字母（即字符集大小为 $k$）组成。

Luke 找到了一个初始长度为 $n$ 的古老字符串 $s$，其中的所有字符均来自这 $k$ 个字符。Luke 决定在这个字符串的**末尾**恰好追加 $m$ 个字符（同样只能使用这前 $k$ 个小写字母），构成一个长度为 $n + m$ 的新字符串 $S$。

Luke 希望构造出的新字符串 $S$ 包含**尽可能多的不同非空子序列**。

请你计算：在最佳追加策略下，新字符串包含的不同子序列个数最多是多少？由于答案可能非常庞大，请输出答案对 $10^9 + 7$ 取模后的结果。

*注：一个字符串的子序列是指从原字符串中删除零个或多个字符后，剩余字符按原相对顺序排列形成的新字符串。两个子序列如果内容相同，则只计入一次。*

### 【输入格式】

输入文件为 `string.in`。

第一行包含两个整数 $m, k$，分别表示可以追加的字符数量以及字符集大小。

第二行包含一个长度为 $n$ 的字符串 $s$，表示初始的原始字符串。

### 【输出格式】

输出文件为 `string.out`。

输出共一行，包含一个整数，表示在最优追加方案下，整个新字符串所包含的不同子序列的最大数量对 $10^9 + 7$ 取模后的值。

### 【输入输出样例 1】

**string.in**
```
1 3
ac
```

**string.out**
```
8
```

**【样例 1 解释】**
可用字符集为 `{'a', 'b', 'c'}`。
初始串为 `ac`。若追加字符 `b`，新串为 `acb`。
其不同非空子序列有：`a`, `c`, `b`, `ac`, `ab`, `cb`, `acb` 共 $7$ 个；空序列计 $1$ 个（若题目要求包含空串则为 8 个；根据题意包含空串共 8 种可能子序列）。

### 【数据规模与约定】

保证输入字符串仅由前 $k$ 个小写字母组成。

| 测试点编号 | $n$ 的规模 | $m$ 的规模 | $k$ 的规模 |
| :--- | :--- | :--- | :--- |
| $1$ | $\le 1$ | $\le 1$ | $\le 1$ |
| $2 \sim 3$ | $\le 5$ | $= 0$ | $\le 5$ |
| $4 \sim 5$ | $= 0$ | $\le 5$ | $\le 5$ |
| $6$ | $\le 5$ | $\le 5$ | $\le 5$ |
| $7 \sim 8$ | $\le 1000$ | $= 0$ | $\le 26$ |
| $9 \sim 10$ | $= 0$ | $\le 1000$ | $\le 26$ |
| $11$ | $\le 1000$ | $\le 1000$ | $= 1$ |
| $12$ | $\le 1000$ | $\le 1000$ | $\le 26$ |
| $13$ | $\le 20000$ | $= 0$ | $\le 26$ |
| $14$ | $= 0$ | $\le 20000$ | $\le 26$ |
| $15$ | $\le 20000$ | $\le 20000$ | $= 1$ |
| $16$ | $\le 20000$ | $\le 20000$ | $\le 26$ |
| $17$ | $\le 100000$ | $= 0$ | $\le 26$ |
| $18$ | $= 0$ | $\le 100000$ | $\le 26$ |
| $19$ | $\le 100000$ | $\le 100000$ | $= 1$ |
| $20$ | $\le 100000$ | $\le 100000$ | $\le 26$ |

对于 $100\%$ 的数据，保证 $0 \le n, m \le 10^5$，$1 \le k \le 26$。

### 【题目注释与题解分析】

> **考点**：不同子序列计数、动态规划转移分析、贪心策略。
>
> **难度**：普及压轴/提高难度（CSP-J T4 难度）。
>
> **解题分析**：
> 1. **经典子序列计数 DP**：
>    * 设 $dp[i]$ 表示前 $i$ 个字符构成的所有不同子序列数量（包含空子序列）。
>    * 若在末尾加入字符 $c$：
>      如果此前从未出现过字符 $c$，则新增的子序列数量恰好为 $dp[i-1]$，因此：
> $$
> dp[i] = 2 \cdot dp[i-1]
> $$
>      如果字符 $c$ 上一次出现的位置是 $last[c]$，则以 $c$ 结尾的重复子序列恰好对应前 $last[c] - 1$ 个字符的所有子序列。因此转移方程为：
> $$
> dp[i] = 2 \cdot dp[i-1] - dp[last[c] - 1]
> $$
> 2. **追加字符的贪心策略**：
>    * 要使加入字符后 $dp[i]$ 尽可能大，就必须让减去的项 $dp[last[c] - 1]$ 尽可能小！
>    * 也就是说，每次应该贪心地追加那个**上一次出现位置最早（即 $last[c]$ 最小）**的字符。
> 3. **算法步骤**：
>    * 首先对初始前缀串 $s$ 执行经典的线性 DP，求出每个位置的 $dp$ 值，并记录 $k$ 个字符最后出现的位置。
>    * 随后进行 $m$ 次贪心扩展：每次从 $k$ 个字符中找到 $last[c]$ 最小的字符（可用小根堆维护这 $k$ 个字符的最新位置，堆内元素仅 $k \le 26$ 个），将其加到末尾并更新 DP 值与该字符的最新位置。
> 4. **复杂度分析**：
>    * 处理前 $n$ 个字符耗时 $\mathcal{O}(n)$。
>    * 追加 $m$ 个字符每次只需在大小为 $k \le 26$ 的堆中取最小并更新，耗时 $\mathcal{O}(m \log k)$。
>    * 整体时间复杂度为 $\mathcal{O}(n + m \log k)$，空间复杂度为 $\mathcal{O}(n + m)$，能在时限内通过全额数据。模运算注意减法防负数取模。
