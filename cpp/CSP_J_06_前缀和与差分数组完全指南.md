# CSP-J 前缀和与差分数组完全指南

## 1. 一维前缀和 (Prefix Sum)
**应用场景**：快速求出一个静态数组任意区间 $[l, r]$ 的元素之和。
**定义**：$S[i] = \sum_{k=1}^{i} A[k]$。
**递推公式**：$S[i] = S[i-1] + A[i]$
**区间和计算**：$Sum(l, r) = S[r] - S[l-1]$

```cpp
vector<int> a(n + 1), s(n + 1, 0);
for (int i = 1; i <= n; ++i) {
    s[i] = s[i-1] + a[i];
}
// 查询区间 [l, r]
int ans = s[r] - s[l-1];
```

## 2. 二维前缀和
用于快速计算矩阵中任意矩形区域的元素和。
**预处理**：$S[i][j] = S[i-1][j] + S[i][j-1] - S[i-1][j-1] + A[i][j]$
**区域和求值**：左上角 $(x_1, y_1)$，右下角 $(x_2, y_2)$ 的矩形和：
$Sum = S[x_2][y_2] - S[x_1-1][y_2] - S[x_2][y_1-1] + S[x_1-1][y_1-1]$

## 3. 差分数组 (Difference Array)
**应用场景**：快速对一个静态数组的某个区间 $[l, r]$ 内所有元素加上或减去一个常数 $v$。
**定义**：$D[i] = A[i] - A[i-1]$ (通常 $D[1] = A[1]$)。
**性质**：差分数组的前缀和等于原数组。即 $A[i] = \sum_{k=1}^{i} D[k]$。

**区间修改**：给区间 $[l, r]$ 加上 $v$：
```cpp
D[l] += v;
D[r + 1] -= v;
```
最后再对 $D$ 求一遍前缀和，即可得到修改后的数组 $A$。
