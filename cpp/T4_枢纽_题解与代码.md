# T4 枢纽 (junction) 题解与完整代码

## 1. 题目重述与建模

### 1.1 问题描述
给定一个包含 $n$ 个节点、$m$ 条无向边的连通无向图，以及两个指定的特殊节点 $a$ 与 $b$（保证 $a \ne b$）。

求满足以下所有条件的无序节点对 $(u, v)$（即 $1 \le u < v \le n$）的数量：
1. $u \ne a$，$u \ne b$；
2. $v \ne a$，$v \ne b$；
3. 从 $u$ 到 $v$ 的**任意一条路径**都必须同时经过 $a$ 和 $b$。

### 1.2 数据规模
- $4 \le n \le 2 \times 10^5$
- $n - 1 \le m \le 5 \times 10^5$
- 保证图连通，可能存在重边。
- 节点数上限为 $2 \times 10^5$，答案最大为 $\binom{n-2}{2} \approx 2 \times 10^{10}$，必须使用 64 位整数（`long long`）。

---

## 2. 解题思路与算法分析

### 2.1 充要条件转化
题目要求：任意一条从 $u$ 到 $v$ 的路径都经过 $a$ 和 $b$。

这等价于：
1. **割点性质 1**：删除节点 $a$ 后，$u$ 与 $v$ 不连通（即所有路径必经 $a$）；
2. **割点性质 2**：删除节点 $b$ 后，$u$ 与 $v$ 不连通（即所有路径必经 $b$）。

同时，如果一条路径同时经过 $a$ 和 $b$，必有先后顺序。若 $u$ 到达 $v$ 必须先经过 $a$ 再经过 $b$：
- 从 $u$ 出发，在不经过 $a$ 的情况下，**无法到达 $b$**；
- 从 $v$ 出发，在不经过 $b$ 的情况下，**无法到达 $a$**。

我们定义两个关键节点集合：
- **集合 $S_a$**：在原图中**删去点 $a$** 后，**无法**到达点 $b$ 的所有非 $a, b$ 节点集合。
  - 也就是说，对于任意 $u \in S_a$，任何从 $u$ 出发的路径要想走向图的其它主体（包括 $b$），都必须通过 $a$。
- **集合 $S_b$**：在原图中**删去点 $b$** 后，**无法**到达点 $a$ 的所有非 $a, b$ 节点集合。
  - 也就是说，对于任意 $v \in S_b$，任何从 $v$ 出发的路径要想走向图的其它主体（包括 $a$），都必须通过 $b$。

### 2.2 集合相交性与独立性分析
- $S_a$ 与 $S_b$ 一定**互不相交**（$S_a \cap S_b = \emptyset$）：
  反证法：若存在节点 $x \in S_a \cap S_b$，则不经 $a$ 无法到达 $b$，且不经 $b$ 无法到达 $a$。然而原图整体连通，若 $x$ 既不能经非 $a$ 路径到达 $b$，又不能经非 $b$ 路径到达 $a$，说明从 $x$ 出发无论如何都无法到达 $\{a, b\}$ 之外的连通块，这与图连通且存在非空其它结构矛盾。
- 对于任意 $u \in S_a, v \in S_b$：
  - 从 $u$ 出发，不经过 $a$ 根本无法连通到 $b$ 所在的连通块，更无法到达 $v$；
  - 同理，不经过 $b$ 无法到达 $u$。
  - 因此从 $u$ 到 $v$ 的任何路径，都必须同时经过 $a$ 和 $b$。

因此，满足条件的二元组 $(u, v)$ 的总数就是：
$$\text{Ans} = |S_a| \times |S_b|$$

### 2.3 算法设计：两次 BFS / DFS
1. **求 $|S_a|$**：
   - 临时标记节点 $a$ 已经被访问（即禁止经过 $a$）；
   - 从节点 $b$ 开始进行 BFS/DFS 遍历；
   - 统计不能被遍历到的节点数量（排除点 $a$ 和点 $b$ 本身），这部分节点的总数就是 $|S_a|$。
2. **求 $|S_b|$**：
   - 临时标记节点 $b$ 已经被访问（即禁止经过 $b$）；
   - 从节点 $a$ 开始进行 BFS/DFS 遍历；
   - 统计不能被遍历到的节点数量（排除点 $a$ 和点 $b$ 本身），这部分节点的总数就是 $|S_b|$。
3. **计算结果**：
   - 输出 $|S_a| \times |S_b|$。

### 2.4 复杂度分析
- **时间复杂度**：建图 $\mathcal{O}(n + m)$，两次 BFS 遍历图的复杂度为 $\mathcal{O}(n + m)$，统计集合大小为 $\mathcal{O}(n)$。总时间复杂度为 $\mathcal{O}(n + m)$。在 $n \le 2 \times 10^5, m \le 5 \times 10^5$ 下可在 0.1 秒内执行完毕。
- **空间复杂度**：邻接表与访问标记数组为 $\mathcal{O}(n + m)$。

## 3. C++ 满分参考代码

```cpp
#include <iostream>
#include <vector>
#include <queue>

using namespace std;

// 广搜统计：在封禁 banned 点的情况下，从 start 点出发能够访问到的非 a, b 节点数
long long bfs(int n, int start, int banned, const vector<vector<int>>& adj, int a, int b) {
    vector<bool> vis(n + 1, false);
    queue<int> q;

    vis[start] = true;
    q.push(start);

    long long reachable_count = 0;

    while (!q.empty()) {
        int u = q.front();
        q.pop();

        if (u != a && u != b) {
            reachable_count++;
        }

        for (int v : adj[u]) {
            if (v == banned || vis[v]) continue;
            vis[v] = true;
            q.push(v);
        }
    }

    // 无法到达的节点数量 = 总非特殊节点数 (n - 2) - 能够访问到的节点数
    long long total_other_nodes = n - 2;
    return total_other_nodes - reachable_count;
}

int main() {
    // 优化 I/O 速度
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, a, b;
    if (!(cin >> n >> m >> a >> b)) return 0;

    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; ++i) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    // 1. 禁用 a，从 b 出发，无法到达的非 a, b 节点数量即为 |S_a|
    long long size_Sa = bfs(n, b, a, adj, a, b);

    // 2. 禁用 b，从 a 出发，无法到达的非 a, b 节点数量即为 |S_b|
    long long size_Sb = bfs(n, a, b, adj, a, b);

    // 3. 乘法原理计算方案数
    long long ans = size_Sa * size_Sb;

    cout << ans << "\n";

    return 0;
}
```

## 4. 边界处理与关键注意点

1. **乘法溢出**：
   - $|S_a|$ 和 $|S_b|$ 均可能接近 $2 \times 10^5$，两者乘积最高可达 $4 \times 10^{10}$，必须使用 `long long` 存储。
2. **重边与自环**：
   - BFS 遍历依靠 `vis` 数组防重，即使存在重边也能保证线性 $\mathcal{O}(n + m)$ 复杂度，无需显式去重。
3. **连通分量计数**：
   - 统计时需剔除特殊节点 $a$ 与 $b$ 本身，非特殊节点总数严格为 $n - 2$。
