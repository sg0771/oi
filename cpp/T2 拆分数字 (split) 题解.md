# T2 拆分数字 (split) 题解

## 1. 题目分析

### 题意简述
给定 $T$ 组询问。每组询问给定两个正整数 $n$ 和 $k$。
判断能否找到恰好 $k$ 个形如 $3^m$（$m$ 为非负整数）的特殊数字，使得它们的和等于 $n$。
即是否存在非负整数序列 $\{a_1, a_2, \dots, a_k\}$ 使得：
$$ n = \sum_{i=1}^k 3^{a_i} $$
如果可以输出 `Yes`，否则输出 `No`。

### 数据范围
- $1 \le k \le n \le 10^{18}$
- $1 \le T \le 10^5$

---

## 2. 解题思路与数学性质

本题的核心是探究将一个大整数 $n$ 拆分成 $k$ 个 $3$ 的非负整数次幂的可行性。

### 性质 1：拆分与合并的步长为 2
考虑基础操作：将一个幂次项 $3^m$（$m \ge 1$）拆分为三个更小的项：
$$ 3^m = 3^{m-1} + 3^{m-1} + 3^{m-1} $$
项数从 $1$ 项变成了 $3$ 项，**净增加 $2$ 项**。
反之，将三个相同的 $3^{m-1}$ 合并为一个 $3^m$，项数**净减少 $2$ 项**。
因此，无论怎样拆分，项数的奇偶性永远不会改变，项数始终保持以步长 $2$ 增减。

### 性质 2：奇偶性守恒
因为对于任意非负整数 $m$，$3^m$ 都是奇数（$3^m \equiv 1 \pmod 2$）。
$k$ 个奇数相加的和为 $n$，其奇偶性必定与 $k$ 相同：
$$ n \equiv k \pmod 2 $$
因此若 $(n - k) \pmod 2 \ne 0$，则绝对不可能拆分，直接判定为 `No`。

### 性质 3：极值范围（最小项数与最大项数）
- **最大项数**：将 $n$ 全部拆解为 $3^0 = 1$，此时项数为 $n$。因此必须满足 $k \le n$。
- **最小项数**：观察 $n$ 的标准三进制表示。
  设 $n$ 的三进制展开式为：
  $$ n = \sum_{i \ge 0} c_i \cdot 3^i \quad (c_i \in \{0, 1, 2\}) $$
  此时三进制各位数字之和 $S_3(n) = \sum c_i$ 即为最少的项数。因为只要某一位项数达到 3，就可以向高位进位合并为 1 项从而减少总项数。在无法继续合并（无任何三个相同幂）的状态下，项数达到理论最小值 $S_3(n)$。

### 结论：充要条件
只要项数处于 $[S_3(n), n]$ 之间，并且奇偶性满足要求，我们总能通过不断将某个 $m \ge 1$ 的项 $3^m$ 拆解为 3 个 $3^{m-1}$，使项数每次严格增加 2，从而覆盖区间内的每一个同奇偶性数值。
综上，满足条件的**充要条件**为：
1. $k \le n$；
2. $k \ge S_3(n)$（$n$ 在三进制下的数位和）；
3. $(n - k) \pmod 2 == 0$。

---

## 3. 复杂度分析

- **时间复杂度**：计算三进制数位和时，因 $n \le 10^{18}$，$\log_3(10^{18}) \approx 38$ 次循环。单组询问耗时仅 $\mathcal{O}(\log_3 n)$，处理 $T = 10^5$ 组数据总操作次数在 $4 \times 10^6$ 级别，耗时约 $0.03\text{s}$。
- **空间复杂度**：仅需若干临时变量，额外空间复杂度为 $\mathcal{O}(1)$。

## 4. 完整代码（附详细注释）

```cpp
#include <iostream>

using namespace std;

// 解决单组测试数据
void solve() {
    long long n, k;
    cin >> n >> k;

    // 条件 1: k 不能大于 n（最多全拆成 3^0=1，共 n 项）
    if (k > n) {
        cout << "No\n";
        return;
    }

    // 条件 2: 奇偶性必须一致（因为 3^m 为奇数，k 个奇数之和奇偶性与 k 相同）
    if ((n - k) % 2 != 0) {
        cout << "No\n";
        return;
    }

    // 计算 n 在三进制表示下的数位之和，即拆分所需的最小项数
    long long temp = n;
    long long min_k = 0;
    while (temp > 0) {
        min_k += (temp % 3);
        temp /= 3;
    }

    // 条件 3: k 必须不小于最少项数 min_k
    if (k >= min_k) {
        cout << "Yes\n";
    } else {
        cout << "No\n";
    }
}

int main() {
    // 快速 I/O
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    if (cin >> T) {
        while (T--) {
            solve();
        }
    }

    return 0;
}
```
