# T3 字符串 (string) 题解与完整代码

## 1. 题目重述与建模

### 1.1 问题描述
给定一个长度为 $n$ 的字符串 $s$，由英文小写字母和字符 `?` 组成。
我们需要将所有的 `?` 替换为小写字母（`a` - `z`），使得替换后的字符串满足：
* 对于任意长度 $\ge 2$ 的连续子串，**没有任何一个小写字母的出现次数严格超过该子串长度的一半**。

求可能的替换方案数，答案对 $998244353$ 取模。

### 1.2 条件等价性转化
设子串长度为 $L$（$L \ge 2$），某个字符的出现次数为 $cnt$。限制条件为：
$$
cnt \le \left\lfloor \frac{L}{2} \right\rfloor
$$
即不能有 $cnt > \frac{L}{2}$。

我们分析最小的可能违规子串长度：
1. **长度 $L = 2$**：
   若连续两个字符相同（形如 $xx$），字符 $x$ 出现了 $2$ 次，而 $\frac{2}{2} = 1$，$2 > 1$。这违反了限制。
   因此：**相邻两字符不能相同**，即对于所有 $i$，满足：
   $$
   s[i] \ne s[i-1]
   $$
2. **长度 $L = 3$**：
   若形如 $xyx$，字符 $x$ 出现了 $2$ 次，而 $\frac{3}{2} = 1.5$，$2 > 1.5$。这也违反了限制。
   因此：**相隔一个位置的两字符不能相同**，即对于所有 $i$，满足：
   $$
   s[i] \ne s[i-2]
   $$

**逆否命题与充分性**：
如果一个字符串对于所有位置都满足 $s[i] \ne s[i-1]$ 且 $s[i] \ne s[i-2]$，那么对于任意长度 $L \ge 4$ 的子串，任意字符在任意连续 3 个位置中至多出现 1 次。此时该字符在长度为 $L$ 的子串中出现次数至多为 $\lceil L/3 \rceil \le \lfloor L/2 \rfloor$（对所有 $L \ge 2$ 均成立）。

**核心结论**：
原题的苛刻限制完全等价于局部条件：
$$
\begin{cases}
s[i] \ne s[i-1] & (i \ge 2) \\
s[i] \ne s[i-2] & (i \ge 3)
\end{cases}
$$
即**任意相邻的三个字符必须两两互不相同**。

## 2. 算法设计与动态规划

由于当前字符 $s[i]$ 的取值只受前两个字符 $s[i-1]$ 和 $s[i-2]$ 的约束，这是一个标准的马尔可夫链 / 线性状态机动态规划。

### 2.1 状态定义
设字符集大小为 $|\Sigma| = 26$。
设 $dp[i][j][k]$ 表示处理到第 $i$ 个字符时，第 $i-1$ 个字符为 $j$、第 $i$ 个字符为 $k$ 的合法方案数（其中 $0 \le j, k < 26$ 且 $j \ne k$）。

### 2.2 状态转移
遍历第 $i+1$ 个字符的所有可能取值 $c \in [0, 25]$：
* 若原字符串 $s[i+1] \ne \text{'?'}$ 且 $c \ne s[i+1] - \text{'a'}$，则该字符不合法，跳过；
* 若 $c = j$ 或 $c = k$（即与前两个字符之一冲突），则跳过；
* 否则进行状态转移：
  $$
  dp[i+1][k][c] = (dp[i+1][k][c] + dp[i][j][k]) \pmod{998244353}
  $$

### 2.3 复杂度与空间优化
* **时间复杂度**：
  状态数为 $n \times 26 \times 26$。每个状态向后转移枚举 $c \in [0, 25]$，总步数为 $n \times 26^3 \approx 5000 \times 17576 \approx 8.7 \times 10^7$ 次基本运算。在 1.0 秒时限内可通过。
  
  *优化观察*：
  注意到 $\sum_{j} dp[i][j][k]$ 是所有以 $k$ 结尾的状态和。转移方程中只需减去 $j = c$ 的项：
  $$
  dp[i+1][k][c] = \left(\sum_{j \ne k} dp[i][j][k]\right) - dp[i][c][k]
  $$
  定义 $sum[k] = \sum_{j} dp[i][j][k]$，则转移可以降至 $\mathcal{O}(26^2)$，总运算次数降为 $5000 \times 676 \approx 3.3 \times 10^6$ 次，速度极快。
* **空间复杂度**：
  滚动数组优化第 $i$ 维，空间复杂度仅为 $\mathcal{O}(26^2)$。

## 3. C++ 满分参考代码

```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

const int MOD = 998244353;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;
    string s;
    cin >> s;

    // 特殊情况：n = 1
    if (n == 1) {
        if (s[0] == '?') cout << 26 << "\n";
        else cout << 1 << "\n";
        return 0;
    }

    // dp[j][k]: 当前字符的前一个为 j，当前字符为 k 的合法方案数
    vector<vector<int>> dp(26, vector<int>(26, 0));

    // 初始化前两个字符
    int start_0 = (s[0] == '?') ? 0 : s[0] - 'a';
    int end_0 = (s[0] == '?') ? 25 : s[0] - 'a';
    int start_1 = (s[1] == '?') ? 0 : s[1] - 'a';
    int end_1 = (s[1] == '?') ? 25 : s[1] - 'a';

    for (int c0 = start_0; c0 <= end_0; ++c0) {
        for (int c1 = start_1; c1 <= end_1; ++c1) {
            if (c0 != c1) {
                dp[c0][c1] = (dp[c0][c1] + 1) % MOD;
            }
        }
    }

    // 逐位递推从第 3 个字符开始 (下标 2 到 n - 1)
    for (int i = 2; i < n; ++i) {
        vector<vector<int>> next_dp(26, vector<int>(26, 0));
        
        // 预处理 sum_k = sum_{j} dp[j][k]
        vector<int> col_sum(26, 0);
        for (int j = 0; j < 26; ++j) {
            for (int k = 0; k < 26; ++k) {
                col_sum[k] = (col_sum[k] + dp[j][k]) % MOD;
            }
        }

        int start_c = (s[i] == '?') ? 0 : s[i] - 'a';
        int end_c = (s[i] == '?') ? 25 : s[i] - 'a';

        for (int k = 0; k < 26; ++k) {
            for (int c = start_c; c <= end_c; ++c) {
                if (c == k) continue; // 当前字符不能与前一个相同
                // next_dp[k][c] = (sum_{j != k, j != c} dp[j][k])
                int ways = (col_sum[k] - dp[c][k] + MOD) % MOD;
                next_dp[k][c] = (next_dp[k][c] + ways) % MOD;
            }
        }
        dp = move(next_dp);
    }

    // 统计最终答案
    int ans = 0;
    for (int j = 0; j < 26; ++j) {
        for (int k = 0; k < 26; ++k) {
            ans = (ans + dp[j][k]) % MOD;
        }
    }

    cout << ans << "\n";
    return 0;
}
```

## 4. 边界处理与关键注意点

1. **小数据特判**：
   * $n = 1$ 时无相邻限制，需单独输出 $26$（若为 `?`）或 $1$。
2. **初始化无解**：
   * 若输入形如 `aa?` 或 `a?a`，初始两个字符相同则 `dp` 全为 0，程序能自适应输出 `0`。
3. **模运算安全**：
   * 在使用前缀和相减时需加 `MOD` 防止负数：`(col_sum[k] - dp[c][k] + MOD) % MOD`。
