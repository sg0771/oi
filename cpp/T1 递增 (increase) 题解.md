# T1 递增 (increase) 题解

## 1. 题目分析

### 题意简述
给定一个长度为 $n$ 的正整数序列 $w$。定义一个序列是“好的”，当且仅当：
- 首项 $a_1 = 1$；
- 之后的每一项都满足 $a_i = a_{i-1} + 1$。

即好的序列形式为：$1, 2, 3, \dots, m$。
我们需要从原序列 $w$ 中找出一个最长的好的**子序列**（不要求在原数组中连续），并输出其最大长度。

### 数据范围
- 对于 $60\%$ 的数据：$1 \le n \le 20$。
- 对于 $100\%$ 的数据：$1 \le n \le 10^5$，$1 \le w_i \le n$。

---

## 2. 解题思路

本题要求在原数组中抽取子序列 $1, 2, 3, \dots, m$。

### 贪心策略
设我们当前已经成功匹配到了数字 $len$（初始时 $len = 0$，期望匹配的目标数字为 $target = 1$）。
当我们从左至右扫描序列 $w$ 时：
- 如果遇到元素 $w[i] == target$，我们立即将它接在当前好子序列的末尾，并将期待匹配的目标值更新为 $target = target + 1$。
- 如果 $w[i] \ne target$，则继续向后扫描。

### 贪心正确性证明
假设存在一个合法的好子序列长度为 $m$，它在原数组中的下标位置为 $p_1 < p_2 < \dots < p_m$，且满足 $w[p_k] = k$。
按照贪心策略，我们为每一个数字 $k$ 选取的都是它在原序列中出现的**尽可能靠前**的位置 $q_k$：
1. 对于数字 $1$，$q_1$ 是第一个等于 $1$ 的元素位置，显然 $q_1 \le p_1$。
2. 假设对于第 $k-1$ 个数字，有 $q_{k-1} \le p_{k-1}$。
3. 因为在原解中 $p_k > p_{k-1} \ge q_{k-1}$ 且 $w[p_k] = k$，说明在位置 $q_{k-1}$ 之后必定存在至少一个等于 $k$ 的元素。贪心策略所选取的第一个大于 $q_{k-1}$ 且值为 $k$ 的位置 $q_k$ 一定满足 $q_k \le p_k$。
4. 由数学归纳法可知，贪心策略在匹配任意长度时所消耗的前缀范围都是最小的，因此贪心得到的匹配长度一定是最优的。

---

## 3. 复杂度分析

- **时间复杂度**：只需对输入序列进行一次单向线性遍历，时间复杂度为 $\mathcal{O}(n)$。对于 $n = 10^5$，运行耗时约 $2\text{ms}$，远优于时限。
- **空间复杂度**：只需维护当前期待匹配的值，可以实现在线边读边处理，额外空间复杂度为 $\mathcal{O}(1)$。

---

## 4. 完整代码（附详细注释）

```cpp
#include <iostream>

using namespace std;

int main() {
    // 提高输入输出效率
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;

    int target = 1; // 当前期待匹配的下一个目标数字，从 1 开始

    for (int i = 0; i < n; ++i) {
        int x;
        cin >> x;
        // 如果当前扫描到的数恰好是期望的目标数字
        if (x == target) {
            target++; // 匹配成功，转向下一个更大的数字
        }
    }

    // 最长好子序列的长度即为已经成功匹配的数字总数 (target - 1)
    cout << target - 1 << "\n";

    return 0;
}
```
