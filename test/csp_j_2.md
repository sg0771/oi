## T1 魔法石 (magic)

### 【题目描述】

在一个远古的数字王国里，勇敢的探险者 Luke 正在寻找传说中的魔法石。古老的预言提到，石头的属性与三个神秘正整数 $x, y, z$ 密切相关。

为了获得魔法石，Luke 必须找到三个正整数 $a, b, c$，使得以下三个条件同时得到满足：

1. $x = \max(a, b)$
2. $y = \max(b, c)$
3. $z = \max(a, c)$

请帮助 Luke 解开谜题。在规定的时间内找出任意一组满足条件的正整数 $a, b, c$。

### 【输入格式】

输入文件为 `magic.in`。

共一行，包含三个正整数 $x, y, z$，两两之间用一个空格隔开。

### 【输出格式】

输出文件为 `magic.out`。

* 若不存在合法的正整数三元组 $(a, b, c)$，输出一行字符串 `NO`；
* 若存在合法解，在第一行输出 `YES`，第二行输出任意一组满足条件的有效正整数 $a, b, c$（两两之间以空格分隔）。

### 【输入输出样例 1】

**magic.in**
```
3 2 3
```

**magic.out**
```
YES
3 2 1
```

### 【输入输出样例 2】

**magic.in**
```
1 1000000000 1000000000
```

**magic.out**
```
YES
1 1 1000000000
```

### 【输入输出样例 3】

**magic.in**
```
10 30 20
```

**magic.out**
```
NO
```

### 【数据规模与约定】

* 对于 $60\%$ 的测试数据，保证 $1 \le x, y, z \le 10^9$。
* 对于 $100\%$ 的测试数据，保证 $1 \le x, y, z \le 10^{18}$。

### 【题目注释与题解分析】

> **考点**：逻辑推导、条件分支、极值性质。  
> **难度**：入门级（CSP-J T1 难度）。  
> **解题分析**：  
> 观察等式：
> $$x = \max(a, b)$$
> $$y = \max(b, c)$$
> $$z = \max(a, c)$$
> 假设 $a, b, c$ 中最大的数为 $M$。根据抽屉原理，$a, b, c$ 中至少有两个数等于 $M$，或者三个两两配对的最大值中，最大的那个值必须出现至少两次。  
> 也就是说，将 $x, y, z$ 从小到大排序后，记为 $p \le q \le r$，必须满足：
> $$q = r$$
> 若 $q \ne r$，则一定不存在合法解，直接输出 `NO`。  
> 若 $q = r$，则构造方案如下：
> $$a = p, \quad b = p, \quad c = r$$
> 此时三对最大值分别为 $\max(p, p) = p$、$\max(p, r) = r$、$\max(p, r) = r$，恰好匹配给定的 $p, r, r$。输出 `YES` 并输出对应数值即可。  
> **注意**：数据范围达到 $10^{18}$，在 C++ 中必须使用 `long long`。

## T2 狗是啥呀 (dog)

### 【题目描述】

在神秘的地狱深处，生活着一种拥有极强生命力的犬类生物，传说它最初长了 $x$ 个头。

一位勇士为了斩杀这奇怪的生物，来到地狱一探究竟。勇士携带了 $n$ 种武器，每种武器可以无限次使用。对于第 $i$ 种武器：
* 每次使用可以击毙该生物 $d_i$ 个头；
* 若该生物尚未被消灭，它会吸收能量并立即重新长出 $h_i$ 个头。

当且仅当生物当前的头部数量小于等于 $0$ 时，它会被彻底击败，且**不会**再长出新的头。

请你计算：勇士最少需要使用多少次武器才能彻底消灭这只生物？若永远无法击败，则输出 `-1`。

### 【输入格式】

输入文件为 `dog.in`。

第一行包含两个整数 $n, x$，分别表示武器的种类数和生物初始的头部数量。  
接下来 $n$ 行，每行包含两个整数 $d_i, h_i$，分别表示第 $i$ 种武器单次斩落的头部数量与之后重生的头部数量。

### 【输出格式】

输出文件为 `dog.out`。

输出共一行，包含一个整数，表示最少使用武器的次数。若无法将其消灭，则输出 `-1`。

### 【输入输出样例 1】

**dog.in**
```
3 10
6 3
8 2
1 4
```

**dog.out**
```
2
```

**【样例 1 解释】**  
先使用一次第 1 种武器，剩余头数为：
$$10 - 6 + 3 = 7$$
再使用一次第 2 种武器，击毙 $8$ 个头后：
$$7 - 8 = -1 \le 0$$
生物被消灭，共使用 $2$ 次武器。

### 【输入输出样例 2】

**dog.in**
```
4 10
4 1
3 2
2 6
1 100
```

**dog.out**
```
3
```

### 【输入输出样例 3】

**dog.in**
```
2 15
10 11
14 100
```

**dog.out**
```
-1
```

### 【数据规模与约定】

* 对于 $20\%$ 的测试数据，保证 $n = 1$，$x \le 20$。
* 对于 $40\%$ 的测试数据，保证 $n \le 2$，$x \le 20$。
* 对于 $60\%$ 的测试数据，保证 $n \le 10$。
* 对于 $100\%$ 的测试数据，保证 $1 \le n \le 100$，$1 \le x, d_i, h_i \le 10^9$。

### 【题目注释与题解分析】

> **考点**：贪心、数学上取整。  
> **难度**：普及下位（CSP-J T2 难度）。  
> **解题分析**：  
> 1. **单次秒杀判断**：遍历所有武器，令 $D_{\max} = \max_{1 \le i \le n} d_i$。若 $D_{\max} \ge x$，则只需一击即可消灭该生物，最少次数为 $1$。  
> 2. **持续削减分析**：如果一次无法消灭，则除了最后一击以外，每一次攻击实际净减少的头数为 $d_i - h_i$。  
>    定义最大净伤害为：
>    $$\Delta_{\max} = \max_{1 \le i \le n} (d_i - h_i)$$
>    若 $\Delta_{\max} \le 0$，且 $D_{\max} < x$，说明怪物的头数不可能持续下降，永远无法击败，直接输出 `-1`。  
> 3. **最优贪心策略**：
>    * 最后一击使用单次打击伤害最高的武器（伤害为 $D_{\max}$）；
>    * 前面的所有攻击均使用净削减效率最高的武器（每次净伤害为 $\Delta_{\max}$）。  
>    前置攻击需要至少打掉的血量为 $x - D_{\max}$，所需前置次数为：
>    $$\text{steps} = \left\lceil \frac{x - D_{\max}}{\Delta_{\max}} \right\rceil = \left\lfloor \frac{x - D_{\max} + \Delta_{\max} - 1}{\Delta_{\max}} \right\rfloor$$
>    总次数即为 $\text{steps} + 1$。  
> **复杂度**：只需线性扫描一遍武器数组，时间复杂度 $\mathcal{O}(n)$，空间复杂度 $\mathcal{O}(1)$。需要注意使用 64 位整数避免溢出。

## T3 字符串 (string)

### 【题目描述】

小 E 得到了一个长度为 $n$ 的字符串 $s$，该字符串由部分小写英文字母和一些问号 `?` 组成。

他的任务是通过将每个问号替换为任意一个小写字母（`a`~`z`），构造出一个合法字符串。合法字符串的规则如下：

* 在替换完成后的整个字符串中，对于**任意**一个长度大于等于 $2$ 的连续子串，都**不能**出现某一个小写字母的出现次数**严格超过**该子串长度的一半。

请你计算一共有多少种可能的替换方式。由于答案可能很大，请输出其对 $998244353$ 取模后的结果。

### 【输入格式】

输入文件为 `string.in`。

第一行包含一个整数 $n$，表示字符串的长度。  
第二行包含一个长度为 $n$ 的字符串 $s$。

### 【输出格式】

输出文件为 `string.out`。

输出共一行，包含一个整数，表示合法替换方案数对 $998244353$ 取模后的结果。

### 【输入输出样例 1】

**string.in**
```
3
a?b
```

**string.out**
```
24
```

**【样例 1 解释】**  
问号不能替换为 `a`（否则子串 `aa` 中 `a` 出现 $2$ 次超过一半），也不能替换为 `b`（否则子串 `bb` 中 `b` 超过一半）。因此除了 `a` 和 `b` 以外的 $24$ 个小写字母均合法。

### 【输入输出样例 2】

**string.in**
```
3
a?a
```

**string.out**
```
0
```

**【样例 2 解释】**  
对于子串 $s[1 \dots 3]$，无论中间填什么字母，`a` 出现了 $2$ 次，而总长度为 $3$，$2 > 3 / 2$，因此不存在任何合法方案。

### 【数据规模与约定】

* 对于 $30\%$ 的测试数据，保证 $n \le 8$。
* 对于 $50\%$ 的测试数据，保证 $n \le 200$。
* 对于另 $10\%$ 的测试数据，保证原字符串中不存在问号。
* 对于 $100\%$ 的测试数据，保证 $1 \le n \le 5000$。

### 【题目注释与题解分析】

> **考点**：鸽巢原理、状态压缩/线性动态规划、前缀和优化。  
> **难度**：普及上位 / 提高组水平（CSP-J T3 难度）。  
> **关键性质转化**：  
> 题目要求：对任意长度 $L \ge 2$ 的子串，任意字符的频数不能超过 $\lfloor L / 2 \rfloor$。  
> 考虑短子串的情况：
> 1. 若存在长度为 $2$ 的子串 $s[i \dots i+1]$ 使得两个字符相同，则该字符占比为 $2 / 2 > 1/2$，不合法。因此**相邻两字符不能相同**：
>    $$s[i] \ne s[i-1]$$
> 2. 若存在长度为 $3$ 的子串 $s[i-1 \dots i+1]$ 形式为 $aba$（即隔一个字符相同），则字符 $a$ 出现 $2$ 次，$2 > 3/2$，不合法。因此**相隔一个位置的字符也不能相同**：
>    $$s[i] \ne s[i-2]$$
> 
> **充要性验证**：只要任意相邻两个字符不同，且任意相隔一个位置的字符不同（即对于任意 $i$，均满足 $s[i] \ne s[i-1]$ 且 $s[i] \ne s[i-2]$），那么任何长度更长的子串中同一字符的出现间隔至少为 $3$，其在长度为 $L$ 的子串中最多出现 $\lceil L / 3 \rceil$ 次。因为对于所有 $L \ge 2$，都有：
> $$\left\lceil \frac{L}{3} \right\rceil \le \left\lfloor \frac{L}{2} \right\rfloor$$
> 所以该局部限制是全局合法的**充分必要条件**！  
> 
> **状态转移**：  
> 每一个位置 $i$ 的字符选择仅依赖于前两个位置 $s[i-1]$ 和 $s[i-2]$。  
> 设状态 $dp[i][c_1][c_2]$ 表示填到第 $i$ 位，第 $i-1$ 位字符为 $c_1$，第 $i$ 位字符为 $c_2$ 的方案数。  
> 字符集大小为 $|\Sigma| = 26$。由于只关心“前一个”和“前前一个”，可以直接维护：
> $$dp[i][c]$$
> 表示第 $i$ 位填字符 $c$ 的方案数。结合包含排斥，维护前一步的总和、以及前两步的冲突项，可以在 $\mathcal{O}(n \cdot 26)$ 的时间与空间复杂度内完成状态转移，完全可以通过 $n \le 5000$。

## T4 傻鹿尖塔 (spire)

### 【题目描述】

傻鹿沉迷于一款名叫《傻鹿尖塔》的电脑游戏。

在游戏中，傻鹿会先后面对 $n$ 个敌人（按顺序从第 $1$ 个到第 $n$ 个）。它见到的第 $i$ 个敌人会对傻鹿造成 $a_i$ 点伤害。若在受到某次伤害后傻鹿的生命值**小于等于零**，则傻鹿会在这次战斗中被击败且游戏结束；否则傻鹿成功击败该敌人并进入下一场战斗。

除此之外，傻鹿初始拥有 $k$ 瓶强力药水。每瓶强力药水能够让傻鹿在与某一名敌人的战斗中**免受任何伤害**并直接击败该敌人。

傻鹿想知道：在最优策略下，它从第一个敌人出发，最多能按顺序连续击败多少个敌人？

### 【输入格式】

输入文件为 `spire.in`。

第一行包含一个正整数 $T$，表示共有 $T$ 组测试数据。  
每组测试数据包含两行：
第一行包含三个整数 $n, m, k$，分别表示敌人的总数量、傻鹿的初始生命值以及强力药水的数量。  
第二行包含 $n$ 个正整数 $a_1, a_2, \dots, a_n$，其中第 $i$ 个正整数表示第 $i$ 个敌人对傻鹿造成的伤害值。

### 【输出格式】

输出文件为 `spire.out`。

对于每组数据输出一行一个整数，表示傻鹿最多能够击败的敌人数量。

### 【输入输出样例 1】

**spire.in**
```
3
5 10 1
3 4 5 2 7
3 7 0
2 3 4
10 20 3
6 12 9 4 10 1 3 4 2 1
```

**spire.out**
```
4
2
8
```

**【样例 1 解释】**  
* **第 1 组数据**：生命值为 $10$，有 $1$ 瓶药水。
  * 第 1 场：承受伤害 $3$，剩余生命 $7$；
  * 第 2 场：承受伤害 $4$，剩余生命 $3$；
  * 第 3 场：使用药水免除伤害 $5$，剩余生命仍为 $3$；
  * 第 4 场：承受伤害 $2$，剩余生命 $1$；
  * 第 5 场：伤害为 $7$，剩余生命无法承受。最多击败 $4$ 个敌人。
* **第 2 组数据**：无药水。击败前两个敌人共受伤害 $5 < 7$；第三个敌人伤害 $4$，受到后生命值非正，故最多击败 $2$ 个。

### 【数据规模与约定】

对于 $100\%$ 的测试数据，保证 $1 \le T \le 5$，$1 \le n \le 10^5$，$1 \le m, a_i \le 10^5$，$0 \le k \le n$。

| 测试点编号 | $n$ 的规模 |
| :--- | :--- |
| $1 \sim 2$ | $n \le 20$ |
| $3 \sim 6$ | $n \le 2000$ |
| $7 \sim 10$ | $n \le 10^5$ |

### 【题目注释与题解分析】

> **考点**：贪心算法、反悔贪心、优先队列（小根堆 / 大根堆）、二分答案。  
> **难度**：普及压轴（CSP-J T4 难度）。  
> **解题分析**：  
> 题目要求按顺序挑战敌人，问最多能连续走多远。  
> 
> **解法一：反悔贪心（推荐最优解）**  
> 遍历敌人 $i = 1, 2, \dots, n$：
> 1. 先假设当前敌人造成的伤害 $a_i$ 全部由生命值扣除，即 $m \gets m - a_i$，并将 $a_i$ 放入大根堆中。
> 2. 如果此时剩余生命值 $m \le 0$：
>    * 若手中还有药水（$k > 0$ 且堆非空），贪心地把药水用在**目前为止遇到过的伤害最大**的那次攻击上：弹出堆顶元素 $x$，$m \gets m + x$，$k \gets k - 1$。
>    * 若药水已耗尽（$k = 0$）且仍然有 $m \le 0$，说明当前第 $i$ 个敌人无论如何都无法战胜，答案即为 $i - 1$，直接结束。
> 3. 若顺利遍历完所有 $n$ 个敌人，则答案为 $n$。  
> 
> **复杂度分析**：  
> 维护大根堆只需 $\mathcal{O}(n \log n)$ 的时间，单组测试数据在 $10^5$ 规模下耗时约 $0.05\text{ s}$，总时间复杂度为 $\mathcal{O}(T \cdot n \log n)$，空间复杂度 $\mathcal{O}(n)$，可在时限内稳定通过。
