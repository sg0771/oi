# T4 傻鹿尖塔 (spire) 题解与完整代码

## 1. 题目重述与建模

### 1.1 问题描述
傻鹿有初始生命值 $m$ 和 $k$ 瓶强力药水。它将按固定顺序先后面对 $n$ 个敌人，第 $i$ 个敌人造成的伤害为 $a_i$。
* 战斗规则：傻鹿按顺序打怪。对于每个敌人，傻鹿可以选择**硬抗**（消耗生命值 $a_i$），或者**使用 1 瓶药水**（不消耗生命值直接战胜该敌人）。
* 失败判定：若在造成伤害后傻鹿的生命值 $\le 0$，则傻鹿会在这次战斗中被击败，战斗序列立刻终止。
* 目标：在保证傻鹿在面对的所有已击败敌人战斗后生命值均 $> 0$ 的前提下，最多能按顺序击败多少个敌人。

---

## 2. 解题思路与算法分析

### 2.1 规则性质与贪心反悔机制
面对按顺序出现的敌人，如果傻鹿能够战胜前 $p$ 个敌人，则必须满足：
1. 在这 $p$ 个敌人中，最多选择 $k$ 个敌人使用药水（免伤）；
2. 其余 $p - (\text{使用药水数})$ 个敌人造成的总伤害严格小于 $m$（即 $\sum a_i < m$）。

直观上，敌人是按序出现的。若能在前 $i$ 个敌人中存活，为了能走得更远，我们希望**当前扣除的生命值尽量少**。
因此，对于前 $i$ 个敌人中我们决定免伤的那些敌人，应当优先挑选**伤害值 $a$ 最大的敌人**来使用药水。

### 2.2 反悔贪心策略
我们维护：
* 一个**大根堆（优先队列）**，保存所有**通过消耗生命值击败**的敌人伤害；
* 当前生命值 $\text{cur\_hp} = m$；
* 剩余药水数 $\text{rem\_k} = k$。

从第 $1$ 个敌人扫描到第 $n$ 个敌人：
1. **优先硬抗**：
   先尝试不用药水战胜敌人 $i$：
   * $\text{cur\_hp} \leftarrow \text{cur\_hp} - a_i$；
   * 将 $a_i$ 压入大根堆中。
2. **生命值耗尽时反悔（贪心补药）**：
   若 $\text{cur\_hp} \le 0$：
   * 此时生命值不足，必须使用药水来抵消某一次高额伤害；
   * 若此时手中还有药水（$\text{rem\_k} > 0$）：
     从堆顶取出至今为止造成**最大伤害**的那次战斗 $top$，把药水用在它身上，将这部分生命值加回：
     $$
     \text{cur\_hp} \leftarrow \text{cur\_hp} + top
     $$
     并消耗一瓶药水：$\text{rem\_k} \leftarrow \text{rem\_k} - 1$。
   * 若手中已无药水（$\text{rem\_k} == 0$），说明当前敌人无论如何无法战胜，且无法继续前进，直接**终止循环**。
3. 成功击败当前敌人，答案计数加 1。

## 3. 复杂度与正确性证明

* **正确性说明**：
  若存在某种使用药水的方案可以通过前 $p$ 个敌人，那么在该前缀中将药水分配给伤害最大的 $k$ 个敌人一定是最优的（使剩余生命值最大化）。反悔贪心始终在生命不足的第一时刻，将已受伤害中最大的那一次转化为“药水免疫”，等价于维护了前缀最小伤害和。
* **复杂度分析**：
  * 每个敌人的伤害最多入堆一次、出堆一次。堆的大小不超过 $n$。
  * 单次操作堆复杂度为 $\mathcal{O}(\log n)$。
  * 单组数据时间复杂度为 $\mathcal{O}(n \log n)$。
  * 对于 $T \le 5, n \le 10^5$，总计算量约 $5 \times 10^5 \log_2(10^5) \approx 8 \times 10^6$ 次，在 0.1 秒内即可完成。
* **空间复杂度**：
  优先队列最大占用 $\mathcal{O}(n)$ 空间。

## 4. C++ 满分参考代码

```cpp
#include <iostream>
#include <vector>
#include <queue>

using namespace std;

void solve() {
    int n;
    long long m;
    int k;
    if (!(cin >> n >> m >> k)) return;

    vector<long long> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
    }

    priority_queue<long long> max_heap; // 记录硬抗过的伤害
    long long cur_hp = m;
    int rem_k = k;
    int defeated_count = 0;

    for (int i = 0; i < n; ++i) {
        cur_hp -= a[i];
        max_heap.push(a[i]);

        // 生命值不足，尝试反悔
        while (cur_hp <= 0 && rem_k > 0 && !max_heap.empty()) {
            cur_hp += max_heap.top();
            max_heap.pop();
            rem_k--;
        }

        // 若使用完药水后生命值仍 <= 0，无法战胜当前敌人
        if (cur_hp <= 0) {
            break;
        }

        defeated_count++;
    }

    cout << defeated_count << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    if (cin >> T) {
        while (T--) {
            solve();
        }
    }
    return 0;
}
```

## 5. 边界处理与关键注意点

1. **生命值归零判定**：
   * 题面明确说明：“生命值小于等于零，则傻鹿被击败”，即 $\text{cur\_hp} \le 0$ 时死亡，必须保持 $\text{cur\_hp} > 0$。
2. **反悔循环 `while`**：
   * 即使一次反悔加回最大伤害，如果单次敌人伤害极高（如初始生命很小，但遇到巨额伤害且需要连喝多瓶药），`while` 能够连续反悔，逻辑完备。
3. **数据类型**：
   * 伤害与生命值可能累加，计算变量均使用 `long long` 保证安全。
