# T3 选家具 (furniture) 题解与完整代码

## 1. 题目重述与建模

### 1.1 问题描述
小 D 需要在 $n$ 家店铺中采购：
- $a$ 台家电
- $b$ 件家具
- $c$ 个装饰

满足 $n = a + b + c$。每家店铺限定最多购买一种物品一件，第 $i$ 家店铺中购买家电的花费为 $a_i$，家具的花费为 $b_i$，装饰的花费为 $c_i$。求满足采购需求的**最小总花费**。

### 1.2 数据规模
- 对于所有数据：$n, a, b, c \le 5000$，$a_i, b_i, c_i \le 10^9$，$n = a + b + c$。
- 最大总花费可能达到 $5000 \times 10^9 = 5 \times 10^{12}$，计算过程必须使用 64 位整数（`long long`）。

---

## 2. 解题思路与算法分析

### 2.1 转化基准（Cost Offset）
由于每家店铺必须恰好购买一件物品，我们可以先假定所有 $n$ 家店铺都购买**装饰**，基础花费为：
$$\text{Base} = \sum_{i=1}^n c_i$$

在此基础上：
- 若店铺 $i$ 改为购买**家电**，代价增量为 $\Delta A_i = a_i - c_i$；
- 若店铺 $i$ 改为购买**家具**，代价增量为 $\Delta B_i = b_i - c_i$；
- 若保持购买装饰，增量为 $0$。

问题等价于：在 $n$ 个二元组 $(\Delta A_i, \Delta B_i)$ 中，选出大小为 $a$ 的集合 $S_A$ 和大小为 $b$ 的集合 $S_B$（$S_A \cap S_B = \emptyset$），最小化：
$$\sum_{i \in S_A} \Delta A_i + \sum_{j \in S_B} \Delta B_j$$

### 2.2 贪心性质与微扰分析
假设已经确定了哪些店铺被选中购买家电或家具（即确定了集合 $S_A \cup S_B$）。对于其中任意两家店铺 $i$ 和 $j$，若 $i \in S_A$ 且 $j \in S_B$，其代价和为 $\Delta A_i + \Delta B_j$。

若将两者交换（$j \in S_A$ 且 $i \in S_B$），代价和为 $\Delta A_j + \Delta B_i$。

为了使原方案更优或等价，需满足：
$$\Delta A_i + \Delta B_j \le \Delta A_j + \Delta B_i \iff \Delta A_i - \Delta B_i \le \Delta A_j - \Delta B_j$$

代入定义：
$$(a_i - c_i) - (b_i - c_i) \le (a_j - c_j) - (b_j - c_j) \iff a_i - b_i \le a_j - b_j$$

**结论**：
将所有店铺按照 $a_i - b_i$ 从小到大排序。排完序后，必然存在一个最优分界点 $k$（$a \le k \le n - b$）：
- 在前 $k$ 家店铺中选出 $a$ 家买家电（其余买装饰）；
- 在后 $n - k$ 家店铺中选出 $b$ 家买家具（其余买装饰）。

### 2.3 前后缀堆维护
1. **前缀维护（Pre）**：
   从左向右遍历前缀 $1 \dots i$，使用维护最小值的**大根堆**（大小维持为 $a$），维护前 $i$ 个店铺中最小的 $a$ 个 $\Delta A$ 之和，记为 $pre[i]$。
2. **后缀维护（Suf）**：
   从右向左遍历后缀 $i \dots n$，使用大根堆（大小维持为 $b$），维护后 $n - i + 1$ 个店铺中最小的 $b$ 个 $\Delta B$ 之和，记为 $suf[i]$。
3. **枚举分界点**：
   枚举分界点 $k$，总最小增量为：
   $$\min_k \{ pre[k] + suf[k + 1] \}$$
   最终最小总花费即为 $\text{Base} + \min(pre[k] + suf[k + 1])$。

### 2.4 复杂度分析
- **时间复杂度**：排序 $\mathcal{O}(n \log n)$，前后缀堆维护 $\mathcal{O}(n \log n)$，枚举分界点 $\mathcal{O}(n)$。总时间复杂度为 $\mathcal{O}(n \log n)$。
- **空间复杂度**：$\mathcal{O}(n)$。

## 3. C++ 满分参考代码

```cpp
#include <iostream>
#include <vector>
#include <numeric>
#include <algorithm>
#include <queue>

using namespace std;

struct Store {
    long long a, b, c;
    long long diff; // a - b
};

int main() {
    // 优化标准 I/O 读取速度
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, a, b, c;
    if (!(cin >> n >> a >> b >> c)) return 0;

    vector<Store> stores(n);
    long long base_cost = 0;
    for (int i = 0; i < n; ++i) {
        cin >> stores[i].a >> stores[i].b >> stores[i].c;
        stores[i].diff = stores[i].a - stores[i].b;
        base_cost += stores[i].c;
    }

    // 1. 按照 a_i - b_i 从小到大排序
    sort(stores.begin(), stores.end(), [](const Store& x, const Store& y) {
        return x.diff < y.diff;
    });

    // 2. 前缀：前 i 个店铺中选 a 个 (a_k - c_k) 的最小值
    vector<long long> pre(n, 0);
    if (a > 0) {
        priority_queue<long long> max_heap;
        long long cur_sum = 0;
        for (int i = 0; i < n; ++i) {
            long long delta_a = stores[i].a - stores[i].c;
            cur_sum += delta_a;
            max_heap.push(delta_a);

            if ((int)max_heap.size() > a) {
                cur_sum -= max_heap.top();
                max_heap.pop();
            }

            if ((int)max_heap.size() == a) {
                pre[i] = cur_sum;
            }
        }
    }

    // 3. 后缀：后 i 个店铺中选 b 个 (b_k - c_k) 的最小值
    vector<long long> suf(n + 1, 0);
    if (b > 0) {
        priority_queue<long long> max_heap;
        long long cur_sum = 0;
        for (int i = n - 1; i >= 0; --i) {
            long long delta_b = stores[i].b - stores[i].c;
            cur_sum += delta_b;
            max_heap.push(delta_b);

            if ((int)max_heap.size() > b) {
                cur_sum -= max_heap.top();
                max_heap.pop();
            }

            if ((int)max_heap.size() == b) {
                suf[i] = cur_sum;
            }
        }
    }

    // 4. 枚举分界点 k
    long long min_delta = 4e18; // 设置足够大的初始无穷大值
    int start_k = (a == 0) ? -1 : a - 1;
    int end_k = (b == 0) ? n - 1 : n - 1 - b;

    for (int k = start_k; k <= end_k; ++k) {
        long long cost_a = (k >= 0) ? pre[k] : 0;
        long long cost_b = (k + 1 < n) ? suf[k + 1] : 0;
        min_delta = min(min_delta, cost_a + cost_b);
    }

    cout << base_cost + min_delta << "\n";
    return 0;
}
```

## 4. 边界处理与关键注意点

1. **64 位整数防溢出**：
   - 最大花费可能超出 $2^{31}-1$，前缀和、后缀和、差值变量均需使用 `long long`。
2. **极端数量为 0 的处理**：
   - 当 $a = 0$ 时，无需挑选买家电的店铺，分界点可取到 $k = -1$；
   - 当 $b = 0$ 时，无需挑选买家具的店铺，分界点可取到 $k = n - 1$。
   - 代码中通过条件判断兼容了 $a = 0$ 或 $b = 0$ 的边界情况。
