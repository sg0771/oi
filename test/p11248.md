# 洛谷 P11248 [GESP202409 七级] 矩阵移动

这是一道典型的**三维网格动态规划（DP）**题目。

---

## 1. 题意简述

* 给定一个 $n \times m$ 的矩阵，每个格子包含字符 `0`、`1` 或 `?`。
* 你可以先将矩阵中**至多 $x$ 个** `?` 替换成 `1`（其余 `?` 相当于 `0`）。
* 随后从左上角 $(1, 1)$ 出发，每次只能**向右**或**向下**移动一格，直到抵达右下角 $(n, m)$。
* 求路径上最多能经过多少个 `1`。
* **数据范围**：$t$ 组测试数据，$1 \le n, m \le 500$，$0 \le x \le 300$，且所有测试数据的 $\sum (n \times m) \le 2.5 \times 10^5$。

---

## 2. 解题思路

由于只能向右或向下走，路径是一条无后效性的单向路径。如果我们在路径上把某个 `?` 当作 `1` 来计分，就等价于在修改矩阵时把这个 `?` 变成了 `1`。

### 状态定义
设 $dp[i][j][k]$ 表示从 $(1, 1)$ 走到 $(i, j)$，且路径上**恰好使用了 $k$ 次将 `?` 变为 `1` 的机会**时，能收集到的 `1` 的最大数量（为防止不合法状态误转移，初始化为 $-\infty$）。

### 状态转移
到达 $(i, j)$ 只能从上方 $(i-1, j)$ 或左方 $(i, j-1)$ 转移过来，分类讨论当前格 $s[i][j]$ 的字符：

1. **$s[i][j] = \text{'1'}$**：不消耗修改次数，得分 $+1$：
   $$dp[i][j][k] = \max(dp[i-1][j][k], dp[i][j-1][k]) + 1$$
2. **$s[i][j] = \text{'0'}$**：不消耗修改次数，得分 $+0$：
   $$dp[i][j][k] = \max(dp[i-1][j][k], dp[i][j-1][k])$$
3. **$s[i][j] = \text{'?'}$**：有两种选择：
   * **不修改**（当作 `0`）：
     $$dp[i][j][k] = \max(dp[i-1][j][k], dp[i][j-1][k])$$
   * **修改为 `1`**（当 $k \ge 1$ 时消耗 $1$ 次机会，得分 $+1$）：
     $$dp[i][j][k] = \max\Big(dp[i][j][k],\ \max(dp[i-1][j][k-1], dp[i][j-1][k-1]) + 1\Big)$$

### 边界与答案
* **起点 $(1, 1)$ 初始化**：
  * 若 $s[1][1] = \text{'1'}$：$dp[1][1][0] = 1$。
  * 若 $s[1][1] = \text{'0'}$：$dp[1][1][0] = 0$。
  * 若 $s[1][1] = \text{'?'}$：$dp[1][1][0] = 0$，且若 $x \ge 1$ 则 $dp[1][1][1] = 1$。
* **最终答案**：在 $(n, m)$ 处枚举所有合法的使用次数 $k \in [0, \min(x, n+m-1)]$，取最大值 $\max dp[n][m][k]$。

### 空间与复杂度优化（关键坑点）
* **时间复杂度**：单组 $O(n \cdot m \cdot x)$，总运算次数约 $2.5 \times 10^5 \times 300 = 7.5 \times 10^7$，在 C++ 中开启 `O2` 或优化循环顺序即可轻松通过。
* **空间优化（滚动数组）**：
  * 直接开 `int dp[505][505][305]` 约占 $311\text{ MB}$ 内存，且每组多测清空整张表极易超时（TLE）。
  * 注意到第 $i$ 行只依赖第 $i-1$ 行，只需开两行滚动数组 `dp[2][505][305]`，空间降至 **1.2 MB** 以内，且局部清空速度极快。

## 3. C++ 参考代码（滚动数组优化）

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <cstring>

using namespace std;

const int INF = 1e9;
int dp[2][505][305];
char grid[505][505];

void solve() {
    int n, m, x;
    if (!(cin >> n >> m >> x)) return;

    // 路径总步数只有 n + m - 1，超过这个数量的修改次数没有意义
    int max_k = min(x, n + m - 1);

    for (int i = 1; i <= n; ++i) {
        cin >> (grid[i] + 1);
    }

    // 初始化第 0 行和第 1 行为负无穷
    for (int r = 0; r < 2; ++r) {
        for (int j = 0; j <= m; ++j) {
            for (int k = 0; k <= max_k; ++k) {
                dp[r][j][k] = -INF;
            }
        }
    }

    // 初始化起点 (1, 1)
    if (grid[1][1] == '1') {
        dp[1][1][0] = 1;
    } else if (grid[1][1] == '0') {
        dp[1][1][0] = 0;
    } else { // '?'
        dp[1][1][0] = 0;
        if (max_k >= 1) dp[1][1][1] = 1;
    }

    for (int i = 1; i <= n; ++i) {
        int cur = i & 1;
        int pre = cur ^ 1;

        // 换行时清空当前行（第 1 行除外，因为 (1,1) 已初始化）
        if (i > 1) {
            for (int j = 0; j <= m; ++j) {
                for (int k = 0; k <= max_k; ++k) {
                    dp[cur][j][k] = -INF;
                }
            }
        }

        for (int j = 1; j <= m; ++j) {
            if (i == 1 && j == 1) continue;

            for (int k = 0; k <= max_k; ++k) {
                int best_prev = max(dp[pre][j][k], dp[cur][j - 1][k]);

                if (grid[i][j] == '1') {
                    if (best_prev != -INF) {
                        dp[cur][j][k] = best_prev + 1;
                    }
                } else if (grid[i][j] == '0') {
                    dp[cur][j][k] = best_prev;
                } else { // '?'
                    // 1. 不修改当前 '?'
                    dp[cur][j][k] = best_prev;
                    // 2. 消耗一次机会将当前 '?' 改为 '1'
                    if (k >= 1) {
                        int best_prev_k1 = max(dp[pre][j][k - 1], dp[cur][j - 1][k - 1]);
                        if (best_prev_k1 != -INF) {
                            dp[cur][j][k] = max(dp[cur][j][k], best_prev_k1 + 1);
                        }
                    }
                }
            }
        }
    }

    int ans = 0;
    int last_row = n & 1;
    for (int k = 0; k <= max_k; ++k) {
        ans = max(ans, dp[last_row][m][k]);
    }
    cout << ans << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    if (cin >> t) {
        while (t--) {
            solve();
        }
    }
    return 0;
}
```

## 4. 常见易错点提醒

1. **起点 `(1, 1)` 是 `?` 的情况**：若 $x = 0$，不能强行访问或转移 $dp[1][1][1]$，否则会越界或算出错误答案。
2. **多组数据清空**：注意不要直接用 `memset(dp, -0x3f, sizeof(dp))` 对整个最大数组在每次 $t$ 循环中清空（若 $t$ 很大且 $n, m$ 很小，整体 `memset` 会导致 TLE），按当前测试用例的实际 $m$ 和 $\min(x, n+m-1)$ 局部清空即可。
3. **$x = 0$ 的边界**：若代码里只把 `dp[n][m][x]` 当作答案，当矩阵里 `?` 的数量少于 $x$ 或 $x=0$ 时可能漏解，应在 $k \in [0, \min(x, n+m-1)]$ 范围内取最大值。
