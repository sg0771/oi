# CSP-J 第二轮（复赛）全题官方题解与满分代码

## 题型总览与备考策略

CSP-J 普及组复赛的题目梯次分明：
* **T1 扑克牌 (`poker`)**：字符串处理 / `std::set` 去重统计，考查基本语法与集合计数。
* **T2 地图探险 (`explore`)**：网格图模拟与方向转向，考查方向向量数组与网格越界/障碍物判定。
* **T3 小木棍 (`sticks`)**：数学规律与贪心构造（或完全背包 DP），重点在于高位不能为 $0$ 以及余数规律分析。
* **T4 接龙 (`chain`)**：分层图动态规划（分步 BFS / 滚动数组 DP），考查多轮转移与去重转移优化。

## T1 扑克牌 (poker)

### 1. 题意简述
小 P 有一副 $n$ 张牌的扑克牌（不含大小王）。一副完整的扑克牌共 $52$ 张（$4$ 种花色，每种花色 $13$ 种点数）。现在已知小 P 手中有 $n$ 张牌，有些可能重复。请问小 P 至少还需要借多少张牌，才能凑成一副完整的扑克牌？

* 数据范围：$1 \le n \le 52$，每张牌由两个字符表示（花色 + 点数）。

### 2. 解题思路
* **去重统计**：
  一副完整扑克牌的总张数为 $52$。手牌中重复的牌没有多余贡献，只需统计**互不相同**的牌有多少种即可。
* **实现方式**：
  使用 `std::set<string>` 插入所有输入的牌名。集合的大小 `st.size()` 即为已有不同牌的数目。
  最终答案即为：$52 - \text{st.size()}$。
* 时间复杂度：$O(n \log n)$，空间复杂度：$O(n)$。

### 3. 满分参考代码（带注释）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 快速输入输出
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // 考场文件重定向
    freopen("poker.in", "r", stdin);
    freopen("poker.out", "w", stdout);

    int n;
    if (!(cin >> n)) return 0;

    set<string> unique_cards;
    for (int i = 0; i < n; ++i) {
        string card;
        cin >> card;
        unique_cards.insert(card); // 自动去重
    }

    // 还需要凑齐的张数 = 52 - 不同的牌数
    int ans = 52 - (int)unique_cards.size();
    cout << ans << "\n";

    return 0;
}
```

## T2 地图探险 (explore)

### 1. 题意简述
在 $n \times m$ 的网格地图中，有些格子为空地 `.`，有些格子为障碍 `x`。探险家初始位于 $(x_0, y_0)$，面向方向 $d_0$（$0$: 右, $1$: 下, $2$: 左, $3$: 上）。
探险家将进行 $k$ 步移动。每一步规则如下：
* 考察前方格子 $(x', y')$：
  * 若 $(x', y')$ 在地图内且是空地，则走到该格，方向不变；
  * 否则，留在原地，面向方向顺时针转动 $90^\circ$（即 $d = (d + 1) \bmod 4$）。
求探险家在 $k$ 步过程中一共访问过多少个**不同的格子**（包括起始点）。

* 数据范围：多组数据 $T \le 5$，$1 \le n, m \le 1000$，$1 \le k \le 10^6$。

### 2. 解题思路
* **模拟 + 方向向量**：
  定义方向数组：`dx = {0, 1, 0, -1}`，`dy = {1, 0, -1, 0}`，恰好对应编号 $0, 1, 2, 3$。
* **访问标记**：
  开设 `vis[x][y]` 数组记录是否访问过，初始化 `vis[x_0][y_0] = true`，初始不同访问格数 `ans = 1`。
  按照题目规则循环 $k$ 次：
  * 计算前方坐标 $nx = x + dx[d], ny = y + dy[d]$；
  * 检查是否越界以及是否为障碍物：
    * 若合法：$x = nx, y = ny$；若此前未访问过，则标记并令 `ans++`；
    * 若不合法：$d = (d + 1) \bmod 4$。
* 时间复杂度：$O(T \cdot (k + nm))$，空间复杂度：$O(nm)$。

### 3. 满分参考代码（带注释）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 方向定义：0: 东/右, 1: 南/下, 2: 西/左, 3: 北/上
const int dx[] = {0, 1, 0, -1};
const int dy[] = {1, 0, -1, 0};

void solve() {
    int n, m, k;
    cin >> n >> m >> k;
    int x, y, d;
    cin >> x >> y >> d;

    vector<string> g(n + 1);
    for (int i = 1; i <= n; ++i) {
        string s;
        cin >> s;
        g[i] = " " + s; // 下标转为 1~m
    }

    // vis 记录每个格子是否被访问过
    vector<vector<bool>> vis(n + 1, vector<bool>(m + 1, false));
    vis[x][y] = true;
    int ans = 1;

    for (int step = 0; step < k; ++step) {
        int nx = x + dx[d];
        int ny = y + dy[d];

        // 检查前方格子是否在界内且为空地
        if (nx >= 1 && nx <= n && ny >= 1 && ny <= m && g[nx][ny] == '.') {
            x = nx;
            y = ny;
            if (!vis[x][y]) {
                vis[x][y] = true;
                ans++;
            }
        } else {
            // 撞墙或出界，原地顺时针旋转 90 度
            d = (d + 1) % 4;
        }
    }

    cout << ans << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    freopen("explore.in", "r", stdin);
    freopen("explore.out", "w", stdout);

    int T;
    if (cin >> T) {
        while (T--) solve();
    }
    return 0;
}
```

## T3 小木棍 (sticks)

### 1. 题意简述
使用 $n$ 根火柴棒拼出一个**正整数**（不能有前导 $0$），每根火柴棒必须全部用完。每个数字所需火柴数如下：
* `0`: 6 根, `1`: 2 根, `2`: 5 根, `3`: 5 根, `4`: 4 根
* `5`: 5 根, `6`: 6 根, `7`: 3 根, `8`: 7 根, `9`: 6 根
求能拼出的**最小正整数**；若无解则输出 `-1`。

* 数据范围：$T \le 50$，$1 \le n \le 10^5$。

### 2. 解题思路
* **贪心观察**：
  1. **位数最少原则**：位数越少，数值越小。数字 `8` 消耗最多的火柴（7 根），因此为了让位数尽可能少，除了前几位调整外，后续位应尽量全填 `8`。
  2. **高位数字最小原则**：确定总位数后，高位放置的数字越小越优。注意：首位不能为 `0`。
* **模 7 分类讨论**：
  根据 $n \bmod 7$ 的余数，决定最前面的几个数字：
  * $n < 2$：无法组成任何合法数字，输出 `-1`；
  * $n = 2$：`1`
  * $n = 3$：`7`
  * $n = 4$：`4`
  * $n = 5$：`2`
  * $n = 6$：`6`
  * $n = 7$：`8`
  * 对于 $n > 7$，设 $k = \lfloor n / 7 \rfloor$：
    * $n \bmod 7 = 0$：全由 $k$ 个 `8` 组成；
    * $n \bmod 7 = 1$：借一个 7，用 8 根火柴拼出首位最小的两位数 `10`，后跟 $k - 1$ 个 `8`；
    * $n \bmod 7 = 2$：首位用 2 根火柴拼 `1`，后跟 $k$ 个 `8`；
    * $n \bmod 7 = 3$：$n = 10$ 时为 `22`；$n > 10$ 借两个 7 用 17 根拼成 `200`，或直接前置 `22`、`200` 等极小前缀；
    * $n \bmod 7 = 4$：借一个 7 用 11 根拼成 `20`，后跟 $k - 1$ 个 `8`；
    * $n \bmod 7 = 5$：首位用 5 根火柴拼 `2`，后跟 $k$ 个 `8`；
    * $n \bmod 7 = 6$：首位用 6 根火柴拼 `6`，后跟 $k$ 个 `8`。
* 时间复杂度：单组测试数据 $O(n / 7)$，总复杂度 $O(T \cdot n)$。

### 3. 满分参考代码（带注释）

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int n;
    cin >> n;

    // 特殊小数据特判
    if (n < 2) {
        cout << -1 << "\n";
        return;
    }
    if (n == 2) { cout << 1 << "\n"; return; }
    if (n == 3) { cout << 7 << "\n"; return; }
    if (n == 4) { cout << 4 << "\n"; return; }
    if (n == 5) { cout << 2 << "\n"; return; }
    if (n == 6) { cout << 6 << "\n"; return; }

    int k = n / 7;
    int rem = n % 7;

    // 按照余数确定最佳前缀，余下的火柴全拼 '8'
    if (rem == 0) {
        for (int i = 0; i < k; ++i) cout << '8';
    } else if (rem == 1) {
        cout << "10";
        for (int i = 0; i < k - 1; ++i) cout << '8';
    } else if (rem == 2) {
        cout << '1';
        for (int i = 0; i < k; ++i) cout << '8';
    } else if (rem == 3) {
        if (n == 10) {
            cout << "22";
        } else {
            cout << "200";
            for (int i = 0; i < k - 2; ++i) cout << '8';
        }
    } else if (rem == 4) {
        cout << "20";
        for (int i = 0; i < k - 1; ++i) cout << '8';
    } else if (rem == 5) {
        cout << '2';
        for (int i = 0; i < k; ++i) cout << '8';
    } else if (rem == 6) {
        cout << '6';
        for (int i = 0; i < k; ++i) cout << '8';
    }
    cout << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    freopen("sticks.in", "r", stdin);
    freopen("sticks.out", "w", stdout);

    int T;
    if (cin >> T) {
        while (T--) solve();
    }
    return 0;
}
```

## T4 接龙 (chain)

### 1. 题意简述
有 $n$ 个人玩词语接龙。第 $i$ 个人持有一个长度为 $l_i$ 的序列 $S_i$。游戏共进行若干轮：
1. 第 1 轮由某人开始，选出其序列中以数字 $1$ 开头、长度在 $[2, k]$ 之间的连续子序列；
2. 随后的每一轮接龙：必须换一个人（不能由上一轮同一个人连续接龙），选择其序列中以**上一轮子序列末尾数字**开头、长度在 $[2, k]$ 之间的连续子序列。
给定 $q$ 次询问：能否在第 $r$ 轮恰好以数字 $c$ 结尾？

* 数据范围：$T \le 5$，$\sum l_i \le 2 \times 10^5$，$r \le 100$，$q \le 10^5$。

### 2. 解题思路
* **分层 BFS / 动态规划（DP）**：
  设 $dp[t][x]$ 表示第 $t$ 轮是否能以数字 $x$ 结尾。
  * **约束条件**：不能由同一个人连续接两轮。
  * **状态设计**：如果 $dp[t][x]$ 仅记录 `bool`，无法保证下一轮选不同的人。因此需记录：
    * 能够贡献该结尾数字的序列来源编号 `from_person`。
    * 若有 $\ge 2$ 个不同的人都能使第 $t$ 轮以 $x$ 结尾，则后续所有人都能无条件接龙（记为标记 $-1$）。
* **区间滑动优化**：
  若第 $t-1$ 轮以数字 $v$ 结尾，在第 $i$ 个序列中遇到 $S_{i, j} = v$（且来源不为 $i$），则该点往后长度在 $[2, k]$ 范围内的所有位置都可以作为第 $t$ 轮的合法结尾。
  利用滑动窗口（维护最近合法的起点位置），可以做到对序列单次扫描完成转移，避免暴力遍历区间。
* 时间复杂度：$O(\max(r) \cdot \sum l_i + q)$，可在时限内轻松通过。

### 3. 满分参考代码（带注释）

```cpp
#include <bits/stdc++.h>
using namespace std;

static const int MAXV = 200005;

// match_player[x]：在当前轮能以 x 结尾的玩家编号；若有多个不同玩家则为 -1，无则为 0
int cur_match[MAXV];
int nxt_match[MAXV];

void solve() {
    int n, k, q;
    cin >> n >> k >> q;

    vector<vector<int>> s(n + 1);
    int max_val = 0;
    for (int i = 1; i <= n; ++i) {
        int l;
        cin >> l;
        s[i].resize(l);
        for (int j = 0; j < l; ++j) {
            cin >> s[i][j];
            max_val = max(max_val, s[i][j]);
        }
    }

    // 存储询问并按轮数处理
    struct Query {
        int r, c, id;
    };
    vector<Query> queries(q);
    int max_r = 0;
    for (int i = 0; i < q; ++i) {
        cin >> queries[i].r >> queries[i].c;
        queries[i].id = i;
        max_r = max(max_r, queries[i].r);
    }

    // ans[r][c] 记录第 r 轮能否以 c 结尾
    vector<vector<bool>> ans_round(max_r + 1, vector<bool>(max_val + 1, false));

    // 初始化第 0 轮：相当于只有数字 1 可以作为首轮起点
    memset(cur_match, 0, sizeof(int) * (max_val + 1));
    cur_match[1] = -1; // -1 表示任意玩家都可以接 1

    for (int r = 1; r <= max_r; ++r) {
        memset(nxt_match, 0, sizeof(int) * (max_val + 1));

        // 遍历所有玩家的序列进行转移
        for (int i = 1; i <= n; ++i) {
            int len = s[i].size();
            int last_valid_idx = -1e9; // 最近一个可作为起点的下标

            for (int j = 0; j < len; ++j) {
                int val = s[i][j];

                // 检查当前元素能否作为这一轮子序列的终点
                if (j - last_valid_idx + 1 <= k && j - last_valid_idx + 1 >= 2) {
                    if (nxt_match[val] == 0) {
                        nxt_match[val] = i;
                    } else if (nxt_match[val] != i) {
                        nxt_match[val] = -1; // 两个以上不同玩家均可达到
                    }
                }

                // 检查当前元素能否作为这一轮接龙的起点（来自上一轮且不是玩家 i 自己）
                if (cur_match[val] != 0 && cur_match[val] != i) {
                    last_valid_idx = j;
                }
            }
        }

        // 记录本轮所有可达数字
        for (int v = 1; v <= max_val; ++v) {
            if (nxt_match[v] != 0) {
                ans_round[r][v] = true;
            }
            cur_match[v] = nxt_match[v];
        }
    }

    // 输出每个询问的答案
    for (int i = 0; i < q; ++i) {
        int r = queries[i].r;
        int c = queries[i].c;
        if (c <= max_val && ans_round[r][c]) {
            cout << 1 << "\n";
        } else {
            cout << 0 << "\n";
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    freopen("chain.in", "r", stdin);
    freopen("chain.out", "w", stdout);

    int T;
    if (cin >> T) {
        while (T--) solve();
    }
    return 0;
}
```

## 考场拿分口诀与避坑指南

1. **审清题目与文件 IO**：
   * 严格核对 `freopen` 的文件名，包括大小写（如 `poker.in` / `poker.out`）。
   * 普及组千万不要在调试完毕后忘记取消注释 `freopen`。
2. **T1 / T2 追求稳与快**：
   * T1、T2 属于模拟与语法基础题，保证在 40 分钟内完成，并用极限样例测试越界与边界情况。
3. **T3 贪心优先手玩规律**：
   * 类似数字拼接问题，先从小规模用爆搜打出 $1 \sim 30$ 的表，再找出模 7 的周期规律，不要盲目凭空猜测。
4. **T4 抓牢阶段 DP 与前缀信息**：
   * 面对多轮博弈/接龙，先确认“阶段”（轮数 $r$），再用单调滑动窗口剔除多余重叠遍历，即可轻松稳夺一等奖。
