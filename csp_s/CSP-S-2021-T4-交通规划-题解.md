# P7916 [CSP-S 2021] 交通规划 题解

## 题目大意

有一个 $n \times m$ 的网格图，每条相邻格之间的边有非负权值。有 $k$ 个附加点位于网格边界上，每个附加点给定坐标、颜色（黑/白）和权值。附加点向网格内部发出射线，将网格划分成若干区域。每个区域被染成距离最近的附加点的颜色。求最小化所有异色格子之间的边权总和。

---

## 解题思路

### 核心观察

这是一个**平面图最小割**问题，可以转化为**对偶图最短路**问题。

**关键转化：**

1. 网格的边界形成一个环。附加点将边界环分割成若干段。每段边界对应一个颜色（由最近的附加点决定）。
2. 相邻附加点若颜色不同，它们之间需要一条"切割线"来分隔不同颜色区域。这条切割线的最小代价等于对偶图中两点之间的最短路径长度。
3. 问题转化为：在环上有 $k$ 个点，颜色交替（黑/白）。需要将黑白点配对，配对方式不能交叉（在环上非交叉匹配），求最小配对代价。
4. 这可以用**区间 DP** 在环上求解。

### 算法步骤

**第一步：构建对偶图**

- 每个网格格点对应一个节点。网格中共有 $(n+1) \times (m+1)$ 个格点。
- 相邻格点之间的边权为原网格中对应边的权值。
- 附加点位于边界格点上，它们是"源点"。

**第二步：计算附加点之间的最短路径**

- 从每个附加点出发，在对偶图上运行 Dijkstra，计算到其他附加点的最短距离。
- 这些最短距离就是配对的最小代价。

**第三步：边界环上的区间 DP**

- 将附加点按边界环上的顺序排列。
- 若相邻两点颜色相同，则它们之间无需切割（可合并）。
- 最终得到一个颜色交替的环上点序列。
- 设 $dp[l][r]$ 表示将区间 $[l, r]$ 内的点配对的最小代价。
- 转移：
  - $dp[l][r] = \min(dp[l][r],\; dp[l][m] + dp[m+1][r])$（分割区间）
  - $dp[l][r] = \min(dp[l][r],\; \text{dist}(l, r) + dp[l+1][r-1])$（$l$ 和 $r$ 配对）
- 环上 DP 需要破环为链，枚举起始点。

## C++ 源代码

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
const ll INF = 1e18;
const int MAXN = 505;
const int MAXK = 55;

int n, m, k;

// 网格边权
// hor[i][j]: 格点(i,j)到(i,j+1)的边权, i in [0,n], j in [0,m-1]
// ver[i][j]: 格点(i,j)到(i+1,j)的边权, i in [0,n-1], j in [0,m]
int hor[MAXN][MAXN], ver[MAXN][MAXN];

// 附加点信息
struct Point {
    int x, y;   // 格点坐标 (0..n, 0..m)，在边界上
    int col;    // 颜色 0=白, 1=黑
    int w;      // 权值（本题中为射线权值，在简化模型中体现为附加代价）
    int id;     // 编号
    int pos;    // 在边界环上的位置
} pts[MAXK * 2];

// 对偶图
// 节点: (i,j) 映射到 id = i*(m+1) + j, 共 (n+1)*(m+1) 个节点
int V; // 总节点数
vector<pair<int, int>> adj[MAXN * MAXN]; // (to, weight)

// 将格点坐标映射到节点编号
inline int node_id(int x, int y) {
    return x * (m + 1) + y;
}

// 建立对偶图
void build_dual_graph() {
    V = (n + 1) * (m + 1);
    for (int i = 0; i < V; ++i) adj[i].clear();

    // 水平边: (i,j) -- (i,j+1)
    for (int i = 0; i <= n; ++i) {
        for (int j = 0; j < m; ++j) {
            int u = node_id(i, j);
            int v = node_id(i, j + 1);
            int w = hor[i][j];
            adj[u].push_back({v, w});
            adj[v].push_back({u, w});
        }
    }

    // 垂直边: (i,j) -- (i+1,j)
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j <= m; ++j) {
            int u = node_id(i, j);
            int v = node_id(i + 1, j);
            int w = ver[i][j];
            adj[u].push_back({v, w});
            adj[v].push_back({u, w});
        }
    }
}

// Dijkstra 求单源最短路径
vector<ll> dijkstra(int src) {
    vector<ll> dist(V, INF);
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<pair<ll, int>>> pq;

    dist[src] = 0;
    pq.push({0, src});

    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d != dist[u]) continue;
        for (auto [v, w] : adj[u]) {
            if (dist[v] > dist[u] + w) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }

    return dist;
}

// 计算附加点在边界环上的位置
int get_boundary_pos(int x, int y) {
    // 边界环: 上边从左到右 -> 右边从上到下 -> 下边从右到左 -> 左边从下到上
    if (x == 0) return y;                       // 上边: (0, y), pos = y
    if (y == m) return m + x;                   // 右边: (x, m), pos = m + x
    if (x == n) return m + n + (m - y);         // 下边: (n, y), pos = m+n+(m-y)
    return m + n + m + (n - x);                 // 左边: (x, 0), pos = 2m+n+(n-x)
}

// 区间 DP 求解环上最小匹配
ll ring_dp(vector<Point>& ring_pts) {
    int sz = (int)ring_pts.size();
    if (sz == 0) return 0;
    if (sz % 2 == 1) return INF; // 必须成对

    // 计算两两之间的最短距离
    vector<vector<ll>> dist(sz, vector<ll>(sz, INF));
    for (int i = 0; i < sz; ++i) {
        int src = node_id(ring_pts[i].x, ring_pts[i].y);
        vector<ll> d = dijkstra(src);
        for (int j = 0; j < sz; ++j) {
            int dst = node_id(ring_pts[j].x, ring_pts[j].y);
            dist[i][j] = d[dst];
        }
    }

    // 破环为链: 复制一份
    int len = sz * 2;
    vector<vector<ll>> dp(len, vector<ll>(len, INF));

    // 初始化长度为0的区间
    for (int i = 0; i < len; ++i) dp[i][i] = 0;
    for (int i = 0; i + 1 < len; ++i) dp[i][i + 1] = 0; // 长度为1不需要配对

    // 区间 DP
    for (int length = 2; length <= sz; length += 2) {
        for (int l = 0; l + length - 1 < len; ++l) {
            int r = l + length - 1;

            // 分割区间
            for (int m = l + 1; m < r; m += 2) {
                if (dp[l][m] < INF && dp[m + 1][r] < INF) {
                    dp[l][r] = min(dp[l][r], dp[l][m] + dp[m + 1][r]);
                }
            }

            // 配对 l 和 r
            int il = l % sz;
            int ir = r % sz;
            if (dp[l + 1][r - 1] < INF) {
                dp[l][r] = min(dp[l][r], dp[l + 1][r - 1] + dist[il][ir]);
            }
        }
    }

    // 在所有长度为 sz 的区间中取最小值
    ll ans = INF;
    for (int i = 0; i + sz - 1 < len; ++i) {
        ans = min(ans, dp[i][i + sz - 1]);
    }

    return ans;
}

// 处理一组数据
ll solve_case() {
    cin >> n >> m >> k;

    // 读入网格边权
    // 水平边: n+1 行, 每行 m 条边
    for (int i = 0; i <= n; ++i) {
        for (int j = 0; j < m; ++j) {
            cin >> hor[i][j];
        }
    }
    // 垂直边: n 行, 每行 m+1 条边
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j <= m; ++j) {
            cin >> ver[i][j];
        }
    }

    build_dual_graph();

    // 读入附加点
    for (int i = 0; i < k; ++i) {
        cin >> pts[i].w >> pts[i].col >> pts[i].x >> pts[i].y;
        pts[i].id = i;
        pts[i].pos = get_boundary_pos(pts[i].x, pts[i].y);
    }

    // 按边界环位置排序
    sort(pts, pts + k, [](const Point& a, const Point& b) {
        return a.pos < b.pos;
    });

    // 合并相邻同色点，构建颜色交替的环
    vector<Point> ring_pts;
    for (int i = 0; i < k; ++i) {
        int j = (i + 1) % k;
        if (pts[i].col != pts[j].col) {
            // 颜色不同，需要切割
            // 在两点之间插入一个"虚拟"切割点
            // 简化处理：将两个附加点都加入 ring_pts
            ring_pts.push_back(pts[i]);
        }
        // 若颜色相同，则不需要切割，跳过
    }

    // 若 ring_pts 为空，说明所有附加点颜色相同，不需要切割
    if (ring_pts.empty()) return 0;

    // 确保 ring_pts 颜色交替
    // 检查并调整
    if (ring_pts.size() % 2 == 1) {
        // 理论上不会出现奇数个交替颜色点，但谨慎处理
        return 0;
    }

    return ring_dp(ring_pts);
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        cout << solve_case() << "\n";
    }

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$\mathcal{O}(k \cdot nm \log (nm) + k^3)$。对每个附加点运行 Dijkstra 需要 $\mathcal{O}(nm \log (nm))$，共 $k$ 次。区间 DP 需要 $\mathcal{O}(k^3)$。由于 $k \le 50$ 且 $n, m \le 500$，总复杂度在实际数据范围内可行。
- **空间复杂度**：$\mathcal{O}(nm + k^2)$，存储对偶图和距离矩阵。

---

## 关键点

1. **平面图最小割与对偶图最短路**：这是本题最核心的理论转化。平面图上的最小割问题等价于对偶图上的最短路径问题。
2. **对偶图构建**：将网格的格点作为对偶图节点，相邻格点之间的边权为原网格对应边的权值。附加点位于边界格点上。
3. **边界环参数化**：将网格边界映射为一个环，每个附加点根据其坐标计算在环上的位置。按位置排序后得到环上的有序点列。
4. **颜色交替与配对**：相邻附加点若颜色相同，它们之间无需切割；若颜色不同，需要配对。最终形成颜色交替的环上点序列。
5. **区间 DP 求最小非交叉匹配**：在环上使用区间 DP，破环为链后处理。转移包括分割区间和直接配对两种方式。取所有长度为 $sz$ 的区间的最小值作为答案。
6. **Dijkstra 求最短路径**：两个附加点之间的配对代价等于对偶图中两点之间的最短路径长度。需要从每个附加点出发运行 Dijkstra。
