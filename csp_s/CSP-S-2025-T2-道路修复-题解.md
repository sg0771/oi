# CSP-S 2025 T2 道路修复 / road（洛谷 P14362）题解

## 一、题目大意

C 国交通系统由 $n$ 座城市和 $m$ 条双向道路构成，任意两座城市都能通过若干条道路相互到达。一次地震后所有道路被破坏，修复第 $i$ 条道路需要 $w_i$ 的费用。

另外有 $k$ 个乡镇可选做城市化改造：改造第 $j$ 个乡镇花费 $c_j$；改造后可以在该乡镇与第 $i$ 座城市之间新建道路，费用为 $a_{j,i}$。乡镇可以**任意选择改造，也可以一个都不改造**。

目标：以最小总费用让原有的 $n$ 座城市两两连通。

## 二、输入输出格式

### 输入格式

- 第一行三个非负整数 $n, m, k$；
- 接下来 $m$ 行，每行 $u_i, v_i, w_i$，表示一条道路；
- 接下来 $k$ 行，每行 $n+1$ 个非负整数 $c_j, a_{j,1}, a_{j,2}, \ldots, a_{j,n}$。

### 输出格式

一行一个非负整数，表示最小总费用。

## 三、样例

### 输入 #1

```text
4 4 2
1 4 6
2 3 7
4 2 5
4 3 4
1 1 8 2 4
100 1 3 2 4
```

### 输出 #1

```text
13
```

### 样例解释

修复第 3、4 条道路（$5+4$），改造第 1 个乡镇（$1$），并新建它与城市 1、3 之间的道路（$1+2$），总费用 $5+4+1+1+2=13$。可以证明不存在更小的方案。

## 四、数据范围

- $1 \le n \le 10^4$，$1 \le m \le 10^6$，$0 \le k \le 10$；
- $0 \le w_i, c_j, a_{j,i} \le 10^9$；
- 保证任意两座城市能通过原有道路相互到达。

## 五、核心思路

### 5.1 关键观察一：城市子图只保留 MST 的 $n-1$ 条边

固定一个乡镇选择方案 $S$ 后，问题变成：在"城市点 + 被选乡镇点"构成的图上求最小生成树。设 `mst` 为**只用原有道路**求出的城市最小生成森林（由于城市图连通，它就是一棵包含 $n-1$ 条边的生成树）。

**结论：** 把城市 MST 的每个连通块缩成一个点后，任何不在 `mst` 里的道路都变成了自环，永远不会被最小生成树选中。因此对每个子集 $S$，只需要考虑"`mst` 的 $n-1$ 条边 + 被选乡镇各自的 $n$ 条新边"，跑 Kruskal 即可。

### 5.2 关键观察二：答案 = 所有子集方案的最小值

记 $G_S$ 为「$n$ 个城市 + $S$ 中乡镇」构成的图（边 = 道路 + $S$ 中乡镇的星形边）。有：

$$\text{答案} = \min_{S \subseteq \{1..k\}} \left( \sum_{j \in S} c_j + \mathrm{MST}(G_S) \right)$$

理由：任何让城市连通的方案都可以看作一棵以「城市 + 实际用到（度数 $\ge 1$）的乡镇」为点集的生成树，其费用不小于对应子集的 $\mathrm{MST}(G_S)$；反过来任意 $\mathrm{MST}(G_S)$ 本身就连通了所有城市，是一个合法方案。

### 5.3 枚举 + 全局排序

$k \le 10$，子集只有 $2^k \le 1024$ 个。做法：

1. 对 $m$ 条道路按 $w$ 排序，Kruskal 求出城市 MST（$n-1$ 条边），记作 `mst`；
2. 把所有 `mst` 边和**全部** $k \times n$ 条乡镇边放进同一个全局数组（乡镇边打上所属乡镇的标记），按权值排一次序；
3. 枚举子集 $S$：
   - 先把 $\sum_{j\in S} c_j$ 计入当前费用 $cur$（若 $cur$ 已 $\ge$ 当前最优解则剪枝）；
   - 沿全局有序数组做 Kruskal，遇到「乡镇不在 $S$ 中」的边直接跳过；
   - 连通 $n+|S|$ 个点需要 $n+|S|-1$ 条边，加满即停。

### 5.4 时间复杂度

- 道路排序：$O(m\log m)$；
- 全局边表排序：$O((n + kn)\log(n+kn))$；
- 枚举子集：每个子集 $O(n + kn)$（且通常提前终止），总共 $O(2^k(n+kn)) \approx 1.1\times 10^8$ 次轻量操作，可通过。

## 六、正确性说明

**引理 1（MST 边够用）**：城市 MST 之外的任何道路，其两个端点在城市 MST 中同属一个连通块；把 MST 边收缩后它成为自环，故任意子集的 MST 中不会出现它。

**引理 2（子集枚举不漏解）**：对固定子集 $S$，城市连通方案的最小费用恰为 $\mathrm{MST}(G_S)$：

- $\mathrm{MST}(G_S)$ 连通所有城市，是合法方案；
- 任意最优方案可删成一颗以「城市 $\cup$ 实际使用乡镇」为点集的生成树，费用 $\ge \mathrm{MST}(G_S)$。

再对外层取 $\min$，即可得到全局最优。

## 七、参考代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

struct Edge {
    int u, v, tag;  // tag=0 表示原道路，tag=j 表示乡镇 j 的边
    ll w;
};

struct DSU {
    vector<int> f;
    DSU(int n) : f(n + 1) { iota(f.begin(), f.end(), 0); }
    int find(int x) { return f[x] == x ? x : f[x] = find(f[x]); }
    bool unite(int x, int y) {
        x = find(x);
        y = find(y);
        if (x == y) return false;
        f[x] = y;
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, k;
    cin >> n >> m >> k;
    vector<Edge> roads(m);
    for (int i = 0; i < m; i++)
        cin >> roads[i].u >> roads[i].v >> roads[i].w;

    vector<ll> c(k);
    vector<vector<ll>> a(k, vector<ll>(n + 1));
    for (int j = 0; j < k; j++) {
        cin >> c[j];
        for (int i = 1; i <= n; i++) cin >> a[j][i];
    }

    // 1) 城市子图的最小生成树
    sort(roads.begin(), roads.end(),
         [](const Edge& x, const Edge& y) { return x.w < y.w; });
    DSU dsu(n + k + 1);
    vector<Edge> all;
    all.reserve(n - 1 + k * n);
    for (const Edge& e : roads) {
        if (dsu.unite(e.u, e.v)) {
            all.push_back({e.u, e.v, 0, e.w});
        }
    }
    // 2) 所有乡镇边放进全局边表（枚举子集时跳过未选乡镇的边）
    for (int j = 0; j < k; j++)
        for (int i = 1; i <= n; i++)
            all.push_back({n + j + 1, i, j + 1, a[j][i]});

    sort(all.begin(), all.end(),
         [](const Edge& x, const Edge& y) { return x.w < y.w; });

    ll ans = LLONG_MAX;
    // 3) 枚举乡镇子集
    for (int S = 0; S < (1 << k); S++) {
        ll cur = 0;
        int extra = 0;
        for (int j = 0; j < k; j++)
            if (S >> j & 1) {
                cur += c[j];
                extra++;
            }
        if (cur >= ans) continue;  // 剪枝：c_j 非负，后面只会更大

        DSU d2(n + k + 1);
        int need = n + extra - 1, got = 0;
        for (const Edge& e : all) {
            if (e.tag != 0 && !(S >> (e.tag - 1) & 1)) continue;
            if (d2.unite(e.u, e.v)) {
                cur += e.w;
                got++;
                if (cur >= ans) break;
            }
            if (got == need) break;
        }
        if (got == need) ans = min(ans, cur);
    }
    cout << ans << '\n';
    return 0;
}
```

## 八、易错点

1. **输出答案用 `long long`**：$m,n,k$ 的边权和可达 $10^{13}$ 级别；
2. **城市连通性保证**：题目保证城市图连通，所以城市 MST 恰好 $n-1$ 条边；若不确定连通，则应求最小生成森林并把连通块个数纳入 $need$；
3. **剪枝条件**：`cur >= ans` 时整个子集可以直接跳过，因为 $c_j \ge 0$ 且之后还要加边权；
4. **乡镇点编号**：乡镇 $j$ 的顶点编号记为 $n+j$，避免与城市冲突；
5. **不能对每个子集重新全排序**：$2^k \times (n+kn)$ 的数据如果每次 `sort` 会超时，正确做法是**只排序一次全局边表**，子集内沿有序表跳过即可（或预处理每行乡镇边排序后多路归并）。
