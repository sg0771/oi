# CSP-S 2024 T1 决斗（duel）题解

## 题目概述

- **题目名称**：决斗（duel）
- **考场/比赛**：CCF CSP-S 2024 提高级 复赛 第一题
- **时间限制**：1.0s
- **空间限制**：512MB

### 题目大意
有 $n$ 个怪兽，第 $i$ 个怪兽的攻击力和防御力均为 $r_i$。
每个怪兽最多只能**攻击一次**其他怪兽，也最多只能**被攻击一次**。
一个怪兽 $i$ 可以攻击怪兽 $j$，当且仅当怪兽 $i$ 的攻击力大于怪兽 $j$ 的攻击力（即 $r_i > r_j$）。被攻击后的怪兽 $j$ 会退出决斗（死亡）。
问经过若干次攻击后，最终**最少**能剩下多少只怪兽。

---

## 题目分析

### 核心观察
1. **贪心策略**：为了尽量多地消灭怪兽，我们应当让攻击力较小的怪兽尽早被消灭，并且用刚好大于它的最小攻击力怪兽去攻击它，从而把更高级别的攻击力留给更大的怪兽。
2. **频数决定下限**：
   - 设某种攻击力 $x$ 出现的次数为 $	ext{cnt}[x]$。
   - 由于攻击力相同的怪兽之间**不能互相攻击**，这意味着这 $	ext{cnt}[x]$ 只怪兽只能被攻击力 strictly 更大（$> x$）的怪兽消灭，或者留在场上。
   - 不管怎么安排攻击顺序，任何一种攻击力值对应的怪兽数量 $	ext{cnt}[x]$，其场上存活的怪兽总数都不可能小于 $\max(	ext{cnt}[x])$。
   - **结论**：最终剩下的最少怪兽数量，恰好等于所有攻击力出现次数的最大值，即 $\max_{x} \{	ext{cnt}[x]\ intrac\}$。

---

## 解题思路

解析这道题有多种等价且简单易懂的角度：

### 方法一：众数 / 频数最大值法（最简思路）

根据鸽巢原理与贪心对配：
- 假设出现次数最多的攻击力数值为 $M$，其出现次数为 $C_{max} = \max(	ext{cnt}[x])$。
- 无论如何，这 $C_{max}$ 只怪兽相互之间无法攻击。
- 比它们攻击力小的怪兽可以被消灭掉，而比它们攻击力大的怪兽数量如果不够 $C_{max}$，就无法消灭全部的这批怪兽；如果比它们攻击力大的怪兽数量超过 $C_{max}$，虽然可以消灭这批怪兽，但那些更大的怪兽又会形成新的瓶颈。
- 实际上，我们总是可以通过**双指针**或**队列/贪心**构造出一种方案，使得最终存活的怪兽数恰好为 $\max(	ext{cnt}[x])$。

**时间复杂度**：$O(n)$ 或 $O(n \log n)$（取决于是否排序/使用哈希表计数）。
**空间复杂度**：$O(n)$。

---

### 方法二：排序 + 双指针 / 队列模拟（直观模拟）

如果我们想显式地模拟攻击过程：
1. 将所有怪兽的攻击力 $r$ 按升序排序。
2. 使用双指针 $i$ 和 $j$，初始时 $i = 0, j = 1$：
   - $i$ 指向当前等待被攻击的最弱怪兽。
   - $j$ 指向当前准备发起攻击的怪兽。
3. 当 $r[j] > r[i]$ 时，说明怪兽 $j$ 可以消灭怪兽 $i$。怪兽 $i$ 被消灭，指针 $i$ 后移（$i{++}$），指针 $j$ 后移（$j{++}$）。
4. 当 $r[j] \le r[i]$ 时，说明怪兽 $j$ 攻击力不够，无法消灭 $i$，指针 $j$ 后移（$j{++}$），寻找更强力的怪兽。
5. 最终被消灭的怪兽数量为 $i$，存活的怪兽数量为 $n - i$。

## 代码实现

### C++ 代码实现（方法一：频数统计）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <unordered_map>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;

    unordered_map<int, int> cnt;
    int max_freq = 0;

    for (int i = 0; i < n; ++i) {
        int r;
        cin >> r;
        cnt[r]++;
        max_freq = max(max_freq, cnt[r]);
    }

    cout << max_freq << "\n";

    return 0;
}
```

### C++ 代码实现（方法二：排序 + 双指针）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;

    vector<int> r(n);
    for (int i = 0; i < n; ++i) {
        cin >> r[i];
    }

    sort(r.begin(), r.end());

    int i = 0; // 指向被攻击的怪兽
    for (int j = 0; j < n; ++j) { // j 指向攻击者
        if (r[j] > r[i]) {
            i++; // r[i] 被消灭，移动到下一个待被攻击的怪兽
        }
    }

    // 存活的数量 = 总数 - 被消灭的数量
    cout << n - i << "\n";

    return 0;
}
```

## 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 备注 |
| :--- | :--- | :--- | :--- |
| **频数统计法** | $O(n)$ | $O(n)$ | 使用哈希表统计频数，最快最简洁 |
| **排序+双指针** | $O(n \log n)$ | $O(n)$ | 主要是排序耗时，逻辑极具直观性 |

## 总结与考场技巧

作为 CSP-S 2024 的 T1，本题属于典型的**贪心与观察题**。
- **解题切入点**：注意“相同的数值不能互相攻击”这一约束，由此直接联想到“频数最大值”这一瓶颈。
- **复杂度与数据范围**：$N \le 10^5$，无论 $O(n)$ 还是 $O(n \log n)$ 均可轻松通过（时限 1.0s）。
