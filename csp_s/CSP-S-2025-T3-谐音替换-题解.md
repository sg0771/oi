# CSP-S 2025 T3 谐音替换 / replace（洛谷 P14363）题解

## 一、题目大意

给定 $n$ 个替换规则 $(s_{i,1}, s_{i,2})$，满足 $|s_{i,1}| = |s_{i,2}|$。一次替换：选出字符串 $s$ 的某个子串 $y$，若 $y = s_{i,1}$，则把 $y$ 替换成 $s_{i,2}$（其余部分不变）。

有 $q$ 次询问，每次给出两个**不同**的字符串 $t_{j,1}, t_{j,2}$，问有多少种 $t_{j,1}$ 的替换能得到 $t_{j,2}$。两种替换不同，当且仅当替换的**位置不同**或使用的**规则不同**。

## 二、输入输出格式

### 输入格式

- 第一行两个正整数 $n, q$；
- 接下来 $n$ 行，每行两个等长字符串 $s_{i,1}, s_{i,2}$；
- 接下来 $q$ 行，每行两个字符串 $t_{j,1}, t_{j,2}$。

### 输出格式

$q$ 行，每行一个非负整数表示答案。

## 三、样例

### 输入 #1

```text
4 2
xabcx xadex
ab cd
bc de
aa bb
xabcx xadex
aaaa bbbb
```

### 输出 #1

```text
2
0
```

### 样例解释

第一个询问 `xabcx -> xadex` 有两种替换：

1. 整段替换：用规则 $(xabcx, xadex)$；
2. 只替换中间：用规则 $(bc, de)$，即 `xa + bc + x -> xa + de + x`。

## 四、数据范围

设 $L_1 = \sum_i (|s_{i,1}| + |s_{i,2}|)$，$L_2 = \sum_j (|t_{j,1}| + |t_{j,2}|)$：

- $1 \le n, q \le 2 \times 10^5$；
- $2 \le L_1, L_2 \le 5 \times 10^6$；
- 所有字符串仅含小写字母，规则两个串等长，且询问 $t_{j,1} \ne t_{j,2}$。

## 五、核心思路

### 5.1 关键观察：长度不变，替换区间必须"包住"所有不同位置

因为 $|s_{i,1}| = |s_{i,2}|$，替换**不改变字符串长度**。所以若 $|t_{j,1}| \ne |t_{j,2}|$，答案直接为 $0$。

设询问为 $t_1 \to t_2$（等长），记 $l$ 为第一个 $t_1[x] \ne t_2[x]$ 的位置，$r$ 为最后一个这样的位置，则 $[l, r]$ 之间的字符**全部**满足 $t_1[x] \ne t_2[x]$（按定义）。替换区间之外 $t_1$ 与 $t_2$ 必须完全相同，所以**替换区间必须恰好覆盖 $[l, r]$**；同时，规则内部 $s_1 \ne s_2$ 的位置区间 $[l', r']$ 必须与 $[l, r]$ 一一对齐。

规则 $(s_1, s_2)$ 可以写成

$$s_1 = A + B + C,\qquad s_2 = A + D + C$$

其中 $A$ 为公共前缀，$C$ 为公共后缀，$B = s_1[l'..r']$、$D = s_2[l'..r']$ 是"核心"部分。

### 5.2 关键观察二：转化为单个字符串的多模式匹配

若 $s_1 = s_2$，替换后字符串不变，永远无法把 $t_1$ 变成 $t_2$，直接丢弃这类规则。

对规则做变换（$?$ 是排在 `z` 之后的特殊字符，取 `{`）：

$$\mathrm{calc}(s_1, s_2) = A + \{ + B + D + \{ + C$$

对询问 $t_1, t_2$ 也做同样的变换得到文本 $T$。可以证明：

> 规则 $(s_1, s_2)$ 是询问的一个合法替换 $\iff$ $\mathrm{calc}(s_1,s_2)$ 作为子串出现在 $T$ 中。

直观上：$A$ 部分对应 $t_1$ 中替换区间开头之前公共前缀的**后缀**；$B$、$D$ 精确匹配被替换的 $t_1$ 核心与 $t_2$ 核心；$C$ 对应替换区间尾部公共后缀的**前缀**；两个 `{` 保证对齐（规则内部核心长度必须等于询问核心长度）。

于是问题变成经典的多模式串匹配：把所有规则串插入 AC 自动机，对每个询问文本跑一遍匹配，统计所有模式串出现次数之和。

### 5.3 AC 自动机：统计每个状态被经过的次数

设节点 $v$ 的 $id_v$ = 以 $v$ 为末尾的规则数（多个规则相同也分别计数），并在建 fail 时自顶向下维护

$$depth_v = depth_{fail(v)} + id_v$$

即 fail 链上 $id$ 之和。扫描文本走到状态 $p$ 时，$depth_p$ 正是"以当前文本位置为结尾的所有规则数"。

为避免每次询问清空整棵 Trie，用**时间戳**记录每个状态在本询问中是否被访问过；只对被访问过的状态累加 $cnt_p \times depth_p$（$cnt_p$ 为该状态在本询问中被经过的次数，重复状态先去重）。

### 5.4 复杂度

记总模式串长度 $\le L_1 + 2n$，询问文本总长 $L_2 + 2q$，字符集大小 $|\Sigma| = 27$：

- 建 Trie + 补全转移表：$O(27 \cdot (L_1 + 2n))$；
- 询问：$O(27 \cdot (L_2 + 2q) + L_2\log L_2)$（后者是去重排序，实践中远小于前者）。

空间 $O(27 \cdot (L_1 + 2n))$。

## 六、正确性说明

1. **合法替换 $\Rightarrow$ 模式串出现**：设替换区间为 $[a, b]$。区间外 $t_1 = t_2$，区间内 $t_1, t_2$ 不同位置恰好对应规则的 $[l', r']$，故区间必须从 $t_1$ 的第一个不同位置 $l$ 之前（$A$ 对应公共前缀的后缀）、到最后一个不同位置 $r$ 之后（$C$ 对应公共后缀的前缀）对齐，且核心 $B = t_1[l..r]$、$D = t_2[l..r]$。这正是一个 `calc` 串的完整出现。
2. **模式串出现 $\Rightarrow$ 合法替换**：出现位置的两个 `{` 只能与文本 $T$ 的两个 `{` 对齐（小写部分不含 `{`），唯一确定了替换区间；区间外字符相同、区间内替换规则逐字符吻合，替换结果就是 $t_2$。
3. **计数不重不漏**：`calc` 串在 $T$ 中最多出现一次（`{` 的位置唯一），AC 自动机按 (规则, 文本结束位置) 计数，恰好对应题目要求的 (规则, 替换位置) 二元组；相同 `calc` 串的不同规则由 $id$ 累加区分。

## 七、参考代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 字符集：a-z 与 '{'（特殊分隔符，排在 'z' 之后）
const int ALPHA = 27;

struct Node {
    int id = 0;      // 以该节点为末尾的规则数
    int fail = 0;
    int depth = 0;   // fail 链上 id 之和（含自己）
    int cnt = 0;     // 本询问中该状态被走过的次数
    int tag = 0;     // 时间戳
    int m[ALPHA] = {0};
};

struct AC {
    vector<Node> t;
    int Tag = 0;

    AC() { t.reserve(200000); t.emplace_back(); }

    int hash(char c) { return (c == '{') ? 26 : c - 'a'; }

    void insert(const string& s) {
        int p = 0;
        for (char c : s) {
            int h = hash(c);
            if (!t[p].m[h]) {
                t.emplace_back();
                t[p].m[h] = (int)t.size() - 1;
            }
            p = t[p].m[h];
        }
        t[p].id++;
    }

    void build() {
        queue<int> q;
        for (int i = 0; i < ALPHA; i++)
            if (t[0].m[i]) q.push(t[0].m[i]);
        while (!q.empty()) {
            int x = q.front();
            q.pop();
            t[x].depth = t[t[x].fail].depth + t[x].id;
            for (int i = 0; i < ALPHA; i++) {
                int v = t[x].m[i];
                if (v) {
                    t[v].fail = t[t[x].fail].m[i];
                    q.push(v);
                } else {
                    t[x].m[i] = t[t[x].fail].m[i];  // 补全转移表
                }
            }
        }
    }

    long long query(const string& s) {
        int p = 0;
        long long ans = 0;
        ++Tag;
        vector<int> path;
        path.reserve(s.size());
        for (char c : s) {
            p = t[p].m[hash(c)];
            if (t[p].tag != Tag) {
                t[p].cnt = 0;
                t[p].tag = Tag;
            }
            t[p].cnt++;
            path.push_back(p);
        }
        sort(path.begin(), path.end());
        path.erase(unique(path.begin(), path.end()), path.end());
        for (int x : path) ans += (long long)t[x].cnt * t[x].depth;
        return ans;
    }
};

// 把 (a,b) 变成 A '{' B D '{' C
string calc(const string& a, const string& b) {
    int l = 0;
    while (l < (int)a.size() && a[l] == b[l]) l++;
    int r = (int)a.size() - 1;
    while (l < r && a[r] == b[r]) r--;
    string s;
    s.reserve(a.size() + 2);
    s.append(a, 0, l);
    s.push_back('{');
    s.append(a, l, r - l + 1);
    s.append(b, l, r - l + 1);
    s.push_back('{');
    s.append(a, r + 1, a.size() - 1 - r);
    return s;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;
    AC ac;
    for (int i = 0; i < n; i++) {
        string a, b;
        cin >> a >> b;
        if (a == b) continue;  // 空核心规则永远不能改变串，直接丢弃
        ac.insert(calc(a, b));
    }
    ac.build();

    for (int j = 0; j < q; j++) {
        string a, b;
        cin >> a >> b;
        if (a.size() != b.size()) {
            cout << 0 << '\n';
            continue;
        }
        cout << ac.query(calc(a, b)) << '\n';
    }
    return 0;
}
```

## 八、易错点

1. **长度不同的询问**：替换不改变长度，$|t_1| \ne |t_2|$ 时直接输出 $0$，否则 `calc` 中访问可能越界；
2. **丢弃 $s_1 = s_2$ 的规则**：它们永远不会改变字符串；
3. **重复规则要分别计数**：末尾节点用 $id$ 累加而不是去重；
4. **`{` 的字符编码**：必须排在 `z` 之后（映射到 26），且保证小写部分不会出现它；
5. **询问间不能清空整棵树**：用时间戳只清被访问过的状态，避免每次询问 $O(L_1)$ 的重置开销；
6. **答案用 `long long`**：总出现次数最多为 $n$ 量级，但累加乘积时注意类型。
