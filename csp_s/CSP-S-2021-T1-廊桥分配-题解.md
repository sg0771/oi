# P7913 [CSP-S 2021] 廊桥分配 题解

## 题目大意

机场有 $n$ 个廊桥，需要分配给国内区和国际区。国内区有 $m_1$ 架飞机，国际区有 $m_2$ 架飞机。每架飞机有抵达时间 $a_i$ 和离开时间 $b_i$。飞机按抵达时间先后顺序到达，若当前有空闲廊桥则停靠，否则无法停靠。

求如何分配廊桥数量（国内区 $i$ 个，国际区 $n-i$ 个），使得能停靠的飞机总数最大。

---

## 解题思路

### 核心观察

将问题拆分为两个独立的子问题：预处理国内区和国际区各自分配 $k$ 个廊桥时能停靠的飞机数。

**关键性质**：对于一个区域，飞机按抵达时间排序后，使用"最小的可用廊桥编号"贪心策略是最优的（先到先得，优先分配编号最小的空闲廊桥）。

### 算法

**预处理 `f[i]`（国内区分配 $i$ 个廊桥能停靠的飞机数）：**

1. 将飞机按抵达时间升序排序。
2. 使用两个优先队列：
   - `free_gates`：当前空闲的廊桥编号（最小堆）
   - `occupied`：当前占用的廊桥，存储 `(离开时间, 廊桥编号)`（最小堆按离开时间）
3. 遍历每架飞机：
   - 释放所有离开时间早于当前飞机抵达时间的廊桥。
   - 若 `free_gates` 非空，分配最小廊桥编号，记录该飞机使用了哪个廊桥。
   - 否则该飞机无法停靠。
4. 统计每个廊桥停靠的飞机数，`f[i]` = 前 $i$ 个廊桥停靠的飞机总数（前缀和）。

同理预处理 `g[i]`（国际区）。

**最终答案：** $\max_{0 \le i \le n} (f[i] + g[n-i])$

### 正确性证明

贪心分配最小廊桥编号的正确性：由于飞机按抵达时间排序，使用编号最小的空闲廊桥可以最大化后续飞机的停靠机会，因为更大的廊桥编号留给后续飞机不会更差。每个廊桥能停靠的飞机数具有单调性，且 $f[i]$ 和 $g[i]$ 是通过贪心得到的最优分配结果。

## C++ 源代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;

struct Flight {
    int arrive, leave;
    bool operator<(const Flight& other) const {
        return arrive < other.arrive;
    }
};

int n, m1, m2;
Flight domestic[MAXN], international[MAXN];
int f[MAXN], g[MAXN]; // f[i]: 国内区分配i个廊桥能停靠的飞机数

// 预处理：计算分配k个廊桥能停靠的飞机数（前缀和）
void preprocess(Flight flights[], int m, int result[]) {
    sort(flights + 1, flights + m + 1);

    // occupied: (leave_time, gate_id) 最小堆
    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> occupied;
    // free_gates: gate_id 最小堆
    priority_queue<int, vector<int>, greater<int>> free_gates;

    for (int i = 1; i <= n; ++i) {
        free_gates.push(i);
    }

    vector<int> count(n + 1, 0); // 每个廊桥停靠的飞机数

    for (int i = 1; i <= m; ++i) {
        int arrive = flights[i].arrive;
        int leave = flights[i].leave;

        // 释放所有已离开的廊桥
        while (!occupied.empty() && occupied.top().first < arrive) {
            int gate = occupied.top().second;
            occupied.pop();
            free_gates.push(gate);
        }

        if (!free_gates.empty()) {
            int gate = free_gates.top();
            free_gates.pop();
            occupied.push({leave, gate});
            count[gate]++;
        }
    }

    // 前缀和
    result[0] = 0;
    for (int i = 1; i <= n; ++i) {
        result[i] = result[i - 1] + count[i];
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m1 >> m2;

    for (int i = 1; i <= m1; ++i) {
        cin >> domestic[i].arrive >> domestic[i].leave;
    }
    for (int i = 1; i <= m2; ++i) {
        cin >> international[i].arrive >> international[i].leave;
    }

    preprocess(domestic, m1, f);
    preprocess(international, m2, g);

    int ans = 0;
    for (int i = 0; i <= n; ++i) {
        ans = max(ans, f[i] + g[n - i]);
    }

    cout << ans << "\n";
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$\mathcal{O}((m_1 + m_2) \log n)$。预处理两个区域时，每架飞机涉及优先队列的入队出队操作，每次 $\mathcal{O}(\log n)$。最终枚举 $n$ 种分配方案为 $\mathcal{O}(n)$。
- **空间复杂度**：$\mathcal{O}(n + m_1 + m_2)$，存储飞机信息和廊桥计数。

---

## 关键点

1. **问题拆分**：将国内区和国际区独立处理，预处理各自的最优分配结果。
2. **贪心策略**：每次分配编号最小的空闲廊桥，这是最优的（可以通过交换论证证明）。
3. **双优先队列**：`occupied` 按离开时间排序用于释放廊桥，`free_gates` 按编号排序用于分配廊桥。
4. **前缀和统计**：`count[i]` 记录 $i$ 号廊桥停靠的飞机数，前缀和得到分配 $k$ 个廊桥的总停靠数。
5. **枚举最优分配**：遍历 $i = 0 \sim n$，取 $\max(f[i] + g[n-i])$。注意 $i$ 可以为 0（所有廊桥分给国际区）或 $n$（所有廊桥分给国内区）。
