# P9753 [CSP-S 2023] 消消乐 题解

## 题目大意

给定一个长度为 $n$ 的字符串，每个字符为小写字母。相邻的两个相同字符可以被消除，消除后两侧的字符合并。求有多少个非空连续子串可以经过若干次消除操作后变为空串。

---

## 解题思路

### 核心观察

消除过程与括号匹配类似，可以用栈来模拟。关键性质：对于字符串 $S$，消除过程的结果是唯一的（与消除顺序无关），因为相邻相同字符消除具有合流性（confluence）。

### 算法：栈状态哈希

定义 $h_i$ 表示前缀 $S[1..i]$ 经过完全消除后的结果（栈状态）。如果 $h_i = h_j$，则说明子串 $S[i+1..j]$ 可以完全消除。因为 $S[1..j]$ 的消除结果等于 $S[1..i]$ 的消除结果，说明 $S[i+1..j]$ 消除后不留下任何字符。

因此，只需统计有多少对 $(i, j)$（$0 \le i < j \le n$）满足 $h_i = h_j$。答案即为 $\sum \binom{\text{cnt}[h]}{2}$。

为高效比较栈状态，使用**字符串哈希**来表示栈内容。具体地，维护一个前缀哈希值，当遇到相同字符时（即栈顶字符与当前字符相同），弹出栈顶（哈希值回退）；否则将当前字符压入栈（哈希值更新）。

---

## C++ 源代码

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef unsigned long long ull;

const int MAXN = 2000005;
const ull BASE = 131;

int n;
char s[MAXN];

// 栈状态哈希：用多项式哈希表示栈中字符序列
// hash = c1 * BASE^{len-1} + c2 * BASE^{len-2} + ... + c_len
// 压入字符 c：hash = hash * BASE + c
// 弹出字符 c：hash = (hash - c) / BASE

ull pow_base[MAXN]; // BASE 的幂

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> (s + 1);

    // 预计算 BASE 的幂
    pow_base[0] = 1;
    for (int i = 1; i <= n; i++) {
        pow_base[i] = pow_base[i-1] * BASE;
    }

    // 记录每个哈希值出现的次数
    unordered_map<ull, int> cnt;
    ull hash_val = 0;
    int top = 0; // 栈大小
    char stk[MAXN]; // 栈内容（用于弹出时知道弹出的字符）

    cnt[hash_val]++; // 空前缀

    for (int i = 1; i <= n; i++) {
        if (top > 0 && stk[top] == s[i]) {
            // 弹出
            hash_val = (hash_val - stk[top]) / BASE; // 注意：这里除法仅在 BASE 为奇数且 hash_val 正确的条件下有效
            top--;
        } else {
            // 压入
            top++;
            stk[top] = s[i];
            hash_val = hash_val * BASE + s[i];
        }
        cnt[hash_val]++;
    }

    long long ans = 0;
    for (auto &p : cnt) {
        long long c = p.second;
        ans += c * (c - 1) / 2;
    }

    cout << ans << "\n";
    return 0;
}
```

**注意**：上述代码中除法回退哈希值的做法在模 $2^{64}$ 意义下要求 BASE 为奇数（保证逆元存在）。以下为更稳健的双哈希版本：

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef unsigned long long ull;

const int MAXN = 2000005;
const ull BASE1 = 131;
const ull BASE2 = 13331;

int n;
char s[MAXN];
char stk[MAXN];
int top;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> (s + 1);

    // 使用 map 存 pair 双哈希
    map<pair<ull, ull>, int> cnt;
    ull h1 = 0, h2 = 0;
    cnt[{0, 0}]++;

    for (int i = 1; i <= n; i++) {
        if (top > 0 && stk[top] == s[i]) {
            // 弹出：h = (h - c) / BASE，需要确保可除
            h1 = (h1 - stk[top]) / BASE1;
            h2 = (h2 - stk[top]) / BASE2;
            top--;
        } else {
            top++;
            stk[top] = s[i];
            h1 = h1 * BASE1 + s[i];
            h2 = h2 * BASE2 + s[i];
        }
        cnt[{h1, h2}]++;
    }

    long long ans = 0;
    for (auto &p : cnt) {
        long long c = p.second;
        ans += c * (c - 1) / 2;
    }

    cout << ans << "\n";
    return 0;
}
```

---

## 复杂度分析

- **时间复杂度**：$O(n)$。每个字符恰好被压入和弹出栈各一次，哈希计算和 `unordered_map`/`map` 操作为 $O(1)$ / $O(\log n)$。
- **空间复杂度**：$O(n)$，存储栈和哈希表。

---

## 关键点

1. **消除唯一性**：相邻相同字符消除的结果与消除顺序无关，可以用栈模拟。
2. **前缀状态等价**：两个前缀消除后的栈状态相同，则它们之间的子串可以完全消除。
3. **哈希表示栈**：用多项式哈希表示栈内容，支持 $O(1)$ 的压入和弹出操作。
4. **组合计数**：若一个哈希值出现 $c$ 次，则贡献 $\binom{c}{2}$ 个可消除子串。
