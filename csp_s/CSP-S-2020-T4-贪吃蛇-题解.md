# P7078 [CSP-S 2020] 贪吃蛇 题解

## 题目大意

$n$ 条蛇，每条蛇有体力值 $a_i$。游戏规则：
- 每轮：体力最大的蛇可以选择**吃**或**不吃**体力最小的蛇。
- 若吃：体力相减得到新体力值，被吃的蛇退出游戏。
- 游戏结束条件：某条蛇选择不吃，或只剩 1 条蛇。
- 每条蛇都足够聪明，优先保证自己存活，其次尽量多吃蛇。

求最终存活的蛇的数量。多组询问，每次修改若干条蛇的体力值。

---

## 解题思路

### 核心观察

**观察 1：双端队列维护**

将蛇按体力排序后，吃蛇产生的新蛇体力**单调递减**。因此可以用两个 `deque` 高效维护：
- `q1`：初始排序的蛇（体力从小到大）
- `q2`：吃完后产生的新蛇（按生成顺序自然递减，新蛇总是插入 `q2` 前端）

每次取最大值时比较 `q1.back()` 和 `q2.back()`；取最小值时比较 `q1.front()` 和 `q2.front()`。

**观察 2：停止条件**

当最强蛇吃完后**不是**最弱蛇时，它绝对安全，一定会选择吃，游戏继续。

当最强蛇吃完后**变成**最弱蛇，它面临危险：下一轮自己可能被吃。此时需要评估"危险链"：

- 当前最强蛇 $A$ 若吃最弱蛇，变成 $A'$（新最弱）。
- 下一轮最强蛇 $B$ 若吃 $A'$，变成 $B'$。
- 若 $B'$ 也是最弱，则 $B$ 也面临同样困境，继续递归。
- 这条链一直延伸，直到某条蛇吃完后**不是**最弱，或只剩 2 条蛇。

**结论**：设危险链长度为 $\text{len}$（包含当前危险轮）。
- 若 $\text{len}$ 为奇数：链首的蛇最终安全，会选择吃，游戏继续。答案为 $\text{cur} - 1$（$\text{cur}$ 为危险轮开始前的蛇数）。
- 若 $\text{len}$ 为偶数：链首的蛇会被吃，因此它不会吃，游戏结束。答案为 $\text{cur}$。

### 算法

1. 将蛇按体力升序排列，放入 `q1`。
2. 模拟吃蛇过程，每次从 `q1` 和 `q2` 中取出最大和最小蛇。
3. 若 `new_snake >= next_min`（吃完后不是最弱），正常吃，继续。
4. 若 `new_snake < next_min`（吃完后变成最弱），进入危险链判断：
   - 将 `new_snake` 放入 `q2` 前端，开始计数链长。
   - 模拟后续轮次，直到新蛇不是最弱或只剩 2 条蛇。
   - 根据链长奇偶性输出答案。

## C++ 源代码

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
const int MAXN = 1000005;

int n;
ll a[MAXN];

struct Snake {
    ll val;
    int id;
    bool operator<(const Snake& other) const {
        if (val != other.val) return val < other.val;
        return id < other.id;
    }
};

// Get max from two deques (pop it)
Snake pop_max(deque<Snake>& q1, deque<Snake>& q2) {
    if (q1.empty()) { Snake s = q2.back(); q2.pop_back(); return s; }
    if (q2.empty()) { Snake s = q1.back(); q1.pop_back(); return s; }
    if (q2.back() < q1.back()) { Snake s = q1.back(); q1.pop_back(); return s; }
    else { Snake s = q2.back(); q2.pop_back(); return s; }
}

// Get min from two deques (pop it)
Snake pop_min(deque<Snake>& q1, deque<Snake>& q2) {
    if (q1.empty()) { Snake s = q2.front(); q2.pop_front(); return s; }
    if (q2.empty()) { Snake s = q1.front(); q1.pop_front(); return s; }
    if (q1.front() < q2.front()) { Snake s = q1.front(); q1.pop_front(); return s; }
    else { Snake s = q2.front(); q2.pop_front(); return s; }
}

// Peek min without popping
Snake peek_min(deque<Snake>& q1, deque<Snake>& q2) {
    if (q1.empty()) return q2.front();
    if (q2.empty()) return q1.front();
    return min(q1.front(), q2.front());
}

int solve() {
    deque<Snake> q1, q2;

    sort(a + 1, a + n + 1);
    for (int i = 1; i <= n; ++i) {
        q1.push_back({a[i], i});
    }

    int safe_rounds = 0; // number of completed safe rounds

    while (true) {
        int sz = (int)q1.size() + (int)q2.size();
        if (sz <= 2) return 1; // only 1 survives

        Snake mx = pop_max(q1, q2);
        Snake mn = pop_min(q1, q2);
        Snake new_snake = {mx.val - mn.val, mx.id};

        Snake next_min = peek_min(q1, q2);

        if (new_snake < next_min) {
            // ---- dangerous round detected ----
            // Push new_snake back (it becomes the weakest)
            q2.push_front(new_snake);
            safe_rounds++; // this round is the first dangerous round

            int chain_len = 1; // current dangerous round counts

            // Simulate the danger chain
            while (true) {
                sz = (int)q1.size() + (int)q2.size();
                if (sz <= 2) {
                    chain_len++;
                    break;
                }

                Snake mx2 = pop_max(q1, q2);
                Snake mn2 = pop_min(q1, q2);
                Snake ns2 = {mx2.val - mn2.val, mx2.id};

                Snake nm2 = peek_min(q1, q2);
                q2.push_front(ns2);
                chain_len++;

                if (!(ns2 < nm2)) {
                    // ns2 is NOT the weakest -> chain breaks
                    break;
                }
            }

            // cur = number of snakes before the first dangerous round
            int cur = n - safe_rounds + 1; // safe_rounds includes the first dangerous round

            if (chain_len % 2 == 1) {
                return cur - 1; // first snake eats, game continues
            } else {
                return cur;     // first snake won't eat, game ends
            }
        }

        // ---- safe round ----
        q2.push_front(new_snake);
        safe_rounds++;
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    for (int t = 1; t <= T; ++t) {
        if (t == 1) {
            cin >> n;
            for (int i = 1; i <= n; ++i) cin >> a[i];
        } else {
            int k; cin >> k;
            for (int i = 0; i < k; ++i) {
                int x, y; cin >> x >> y;
                a[x] = y;
            }
        }
        cout << solve() << "\n";
    }

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$\mathcal{O}(n \log n)$。排序需要 $\mathcal{O}(n \log n)$，双端队列模拟每条蛇最多入队出队一次，为 $\mathcal{O}(n)$。
- **空间复杂度**：$\mathcal{O}(n)$，用于存储两个双端队列中的蛇。

---

## 关键点

1. **双端队列维护**：`q1` 存初始排序的蛇，`q2` 存吃完后产生的新蛇。由于新蛇体力单调递减，`q2` 自然保持有序（新蛇插入前端，`q2` 从后往前递增）。
2. **停止条件分析**：当最强蛇吃完后不是最弱蛇时，它安全，一定吃；当变成最弱蛇时，触发"危险链"分析。
3. **危险链奇偶性**：若链长为奇数，链首蛇最终安全，会选择吃，答案减 1；若为偶数，链首蛇会被吃，选择不吃，答案为当前蛇数。
4. **体力相等时的处理**：体力相同时用编号区分大小，保证决策的确定性。
5. **多组数据**：每组数据修改部分蛇的体力后重新计算，每组独立排序模拟。
