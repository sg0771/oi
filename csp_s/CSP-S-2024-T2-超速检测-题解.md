# CSP-S 2024 T2 超速检测（洛谷 P11232）题解

## 一、题目大意

有一条长度为 $L$ 的南北主干道（坐标为 $[0,L]$，北端为 $L$），路上有 $n$ 辆车和 $m$ 个测速仪。

第 $i$ 辆车从坐标 $d_i$ 处以初速度 $v_i$、加速度 $a_i$ 做匀变速直线运动向北行驶（只考虑从南向北的车辆，所以 $v_i>0$，但 $a_i$ 可正、可负、可为零）。当车辆到达最北端（坐标 $L$）或速度降为 $0$ 时，视为驶离主干道。

第 $j$ 个测速仪位于坐标 $p_j$，可以开启或关闭。当车辆经过一个开启的测速仪时，如果瞬时速度 $>V$（严格大于），则该车被判为超速。车辆在驶入、驶出位置若正好有测速仪，也会被测量。

要求解决两个问题：

1. 所有测速仪都开启时，有多少辆车会被判定为超速；
2. 在不漏掉任何一辆（在所有测速仪开启时）会被判定为超速的车辆的前提下，最多可以关闭多少个测速仪。

## 二、输入输出格式

### 输入格式

第一行一个正整数 $T$，表示数据组数。

每组数据：

- 第一行四个整数 $n, m, L, V$；
- 接下来 $n$ 行，每行三个整数 $d_i, v_i, a_i$；
- 最后一行 $m$ 个整数 $p_1, p_2, \dots, p_m$，保证 $p$ 严格递增。

### 输出格式

每组数据输出一行两个整数：第一个数为所有测速仪开启时被判为超速的车辆数量；第二个数为最多可以关闭的测速仪数量。

## 三、样例

### 输入 #1

```text
1
5 5 15 3
0 3 0
12 4 0
1 1 4
5 5 -2
6 4 -4
2 5 8 9 15
```

### 输出 #1

```text
3 3
```

### 样例解释

测速仪位置为 $2,5,8,9,15$，限速 $V=3$。

- 第 1 辆车：$d=0, v=3, a=0$，匀速且速度等于限速，不超速。
- 第 2 辆车：$d=12, v=4, a=0$，匀速且 $4>3$，会被位置 $15$ 的测速仪判为超速。
- 第 3 辆车：$d=1, v=1, a=4$。由 $\dfrac{V^2-v^2}{2a}=\dfrac{9-1}{8}=1$，车到达位置 $1+1=2$ 时速度恰为 $3$，此后一直超速，所以位置 $2$ 之后的测速仪（$5,8,9,15$）都能判其超速。
- 第 4 辆车：$d=5, v=5, a=-2$。由 $\dfrac{9-25}{-4}=4$，车到达位置 $5+4=9$ 时速度降为 $3$，因此它在 $[5,9)$ 区间超速，位置 $5$ 和 $8$ 的测速仪可判其超速。
- 第 5 辆车：$d=6, v=4, a=-4$。超速区间为 $[6, 6\frac78)$，其间没有测速仪，不被判定超速。

故第一问答案为 $3$。第二问中，只需保留位置 $5$ 和 $15$ 两个测速仪即可覆盖第 3、4、2 辆车，最多可关闭 $5-2=3$ 个。

## 四、数据范围

- $1 \le T \le 20$；
- $1 \le n, m \le 10^5$，$1 \le L \le 10^6$，$1 \le V \le 10^3$；
- $0 \le d_i < L$，$1 \le v_i \le 10^3$，$|a_i| \le 10^3$；
- $0 \le p_1 < p_2 < \cdots < p_m \le L$。

特殊性质：

- A：$a_i = 0$；
- B：$a_i > 0$；
- C：$a_i < 0$，且所有车都不在最北端驶离主干道。

## 五、核心思路

### 5.1 关键观察

对任意一辆车，它**在道路上超速的位置一定是一段连续的区间**（可能为空）。因此，一辆车能被哪些测速仪判为超速，也对应一段**测速仪编号区间** $[l, r]$。

于是两个问题分别变成：

1. 每辆车是否存在非空的检测区间，统计个数；
2. 有若干区间，选最少的点（测速仪）使每个区间至少包含一个点，答案为 $m - $ 最少选点数。

第 2 个问题就是经典的**区间选点贪心**。

### 5.2 运动学公式

全程只用一条公式（速度—位移公式）：

$$v_t^2 - v_0^2 = 2as$$

即当位移为 $s$ 时，瞬时速度为：

$$v_t = \sqrt{v_0^2 + 2as}$$

反过来，速度从 $v_0$ 变为 $v_t$ 所需的位移为：

$$s = \frac{v_t^2 - v_0^2}{2a}$$

为了避免浮点精度问题，比较时都使用平方：

$$\text{速度大于限速} \iff v^2 + 2a(x - d) > V^2$$

### 5.3 对每辆车分类讨论，求出检测区间

约定：记"速度刚好达到 $V$ 的位置"为阈值 $t$（可能不存在），用二分在 $p$ 数组中查找满足条件的测速仪编号，得到闭区间 $[l, r]$（编号从 $1$ 开始）。

#### 情况 1：$a_i = 0$（匀速）

速度恒为 $v_i$：

- 若 $v_i \le V$，永远不会超速；
- 若 $v_i > V$，从 $d_i$ 开始一路超速，能检测它的测速仪为第一个满足 $p_j \ge d_i$ 的编号 $l$ 到 $m$，即区间 $[l, m]$。

#### 情况 2：$a_i > 0$（匀加速）

速度单调递增，超速之后一直超速，所以检测区间右端点恒为 $m$。

速度达到限速的位置为：

$$t = d_i + \frac{V^2 - v_i^2}{2a_i}$$

注意 $t$ 处速度为 $V$，**不算超速**，所以左端点 $l$ 是第一个满足 $p_j > t$ 的测速仪：

- 若 $v_i > V$：一开始就超速，等价于 $t < d_i$（实现时可直接令 $l$ 为第一个满足 $p_j \ge d_i$ 的编号，或者令 $t = d_i - 1$ 后统一处理）；
- 若 $v_i \le V$：二分求第一个 $p_j > t$。

若存在这样的 $l$，则该车检测区间为 $[l, m]$。

#### 情况 3：$a_i < 0$（匀减速）

速度单调递减，只有可能"先超速、后降到限速以下"：

- 若 $v_i \le V$，永远不会超速；
- 若 $v_i > V$：
  - 左端点 $l$：第一个满足 $p_j \ge d_i$ 的测速仪（注意驶入位置本身会被测速）；
  - 右端点 $r$：最后一个满足 $p_j < t$ 的测速仪，其中 $t = d_i + \dfrac{V^2 - v_i^2}{2a_i}$ 是速度降到 $V$ 的位置。因为 $t$ 处速度为 $V$，不超速，所以要求严格小于。

若 $l \le r$，则检测区间为 $[l, r]$，否则该车不会被判定超速。

第一问答案就是所有非空检测区间的个数。

### 5.4 第二问：区间选点贪心

把得到的每个检测区间视为数轴上的线段，问题转化为：**选最少的点，使每条线段至少包含一个点**。

经典贪心：

1. 将所有区间按**右端点从小到大**排序；
2. 维护变量 `last`，表示最近一次选的点（测速仪）所在位置；
3. 从左到右扫描：若 `last` 已落在当前区间内（即 $last \ge l_i$），该区间已被覆盖；否则在 $r_i$ 处放一个点，`last = r_i`，点数加一。

正确性：按右端点排序后，每次在未覆盖区间的最右端放点，能同时覆盖最多尚未处理的区间，贪心最优。

最少需要开启的测速仪数量为 $cnt$，则最多可关闭 $m - cnt$ 个。

### 5.5 时间复杂度

每辆车求区间用二分，$O(\log m)$；排序 $O(k\log k)$（$k$ 为检测区间个数），总复杂度 $O((n + k)\log n) \approx O(n\log n)$，可以轻松通过 $10^5$ 的数据。

## 六、注意事项（易错点）

1. **严格大于**：题目要求 $v_t > V$ 才算超速，$v_t = V$ 不算。体现在：
   - 加速车：左端点取第一个 $p_j > t$；
   - 减速车：右端点取最后一个 $p_j < t$。
2. **整数边界与取整**：阈值 $t$ 往往是分数。利用所有 $p_j$ 都是整数这一条件，可以只用整数比较、二分，避免浮点误差。若用浮点，$t$ 恰为整数时尤其要小心开闭区间。
3. **多测清空**：区间数组计数、答案等每组数据都要重置。
4. **减速车的左端点**：$p_l \ge d_i$ 而不是 $> d_i$，因为驶入位置上的测速仪也会测量。
5. 若计算出的 $l > r$（或不存在），该车不算超速，不要加入区间。

## 七、参考代码（C++17，整数二分，无浮点）

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

const int MAXN = 100005;

int n, m, L, V;
int d[MAXN], v[MAXN], a[MAXN], p[MAXN];

struct Seg {
    int l, r; // 测速仪编号闭区间 [l, r]
    bool operator<(const Seg &o) const {
        return r < o.r;
    }
} seg[MAXN];

int tot; // 检测区间个数（第一问答案）

// 第一个 p[idx] >= x 的编号，不存在返回 m+1
int lower_pos(int x) {
    int lo = 1, hi = m, ans = m + 1;
    while (lo <= hi) {
        int mid = (lo + hi) >> 1;
        if (p[mid] >= x) {
            ans = mid;
            hi = mid - 1;
        } else {
            lo = mid + 1;
        }
    }
    return ans;
}

// 第一个 p[idx] > x 的编号，不存在返回 m+1
int upper_pos(int x) {
    int lo = 1, hi = m, ans = m + 1;
    while (lo <= hi) {
        int mid = (lo + hi) >> 1;
        if (p[mid] > x) {
            ans = mid;
            hi = mid - 1;
        } else {
            lo = mid + 1;
        }
    }
    return ans;
}

// 最后一个满足 p[idx] < x 的编号，不存在返回 0
int last_before(int x) {
    int lo = 1, hi = m, ans = 0;
    while (lo <= hi) {
        int mid = (lo + hi) >> 1;
        if (p[mid] < x) {
            ans = mid;
            lo = mid + 1;
        } else {
            hi = mid - 1;
        }
    }
    return ans;
}

void add_seg(int l, int r) {
    if (l <= r) {
        seg[++tot] = {l, r};
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        cin >> n >> m >> L >> V;
        for (int i = 1; i <= n; i++) {
            cin >> d[i] >> v[i] >> a[i];
        }
        for (int i = 1; i <= m; i++) {
            cin >> p[i];
        }

        tot = 0;
        for (int i = 1; i <= n; i++) {
            ll vv = 1LL * v[i] * v[i];
            ll VV = 1LL * V * V;

            if (a[i] == 0) {
                // 匀速：初速度大于限速才有检测区间
                if (v[i] > V) {
                    add_seg(lower_pos(d[i]), m);
                }
            } else if (a[i] > 0) {
                // 匀加速：右端点恒为 m，找第一个 p > t 的测速仪
                // 速度到达 V 的位置 t = d + (V^2 - v^2) / (2a)
                // v > V 时 t < d，直接令 t = d - 1 统一处理
                ll t;
                if (v[i] > V) {
                    t = d[i] - 1;
                } else {
                    ll num = VV - vv;          // >= 0
                    ll den = 2LL * a[i];       // > 0
                    t = d[i] + num / den;      // 向下取整：p > t 即可保证严格超速
                    // 注意 num/den 向下取整后，若 p == ceil(t) 且 t 为分数，
                    // 仍有 p > floor(t)，逻辑上一致；t 为整数时 p > t 恰好排除速度==V 的点。
                }
                add_seg(upper_pos((int)t), m);
            } else {
                // 匀减速：初速度 <= V 永远不会超速
                if (v[i] <= V) {
                    continue;
                }
                int l = lower_pos(d[i]);
                // 速度降到 V 的位置 t = d + (V^2 - v^2) / (2a)
                // 因 a < 0，num = V^2 - v^2 < 0，den = 2a < 0，
                // 需要向上取整（即向负无穷方向）后，要求 p < t。
                ll num = VV - vv; // < 0
                ll den = 2LL * a[i]; // < 0
                // ceil(num/den)（两个负数相除为正）
                ll q = num / den;
                ll rem = num % den;
                ll add = (rem != 0) ? q + 1 : q; // 对正数做上取整
                ll t = d[i] + add;
                int r = last_before((int)t);
                add_seg(l, r);
            }
        }

        // 第一问
        cout << tot << ' ';

        // 第二问：区间选点贪心
        sort(seg + 1, seg + tot + 1);
        int need = 0; // 最少需要开启的测速仪数量
        int last = -1;
        for (int i = 1; i <= tot; i++) {
            if (last >= seg[i].l) {
                continue; // 已被覆盖
            }
            need++;
            last = seg[i].r; // 贪心选右端点
        }
        cout << m - need << '\n';
    }
    return 0;
}
```

## 八、正确性说明

**第一问**：由运动学公式，任意时刻位置为 $x$ 时速度平方为 $v^2 + 2a(x-d)$，与 $V^2$ 比较即可判断是否超速。速度关于位置单调（$a>0$ 单调递增、$a<0$ 单调递减、$a=0$ 恒定），所以超速位置集合是连续区间；加上测速仪位置严格递增且都在 $[0,L]$ 内，能判超速的测速仪编号也是连续区间。逐车统计非空区间即可。

**第二问**：把"每个超速车辆至少被一个保留测速仪检测"转化为"每条线段至少被一个点覆盖"。按右端点排序后，选择当前最左未覆盖线段的右端点，可以覆盖所有左端点不超过该点且与之相交的后续线段；对任意最优解，该选择不会更劣，因此贪心得到最少点数 $cnt$，最多可关闭 $m-cnt$ 个测速仪。
