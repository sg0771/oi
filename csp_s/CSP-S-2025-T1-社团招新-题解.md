# CSP-S 2025 T1 社团招新 / club（洛谷 P14361）题解

## 一、题目大意

小 L 招收了 $n$ 名新成员（$n$ 为偶数），要将他们分到 3 个部门。第 $i$ 个成员对第 $j$ 个部门的满意度为 $a_{i,j}$，分配到部门 $d_i$ 的满意度贡献为 $a_{i,d_i}$，总满意度为所有成员贡献之和。

限制：**每个部门的人数都不超过 $\frac{n}{2}$**。求满足限制的最大总满意度。

## 二、输入输出格式

### 输入格式

- 第一行一个正整数 $t$，表示数据组数；
- 每组数据：第一行一个正整数 $n$（偶数）；接下来 $n$ 行，每行三个非负整数 $a_{i,1}, a_{i,2}, a_{i,3}$。

### 输出格式

每组数据输出一行一个非负整数，表示最大满意度。

## 三、样例

### 输入 #1

```text
3
4
4 2 1
3 2 4
5 3 4
3 5 1
4
0 1 0
0 1 0
0 2 0
0 2 0
2
10 9 8
4 0 0
```

### 输出 #1

```text
18
4
13
```

### 样例解释

第一组数据：四个成员分别分到部门 $1,3,1,2$，各部门人数为 $2,1,1$，均不超过 $2$，满意度 $4+4+5+5=18$。

第二组数据：分到 $1,1,2,2$，满意度 $0+0+2+2=4$。

第三组数据：两个成员分别分到 $2,1$，满意度 $9+4=13$。

## 四、数据范围

- $1 \le t \le 5$；
- $2 \le n \le 10^5$，$n$ 为偶数；
- $0 \le a_{i,j} \le 2\times 10^4$。

## 五、核心思路

### 5.1 关键观察：先贪心，再调整

先忽略人数限制，把每个人分到满意度**最大**的部门，得到一个"理想答案" $S=\sum_i \max_j a_{i,j}$。

关键性质：**最多只有一个部门的人数会超过 $\frac{n}{2}$**。因为若两个部门都超过 $\frac{n}{2}$，总人数就超过 $n$，矛盾。

因此：

1. 若按最大值分配后所有部门人数都 $\le \frac{n}{2}$，答案就是 $S$；
2. 否则恰有一个部门 $c$ 超员，只需把该部门中一部分成员改分到**满意度次大**的部门，直到该部门人数降到 $\frac{n}{2}$。由于另外两个部门的人数总和至少为 $\frac{n}{2}$，调整后必然合法。

### 5.2 贪心选择"损失最小"的人

把第 $i$ 个人从最大值部门 $c$ 移到次大部门，满意度损失为

$$\text{loss}_i = \max_j a_{i,j} - \text{次大值}_i$$

为了总损失最小，把超员部门中所有人的 $\text{loss}$ 排序（或用堆），**每次取出 loss 最小的人改派**，直到人数降到 $\frac{n}{2}$。

### 5.3 时间复杂度

每人找最大值/次大值 $O(1)$（只有 3 个值），超员部门内排序或堆操作 $O(n\log n)$，总复杂度 $O(n\log n)$，可以通过 $n=10^5$。

## 六、正确性说明

**调整后合法**：唯一的超员部门 $c$ 人数降到 $\frac{n}{2}$，另外两个部门的总人数为 $n-\frac{n}{2}=\frac{n}{2}$，各自不超过总数，故一定合法。

**损失最小即最优**：任何可行方案都可以看作"从按最大值分配的方案中，把一部分本应分到 $c$ 的人改派到别处"。由于只能有一个部门超员，且改派目标取次大值最优，问题等价于从超员部门选出恰好 $\text{size}(c)-\frac{n}{2}$ 个人，使 loss 之和最小——显然每次选 loss 最小的人。

## 七、参考代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        vector<int> a1(n), a2(n), a3(n);
        // cnt[j]: 按最大值分配后第 j 个部门的人数（0-based）
        vector<int> cnt(3, 0);
        vector<vector<ll>> loss(3); // loss[j]: 部门 j 中每个人改派到次大部门的损失
        ll ans = 0;

        for (int i = 0; i < n; i++) {
            cin >> a1[i] >> a2[i] >> a3[i];
            int mx = max({a1[i], a2[i], a3[i]});
            int pos = (a1[i] == mx ? 0 : (a2[i] == mx ? 1 : 2));
            int second = 0;
            for (int j = 0; j < 3; j++) {
                if (j != pos) second = max(second, (j == 0 ? a1[i] : (j == 1 ? a2[i] : a3[i])));
            }
            cnt[pos]++;
            loss[pos].push_back(mx - second);
            ans += mx;
        }

        for (int j = 0; j < 3; j++) {
            if (cnt[j] > n / 2) {
                sort(loss[j].begin(), loss[j].end());
                int need = cnt[j] - n / 2;
                for (int i = 0; i < need; i++) ans -= loss[j][i];
                break;
            }
        }
        cout << ans << '\n';
    }
    return 0;
}
```

## 八、易错点

1. **"次大值"不是第二大值**：改派目标是除最大值部门外满意度最高的部门（$j\ne pos$ 中的最大值）；
2. 最大值并列时，把该人计入任一最大值部门即可（答案不变），但 loss 计算仍取"次大"；
3. 答案要用 `long long`（$n=10^5$，每人满意度 $2\times10^4$，总和可达 $2\times10^9$）；
4. 超员部门最多一个，找到后处理完直接结束。
