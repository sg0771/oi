# CSP-S 2024 T3 染色（洛谷 P11233）题解

## 一、题目大意

给定一个长度为 $n$ 的正整数数组 $A$，其中所有数从左至右排成一排。

需要将 $A$ 中的每个数染成红色或蓝色之一，然后按如下方式计算最终得分：

设 $C$ 为长度为 $n$ 的整数数组，对于 $A$ 中的每个数 $A_i$（$1 \le i \le n$）：

- 如果 $A_i$ 左侧没有与其同色的数，则令 $C_i = 0$；
- 否则，记其左侧与其**最靠近**的同色数为 $A_j$：
  - 若 $A_i = A_j$，则令 $C_i = A_i$；
  - 否则令 $C_i = 0$。

最终得分为 $\sum_{i=1}^{n} C_i$，求最终得分的最大值。

## 二、输入输出格式

### 输入格式

本题有多组测试数据。

- 第一行一个正整数 $T$，表示数据组数；
- 每组数据两行：第一行一个正整数 $n$；第二行 $n$ 个正整数 $A_1, A_2, \dots, A_n$。

### 输出格式

每组数据输出一行一个非负整数，表示最终得分的最大可能值。

## 三、样例

### 输入 #1

```text
3
3
1 2 1
4
1 2 3 4
8
3 5 2 5 1 2 1 4
```

### 输出 #1

```text
1
0
8
```

### 样例解释

第一组数据 $[1,2,1]$：把 $A_1$、$A_3$ 染红，$A_2$ 染蓝（`121`），$C_3=1$，得分 $1$。其他方案得分均为 $0$。

第二组数据 $[1,2,3,4]$：所有数互不相同，任何方案得分都是 $0$。

第三组数据：一种最优染色为 $A_1,A_2,A_4,A_5,A_7$ 染红，$A_3,A_6,A_8$ 染蓝（`35251214`），对应 $C=[0,0,0,5,0,1,2,0]$，得分 $8$。

## 四、数据范围

- $1 \le T \le 10$；
- $2 \le n \le 2 \times 10^5$；
- $1 \le A_i \le 10^6$；
- 时间限制 1s，空间限制 512MB。

（注：$A_i$ 最大 $10^6$，得分可达 $2\times 10^5 \times 10^6 = 2\times 10^{11}$，**必须使用 64 位整数**。）

## 五、核心思路

### 5.1 关键观察

只有"**某一对相同数值被染成同色，且中间没有同色干扰**"时才会产生贡献。

具体地，若 $A_i$ 产生贡献 $A_i$，则它左侧最近且与它同色的数 $A_j$ 必须满足 $A_j = A_i$，并且 $j$ 与 $i$ 之间不能有与它们同色的数（否则"最靠近的同色数"就不是 $A_j$ 了）。于是 $j$ 到 $i$ 之间的数只能全部染成**另一种颜色**。

因此，一次贡献对应一条"线段"：

> 把 $A_p$ 与 $A_i$（$A_p = A_i$）染成同色，中间 $(p, i)$ 全部染成异色，获得贡献 $A_i$。

选出的贡献线段之间**不能相交**（共享位置的数不可能同时满足两条线段的染色约束），但可以相离或相邻。问题转化为：在一维线段上选择一组互不相交的线段，使权值和最大——这是经典的加权区间调度，可以 $O(n)$ DP。

### 5.2 只考虑"上一个相同数"

如果 $A_i$ 要产生贡献，配对的 $p$ 一定是**它左边最近的一个相同数**（记作 $lst_i$）。因为若取更早的 $p' < p$，配对区间 $[p', i]$ 会更大，中间被迫染异色的数更多，且 $p$ 本身如果保留也不可能再产生贡献，结果只会更差。因此只需维护每个值上一次出现的位置。

### 5.3 DP 状态与转移

设：

- $f_i$：处理完前 $i$ 个数的最大得分；
- $s_i$：前 $i$ 个数**全部染成同一种颜色**时的得分，即
  $$s_i = s_{i-1} + A_i \times [A_{i-1} = A_i]$$
  它表示相邻相同数的累加贡献（前缀和形式）。

对第 $i$ 个数，要么不产生贡献，要么与 $lst_i$ 配对产生贡献：

1. **不产生贡献**：$f_i$ 至少为 $f_{i-1}$。
2. **产生贡献**：设 $p = lst_i$（要求 $p \ge 1$），将 $A_p$ 与 $A_i$ 染成同色，则 $(p, i)$ 中所有数被迫染成另一种颜色，特别是位置 $p+1$：
   - $[1, p+1]$ 部分的最优解为 $f_{p+1}$（两种颜色完全对称，所以直接取 $f_{p+1}$ 即可；该前缀中 $p+1$ 的位置是"异色段的开头"，$f_{p+1}$ 的最优方案可以满足这一要求）；
   - 中间 $p+1 \sim i-1$ 全部染异色，贡献为 $s_{i-1} - s_{p+1}$（即其中相邻相同数的贡献，取 $\max(\cdot, 0)$ 防止负值）；
   - 第 $i$ 位贡献 $A_i$。

于是：

$$f_i = \max\left(f_{i-1},\ f_{p+1} + A_i + \max(s_{i-1} - s_{p+1},\ 0)\right) \quad (p = lst_i)$$

注意这里必须用 $f_{p+1}$ 而不是 $f_p$：因为 $p+1$ 被强制染成了与 $A_p$、$A_i$ 不同的颜色，它不能被当作自由前缀的一部分。

### 5.4 边界情况：相邻相同数

当 $A_i = A_{i-1}$ 时，$p = i-1$，中间区间为空，$s_{i-1} - s_{p+1} = 0$，转移变为：

$$f_i = \max(f_{i-1},\ f_i + A_i) = f_{i-1} + A_i$$

这正好对应"相邻相同数必须同色、必定获得贡献"。实现时无需特判，公式天然正确。

### 5.5 复杂度

每项 $O(1)$ 转移，总复杂度 $O(n)$，空间 $O(n + \max A)$（`last` 数组按值域开，$10^6$ 级别）。

## 六、正确性说明

**为什么取 $lst_i$ 最优**：假设最优方案中 $A_i$ 与更早的 $p'$ 配对（$p' < p = lst_i$），则 $A_p$ 在 $p'$ 与 $i$ 之间。若 $A_p$ 染与 $A_i$ 同色，则它与 $A_i$ 更近，$A_i$ 的"最近同色"就不是 $p'$，方案非法；若 $A_p$ 染异色，则把配对改为 $p$ 后，$p'$ 失去贡献但 $p$ 获得贡献，中间被迫染异色的区间反而缩短，结果不可能变差。故只需考虑最近的上一个相同数。

**为什么转移式成立**：$A_i$ 产生贡献时，$(p,i)$ 中所有数必须染异色，因此它们两两之间不能产生任何同色贡献，其贡献恰好是"整段同色前缀和"之差 $s_{i-1}-s_p$；$[1,p]$ 部分与后面的染色相互独立，取最优 $f_p$ 即可。

## 七、参考代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

const int MAXN = 200005;
const int MAXV = 1000005;

int a[MAXN];
int lst[MAXV]; // 每个值最近一次出现的位置
ll f[MAXN];    // 处理完前 i 个数的最大得分
ll s[MAXN];    // 前 i 个数全部同色的得分（相邻相同数贡献的前缀和）

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        for (int i = 1; i <= n; i++) {
            cin >> a[i];
        }

        // 计算 s：全染同色的贡献
        for (int i = 1; i <= n; i++) {
            s[i] = s[i - 1] + (a[i] == a[i - 1] ? a[i] : 0);
        }

        for (int i = 1; i <= n; i++) {
            f[i] = f[i - 1]; // 不产生贡献
            int p = lst[a[i]];
            if (p) {
                // 与最近的上一个相同数 p 配对：
                // f[p+1] + 中间整段异色贡献(s[i-1]-s[p+1]) + 第 i 位贡献 a[i]
                ll mid = s[i - 1] - s[p + 1];
                if (mid < 0) mid = 0;
                ll cand = f[p + 1] + a[i] + mid;
                f[i] = max(f[i], cand);
            }
            lst[a[i]] = i; // 更新最近出现位置
        }

        cout << f[n] << '\n';

        // 只清空本次用到的值，避免 O(值域) 清空
        for (int i = 1; i <= n; i++) {
            lst[a[i]] = 0;
            f[i] = s[i] = 0;
        }
    }
    return 0;
}
```

## 八、另一种理解：加权区间调度

可以把每个"可能的配对"看成线段：

- 端点：位置 $p = lst_i$ 与 $i$（$A_p = A_i$）；
- 权值：$A_i$；
- 若 $A_i = A_{i-1}$（相邻），权值直接累加进答案，因为相邻同色必得贡献且不影响其他配对。

题目即求**不相交线段的权值和最大值**。按右端点（即下标 $i$）扫描，维护：

$$dp_i = \max(dp_{i-1},\ dp_{lst_i} + A_i)$$

再加上"相邻相同数"的强制贡献即可。这一理解与第五节的形式等价（差分 $s$ 前缀和正是处理中间段被强制染异色后的剩余贡献）。

## 九、易错点

1. **64 位整数**：$A_i \le 10^6$、$n \le 2\times 10^5$，答案最大约 $2\times 10^{11}$，用 `long long`。
2. **值域开数组**：$A_i \le 10^6$，`last` 数组要开到 $10^6+5$；每组数据只需清空用过的位置，不要对整个值域 `memset`（会超时）。
3. **"最近同色"语义**：贡献要求最近同色数数值相同，因此配对必须选最近的上一个相同数，不能随意选更早的。
4. **多测清空**：`lst`、`f`、`s` 都要恢复初值。
