# P9754 [CSP-S 2023] 结构体 题解

## 题目大意

模拟一个 C 风格的结构体系统，支持四种操作：
1. 定义结构体类型：包含若干成员，每个成员有类型名和名称，需要按对齐规则排列
2. 定义元素：在全局作用域中定义一个指定类型的变量
3. 访问元素：给定一个元素路径（如 `a.b.c`），输出其起始地址
4. 地址查询：给定一个地址，输出其对应的元素路径（若地址位于某个基本类型元素内）

对齐规则：每个成员的对齐要求为其类型的对齐要求，成员起始地址必须是其对齐要求的整数倍。结构体的大小必须是其对齐要求的整数倍（即结构体末尾可能有填充）。

---

## 解题思路

### 核心数据结构

**类型系统**：维护一个 `map<string, TypeInfo>` 记录每种类型的成员列表、大小和对齐要求。基本类型（`byte`, `short`, `int`, `long`）的大小和对齐分别为 $1,1$、$2,2$、$4,4$、$8,8$。

**全局元素表**：维护一个 `vector<Element>` 记录每个已定义元素的名称、类型和起始地址。全局起始地址从 $0$ 开始，每个元素按对齐规则放置。

**地址查询**：用一个 `map<long long, pair<string, int>>` 维护每个基本类型元素占据的地址区间。键为起始地址，值为（元素名称，元素大小）。查询时用 `upper_bound` 找到包含目标地址的区间。

### 算法

1. **定义结构体**：解析成员列表，逐个放置成员。维护当前偏移量，每个成员放置在对齐边界上。结构体大小为最后一个成员末尾对齐到结构体对齐要求。

2. **定义元素**：在全局地址空间中按对齐规则放置，记录到元素表和地址映射表。

3. **访问元素**：按路径逐级解析，沿类型成员列表计算偏移量，最终输出全局起始地址 + 偏移量。

4. **地址查询**：在地址映射表中二分查找，输出名称路径。若地址不合法则输出 `ERR`。

## C++ 源代码

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

// 基本类型信息
struct TypeInfo {
    ll size;       // 类型大小
    ll align;      // 对齐要求
    vector<pair<string, string>> members; // (成员类型, 成员名称)
    map<string, int> member_idx;          // 成员名称 -> 成员索引
    vector<ll> member_offset;             // 每个成员的偏移量
};

map<string, TypeInfo> types;

// 全局元素
struct Element {
    string name;
    string type;
    ll addr;
};
vector<Element> elements;
map<string, int> elem_idx; // 元素名称 -> 索引

// 地址 -> (元素名称, 元素大小)
map<ll, pair<string, ll>> addr_map;

// 初始化基本类型
void init() {
    types["byte"]  = {1, 1, {}, {}, {}};
    types["short"] = {2, 2, {}, {}, {}};
    types["int"]   = {4, 4, {}, {}, {}};
    types["long"]  = {8, 8, {}, {}, {}};
}

// 操作 1：定义结构体
void define_struct() {
    string name;
    int k;
    cin >> name >> k;
    TypeInfo &ti = types[name];
    ti.size = 0;
    ti.align = 1;
    ll offset = 0;
    for (int i = 0; i < k; i++) {
        string mtype, mname;
        cin >> mtype >> mname;
        TypeInfo &mt = types[mtype];
        // 对齐
        ll aligned = (offset + mt.align - 1) / mt.align * mt.align;
        ti.members.push_back({mtype, mname});
        ti.member_idx[mname] = i;
        ti.member_offset.push_back(aligned);
        offset = aligned + mt.size;
        ti.align = max(ti.align, mt.align);
    }
    // 结构体大小对齐
    ti.size = (offset + ti.align - 1) / ti.align * ti.align;
    cout << ti.size << " " << ti.align << "\n";
}

// 操作 2：定义元素
void define_element() {
    string etype, ename;
    cin >> etype >> ename;
    TypeInfo &ti = types[etype];
    // 全局起始地址（从 0 开始）
    static ll global_offset = 0;
    ll aligned = (global_offset + ti.align - 1) / ti.align * ti.align;
    elements.push_back({ename, etype, aligned});
    elem_idx[ename] = elements.size() - 1;
    // 记录地址映射（仅基本类型或递归展开）
    addr_map[aligned] = {ename, ti.size};
    global_offset = aligned + ti.size;
    cout << aligned << "\n";
}

// 获取元素路径的起始地址
ll get_addr(const string &path) {
    // 解析第一段
    size_t dot = path.find('.');
    string first = (dot == string::npos) ? path : path.substr(0, dot);
    string rest = (dot == string::npos) ? "" : path.substr(dot + 1);

    int eid = elem_idx[first];
    ll base = elements[eid].addr;
    string cur_type = elements[eid].type;

    // 逐级解析
    while (!rest.empty()) {
        dot = rest.find('.');
        string member = (dot == string::npos) ? rest : rest.substr(0, dot);
        rest = (dot == string::npos) ? "" : rest.substr(dot + 1);

        TypeInfo &ti = types[cur_type];
        int mid = ti.member_idx[member];
        base += ti.member_offset[mid];
        cur_type = ti.members[mid].first;
    }
    return base;
}

// 操作 3：访问元素
void access_element() {
    string path;
    cin >> path;
    cout << get_addr(path) << "\n";
}

// 操作 4：地址查询
// 递归查找地址 addr 在类型 type 的哪个成员中，size 是该类型实例的大小
string find_addr(ll addr, const string &type_name, ll base, const string &prefix) {
    TypeInfo &ti = types[type_name];
    // 检查是否超出范围
    if (addr < base || addr >= base + ti.size) return "ERR";

    // 如果是基本类型，直接返回
    if (ti.members.empty()) {
        return prefix;
    }

    // 在成员中查找
    for (int i = 0; i < (int)ti.members.size(); i++) {
        ll member_base = base + ti.member_offset[i];
        string &mtype = ti.members[i].first;
        TypeInfo &mt = types[mtype];
        if (addr >= member_base && addr < member_base + mt.size) {
            string new_prefix = prefix.empty() ? ti.members[i].second
                                                : prefix + "." + ti.members[i].second;
            return find_addr(addr, mtype, member_base, new_prefix);
        }
    }
    return "ERR";
}

void query_addr() {
    ll addr;
    cin >> addr;
    // 在全局元素中查找
    auto it = addr_map.upper_bound(addr);
    if (it == addr_map.begin()) {
        cout << "ERR\n";
        return;
    }
    --it;
    ll base = it->first;
    string ename = it->second.first;
    ll esize = it->second.second;
    if (addr >= base + esize) {
        cout << "ERR\n";
        return;
    }
    string etype = elements[elem_idx[ename]].type;
    string result = find_addr(addr, etype, base, ename);
    cout << result << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init();

    int q;
    cin >> q;
    while (q--) {
        int op;
        cin >> op;
        if (op == 1) {
            define_struct();
        } else if (op == 2) {
            define_element();
        } else if (op == 3) {
            access_element();
        } else {
            query_addr();
        }
    }

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(q \cdot k)$，$q$ 为操作数，$k$ 为结构体成员数。定义结构体时需遍历成员，访问元素时沿路径递归查找，地址查询时二分查找后在成员列表中线性扫描。
- **空间复杂度**：$O(\sum k + q)$，存储所有类型信息和元素信息。

---

## 关键点

1. **对齐规则**：每个成员的起始地址必须是其类型对齐要求的整数倍，结构体大小也需对齐。
2. **类型系统**：用 `map` 维护类型名到类型信息的映射，支持递归定义。
3. **地址映射**：用 `map` 维护全局地址区间到元素名的映射，支持地址反查。
4. **路径解析**：访问元素时逐级沿类型成员偏移量计算地址；地址查询时递归深入类型成员。
