# P8817 [CSP-S 2022] 假期计划 题解

## 题目大意

$n$ 个点（$1$ 号点是家），选择 $4$ 个不同的景点 $A,B,C,D$（均不为 $1$），使得路径 $1 \to A \to B \to C \to D \to 1$ 中每段转车次数不超过 $k$ 次，最大化四个景点的分数之和。

---

## 解题思路

### 核心观察

每段路径转车次数 $\le k$，等价于两点之间的最短路径长度 $\le k+1$（转 $k$ 次车 = 经过 $k+1$ 条边）。因此首先需要求出所有点对之间是否在 $k+1$ 步内可达。

### 算法

**第一步：BFS 预处理可达性**

因为 $n \le 2500$，可以从每个点出发做一次 BFS，标记所有距离 $\le k+1$ 的点为可达。由于每条边权为 $1$，BFS 的复杂度为 $O(n(n+m))$。

**第二步：预处理每个点的 Top 3**

对于每个景点 $i$（$2 \le i \le n$），找出所有与 $i$ 互相可达（距离 $\le k+1$）的景点中分数最高的 $3$ 个，记为 $\text{top3}[i]$。只保留 $3$ 个是因为：后续枚举 $B$ 和 $C$ 时，需要从 $B$ 的可达集合中选 $A$、从 $C$ 的可达集合中选 $D$，且 $A,B,C,D$ 互不相同。因为最多只有 $2$ 个冲突（$A$ 可能与 $C$ 或 $D$ 冲突），保留 $3$ 个候选足够保证存在合法解。

**第三步：枚举 B 和 C**

枚举所有 $B, C$（$2 \le B, C \le n$，$B \neq C$ 且 $B$ 与 $C$ 互相可达），在 $\text{top3}[B]$ 中选 $A$，在 $\text{top3}[C]$ 中选 $D$，要求 $1 \to A$ 和 $D \to 1$ 均可达，且 $A,B,C,D$ 互不相同。取最大分数和。

## C++ 源代码

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

const int MAXN = 2505;
int n, m, k;
ll score[MAXN];
vector<int> adj[MAXN];
bool reachable[MAXN][MAXN];  // reachable[i][j]: j 在 i 的 k+1 步内可达
int dist[MAXN];

// BFS 从起点 s 出发，标记所有距离 <= k+1 的点
void bfs(int s) {
    memset(dist, -1, sizeof(dist));
    queue<int> q;
    q.push(s);
    dist[s] = 0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        if (dist[u] > k) break;
        for (int v : adj[u]) {
            if (dist[v] == -1) {
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
    }
    for (int i = 1; i <= n; i++) {
        if (dist[i] != -1 && dist[i] <= k + 1) {
            reachable[s][i] = true;
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m >> k;
    for (int i = 2; i <= n; i++) {
        cin >> score[i];
    }
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    for (int i = 1; i <= n; i++) {
        bfs(i);
    }

    vector<vector<int>> top3(n + 1);
    for (int i = 1; i <= n; i++) {
        vector<pair<ll, int>> cand;
        for (int j = 2; j <= n; j++) {
            if (i != j && reachable[i][j]) {
                cand.push_back({score[j], j});
            }
        }
        sort(cand.begin(), cand.end(), greater<pair<ll, int>>());
        for (int t = 0; t < min(3, (int)cand.size()); t++) {
            top3[i].push_back(cand[t].second);
        }
    }

    ll ans = 0;
    for (int B = 2; B <= n; B++) {
        for (int C = 2; C <= n; C++) {
            if (B == C || !reachable[B][C]) continue;
            for (int A : top3[B]) {
                if (A == B || A == C) continue;
                for (int D : top3[C]) {
                    if (D == A || D == B || D == C) continue;
                    if (reachable[1][A] && reachable[D][1]) {
                        ans = max(ans, score[A] + score[B] + score[C] + score[D]);
                    }
                }
            }
        }
    }

    cout << ans << "\n";
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(n^2 + n \cdot m)$。BFS 部分 $O(n(n+m))$；Top 3 排序 $O(n^2 \log n)$（可优化为 $O(n^2)$）；枚举 $B,C$ 和 Top 3 组合 $O(n^2 \times 9)$。在 $n \le 2500$ 时可以接受。
- **空间复杂度**：$O(n^2)$，主要存储可达性矩阵。

---

## 关键点

1. **BFS 距离**：转车 $k$ 次对应 $k+1$ 条边，因此 BFS 需要标记距离 $\le k+1$ 的点。
2. **Top 3 剪枝**：只需保留每个点可达的分数最高的 $3$ 个景点即可保证找到最优解，将枚举量从 $O(n^4)$ 降至 $O(n^2)$。
3. **路径对称性**：无向图中 $1 \to A$ 可达等价于 $A \to 1$ 可达，无需额外处理。
4. **去重检查**：$A,B,C,D$ 必须互不相同，在枚举时逐层检查。
