# P7075 [CSP-S 2020] 儒略日 题解

## 题目大意

给定儒略日 $r$（从公元前 4713 年 1 月 1 日正午开始的天数），转换为公历日期。需处理儒略历（1582 年 10 月 4 日前）和格里高利历（1582 年 10 月 15 日后）两套历法，以及公元前无公元零年的规则。

---

## 解题思路

### 分段处理

| 儒略日范围 | 历法 | 闰年规则 |
|-----------|------|---------|
| $r < 2299161$ | 儒略历 | 年份是 4 的倍数 |
| $r \ge 2299161$ | 格里高利历 | 年份是 400 的倍数，或 4 的倍数但非 100 的倍数 |

（JD 2299160 = 1582/10/4 儒略历，JD 2299161 = 1582/10/15 格里高利历，中间 10 天被删除。）

### 天文纪年法

令公元前 1 年 = 年份 0，公元前 2 年 = 年份 $-1$，则公元 $y$ 年 = 年份 $y$。此法下公元零年存在（即公元前 1 年），闰年判断统一为模运算。

### 求年公式

**儒略历**：JD 0 = 年份 $-4712$ 的 1 月 1 日。从年份 $-4712$ 到年份 $y$ 的 1 月 1 日的天数为：

$$\text{days}_{J}(y) = 365(y + 4712) + \left\lfloor \frac{y - 1}{4} \right\rfloor + 1179$$

**格里高利历**：年份 $y$ 的 1 月 1 日的 JD 为：

$$\text{JD}_{G}(y) = 365(y-1) + \left\lfloor \frac{y-1}{4} \right\rfloor - \left\lfloor \frac{y-1}{100} \right\rfloor + \left\lfloor \frac{y-1}{400} \right\rfloor + 1721426$$

对 $r$ 二分查找年份 $y$，再计算月日。

### 输出格式

年份 $\le 0$ 时为公元前，输出 `Day Month Year BC`（Year 取绝对值）；年份 $> 0$ 时输出 `Day Month Year`。

## C++ 源代码

```cpp
#include <iostream>
using namespace std;

typedef long long ll;

int monthDays[] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

bool isLeapJulian(ll y) { return y % 4 == 0; }
bool isLeapGregorian(ll y) {
    return y % 400 == 0 || (y % 4 == 0 && y % 100 != 0);
}

// 儒略历: JD of Jan 1, year y (astronomical)
ll jdJan1Julian(ll y) {
    return 365LL * (y + 4712) + (y - 1) / 4 + 1179;
}

// 格里高利历: JD of Jan 1, year y (astronomical)
ll jdJan1Gregorian(ll y) {
    return 365LL * (y - 1) + (y - 1) / 4 - (y - 1) / 100 + (y - 1) / 400 + 1721426;
}

void solve(ll r) {
    ll year, doy;  // doy = day of year (0-indexed)
    bool useJulian;

    if (r < 2299161) {
        useJulian = true;
        // 二分年份
        ll lo = -4712, hi = 1582;
        while (lo < hi) {
            ll mid = (lo + hi + 1) / 2;
            if (jdJan1Julian(mid) <= r) lo = mid;
            else hi = mid - 1;
        }
        year = lo;
        doy = r - jdJan1Julian(year);
    } else {
        useJulian = false;
        ll lo = 1582, hi = 1e9;
        while (lo < hi) {
            ll mid = (lo + hi + 1) / 2;
            if (jdJan1Gregorian(mid) <= r) lo = mid;
            else hi = mid - 1;
        }
        year = lo;
        doy = r - jdJan1Gregorian(year);
    }

    bool leap = useJulian ? isLeapJulian(year) : isLeapGregorian(year);
    int month = 1;
    for (int m = 1; m <= 12; ++m) {
        int days = monthDays[m];
        if (m == 2 && leap) days = 29;
        if (doy < days) { month = m; break; }
        doy -= days;
    }
    int day = (int)doy + 1;

    if (year <= 0)
        cout << day << " " << month << " " << (1 - year) << " BC\n";
    else
        cout << day << " " << month << " " << year << "\n";
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int Q;
    cin >> Q;
    while (Q--) {
        ll r;
        cin >> r;
        solve(r);
    }
    return 0;
}
```

---

## 复杂度分析

- **时间复杂度**：$\mathcal{O}(Q \log Y)$，$Y$ 为年份范围（约 $10^9$），每个查询二分查找年份。
- **空间复杂度**：$\mathcal{O}(1)$。

---

## 关键点

1. **天文纪年法**：公元前 1 年记为年份 0，使闰年判断统一为模运算，避免 BC/AD 边界特判。
2. **历法分界**：JD 2299160→2299161 对应 1582/10/4→10/15，中间 10 天不存在。
3. **二分求年**：用公式计算每年 1 月 1 日的 JD，二分找到 $r$ 所在年份，再逐月减去天数求月日。
