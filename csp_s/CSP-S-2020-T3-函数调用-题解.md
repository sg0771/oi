# P7077 [CSP-S 2020] 函数调用 题解

## 题目大意

有 $n$ 个数据 $a_1, a_2, \ldots, a_n$。$m$ 个函数，分为三种类型：
- **类型 1**：单点加值，对 $a_{p}$ 加上 $v$。
- **类型 2**：全局乘值，将所有 $a_i$ 乘以 $v$。
- **类型 3**：依次调用 $c$ 个其他函数（保证不形成递归）。

$Q$ 次操作，每次按序列调用若干函数。求最终所有数据的值，对 $998244353$ 取模。

---

## 解题思路

### 核心观察

问题可以建模为一张 **DAG**（有向无环图），节点是函数，边表示调用关系。关键观察：

1. **乘法的影响是全局的**：一个类型 2 函数不仅影响当前数据，还会"放大"所有在它之前执行的类型 1 函数的贡献。
2. **只需计算每个函数的"等效执行次数"**：若知道每个类型 1 函数被"等效执行"了多少次（考虑后续乘法放大），则可以直接计算最终答案。

### 算法步骤

**第一步：建图与拓扑排序**

- 对每个类型 3 函数 $u$，它调用 $v_1, v_2, \ldots, v_k$，建有向边 $u \to v_i$（表示 $u$ 依赖 $v_i$）。
- 统计入度，进行拓扑排序得到拓扑序。

**第二步：自底向上计算乘法倍数 `mul[i]`**

- 对于类型 1：`mul[i] = 1`（加法不改变乘法倍数）
- 对于类型 2：`mul[i] = v`
- 对于类型 3：`mul[i] = mul[v_1] * mul[v_2] * ... * mul[v_k]`（按拓扑序从叶子向上计算）

**第三步：自顶向下计算执行次数 `cnt[i]`**

- 处理 $Q$ 次操作时，从后往前处理：维护后缀乘积 `prod`，每次 `cnt[f] += prod`，然后 `prod *= mul[f]`。
- 对于类型 3 函数，将其 `cnt` 按**逆序**传播给子函数：维护 `prod = 1`，对每个子函数 $g$（从后往前），`cnt[g] += cnt[u] * prod`，`prod *= mul[g]`。

**第四步：计算最终答案**

- 总乘法倍数 `total_mul = mul[op_1] * mul[op_2] * ... * mul[op_Q]`
- 对每个位置 $i$：$a_i = a_i \times \text{total\_mul} + \sum_{f \in \text{type1 at position } i} \text{cnt}[f] \times \text{val}[f]$

### 关键理解：为什么逆序传播

类型 3 函数按顺序调用子函数 $v_1, v_2, \ldots, v_k$。$v_1$ 的贡献会被 $v_2, \ldots, v_k$ 的乘法放大。因此需要从后往前处理，维护后缀乘积。

## C++ 源代码

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
const int MOD = 998244353;
const int MAXN = 100005;
const int MAXM = 100005;

int n, m, Q;
int a[MAXN];
int type[MAXM];           // 1: add, 2: mul, 3: call
int pos[MAXM], val[MAXM]; // for type 1: position and value; for type 2: multiplier
vector<int> calls[MAXM];  // for type 3: called functions
int in_deg[MAXM];
int mul[MAXM];            // multiplication factor of each function
int cnt[MAXM];            // execution count of each function
vector<int> g[MAXM];      // reverse edges: who calls me
int add_contrib[MAXN];    // total add contribution for each position

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    // ---- read input ----
    cin >> n;
    for (int i = 1; i <= n; ++i) cin >> a[i];

    cin >> m;
    for (int i = 1; i <= m; ++i) {
        cin >> type[i];
        if (type[i] == 1) {
            cin >> pos[i] >> val[i];
            mul[i] = 1;
        } else if (type[i] == 2) {
            cin >> val[i];
            mul[i] = val[i];
        } else {
            int c; cin >> c;
            calls[i].resize(c);
            for (int j = 0; j < c; ++j) {
                cin >> calls[i][j];
                int v = calls[i][j];
                g[v].push_back(i);   // v is called by i
                in_deg[i]++;
            }
            mul[i] = 1;
        }
    }

    cin >> Q;
    vector<int> ops(Q);
    for (int i = 0; i < Q; ++i) cin >> ops[i];

    // ---- topological sort ----
    // edges: caller -> callee. in_deg of callee increases.
    // We need callee processed before caller, so leaves first.
    queue<int> q;
    for (int i = 1; i <= m; ++i)
        if (in_deg[i] == 0) q.push(i);

    vector<int> topo;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        topo.push_back(u);
        for (int v : g[u]) { // v calls u
            if (--in_deg[v] == 0) q.push(v);
        }
    }

    // ---- step 1: compute mul[i] bottom-up (topological order) ----
    for (int u : topo) {
        if (type[u] == 3) {
            ll prod = 1;
            for (int v : calls[u]) {
                prod = prod * mul[v] % MOD;
            }
            mul[u] = (int)prod;
        }
    }

    // ---- step 2: compute cnt[i] top-down (reverse topological order) ----
    // First, process the Q operations
    ll suffix_prod = 1;
    for (int i = Q - 1; i >= 0; --i) {
        int f = ops[i];
        cnt[f] = (cnt[f] + suffix_prod) % MOD;
        suffix_prod = suffix_prod * mul[f] % MOD;
    }

    // Then, propagate cnt through type-3 functions
    for (int i = (int)topo.size() - 1; i >= 0; --i) {
        int u = topo[i];
        if (type[u] == 3 && cnt[u] > 0) {
            ll prod = 1;
            // process callees in reverse order
            for (int j = (int)calls[u].size() - 1; j >= 0; --j) {
                int v = calls[u][j];
                cnt[v] = (cnt[v] + (ll)cnt[u] * prod) % MOD;
                prod = prod * mul[v] % MOD;
            }
        }
    }

    // ---- step 3: compute final answer ----
    int total_mul = (int)suffix_prod; // suffix_prod after processing all Q ops

    for (int i = 1; i <= n; ++i) {
        a[i] = (ll)a[i] * total_mul % MOD;
    }

    for (int i = 1; i <= m; ++i) {
        if (type[i] == 1) {
            int p = pos[i];
            a[p] = (a[p] + (ll)cnt[i] * val[i]) % MOD;
        }
    }

    for (int i = 1; i <= n; ++i) {
        cout << a[i] << (i == n ? '\n' : ' ');
    }

    return 0;
}
```

---

## 复杂度分析

- **时间复杂度**：$\mathcal{O}(n + m + Q + \sum C_j)$，其中 $\sum C_j$ 是所有类型 3 函数调用的子函数个数之和。建图、拓扑排序、两遍 DAG 遍历均为线性。
- **空间复杂度**：$\mathcal{O}(n + m + \sum C_j)$，存储图、拓扑序和各函数的参数。

---

## 关键点

1. **DAG 建模**：将函数调用关系转化为有向无环图，利用拓扑排序处理依赖。
2. **自底向上计算 mul**：先计算每个函数的乘法倍数，叶子节点（类型 1/2）的 mul 已知，类型 3 的 mul 为其子函数 mul 的乘积。
3. **逆序传播 cnt**：乘法会影响之前执行的加法，因此 cnt 的传播需要逆序处理，维护后缀乘积。Q 次操作和类型 3 内部调用都需要逆序。
4. **最终贡献**：每个位置最终值 = 初始值乘以总乘法倍数 + 所有作用在该位置的加法贡献之和。
5. **取模注意**：所有乘法运算使用 `long long` 中间结果再取模，避免溢出。
