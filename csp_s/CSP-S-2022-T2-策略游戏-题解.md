# P8818 [CSP-S 2022] 策略游戏 题解

## 题目大意

给定长度为 $n$ 的数组 $A$ 和长度为 $m$ 的数组 $B$，定义 $C_{ij} = A_i \times B_j$。有 $q$ 次询问，每次给定 $l_1, r_1, l_2, r_2$，L 先在 $A[l_1, r_1]$ 中选一个下标 $i$，Q 后在 $B[l_2, r_2]$ 中选一个下标 $j$。L 希望最大化 $C_{ij}$，Q 希望最小化 $C_{ij}$。两人都采取最优策略，求最终得分。

---

## 解题思路

### 核心观察

这是一个典型的**零和博弈**问题。L 先选 $A_i$，Q 后选 $B_j$。Q 知道 L 的选择后，会选使 $C_{ij}$ 最小的 $B_j$。L 预判 Q 的策略，会选择使这个最小值最大的 $A_i$。

对于固定的 $A_i$：
- 若 $A_i \ge 0$：Q 会选择 $B$ 区间中的最小值 $\min B$，得分为 $A_i \times \min B$。
- 若 $A_i < 0$：Q 会选择 $B$ 区间中的最大值 $\max B$，得分为 $A_i \times \max B$。

L 需要在 $A$ 区间中选一个值，使得上述得分最大。设 $A$ 区间中：
- $\text{max\_pos}$：最大正数
- $\text{min\_pos}$：最小正数
- $\text{max\_neg}$：最大负数（绝对值最小）
- $\text{min\_neg}$：最小负数（绝对值最大）
- $\text{has\_zero}$：是否包含 $0$

L 的最优选择一定在 $\{\text{max\_pos}, \text{min\_pos}, \text{max\_neg}, \text{min\_neg}, 0\}$ 中。只需枚举这 $5$ 个候选值，计算对应得分取最大值。

### 算法

使用**线段树**分别维护 $A$ 和 $B$ 的区间信息：
- $A$ 的线段树维护：最大正数、最小正数、最大负数、最小负数、是否含 $0$。
- $B$ 的线段树维护：最大值、最小值。

对于每个询问，在线段树上查询 $A[l_1, r_1]$ 和 $B[l_2, r_2]$，然后枚举 $A$ 的候选值计算答案。

## C++ 源代码

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
const ll INF = 1e18;

// ---------- A 的线段树节点 ----------
struct NodeA {
    ll max_pos, min_pos;  // 正数的最大值和最小值
    ll max_neg, min_neg;  // 负数的最大值（最接近 0）和最小值（最远离 0）
    bool has_zero;

    NodeA() {
        max_pos = -INF; min_pos = INF;
        max_neg = -INF; min_neg = INF;
        has_zero = false;
    }

    void set(ll x) {
        max_pos = -INF; min_pos = INF;
        max_neg = -INF; min_neg = INF;
        has_zero = false;
        if (x > 0)      max_pos = min_pos = x;
        else if (x < 0) max_neg = min_neg = x;
        else            has_zero = true;
    }
};

NodeA mergeA(const NodeA& a, const NodeA& b) {
    NodeA res;
    res.max_pos = max(a.max_pos, b.max_pos);
    res.min_pos = min(a.min_pos, b.min_pos);
    res.max_neg = max(a.max_neg, b.max_neg);
    res.min_neg = min(a.min_neg, b.min_neg);
    res.has_zero = a.has_zero || b.has_zero;
    return res;
}

// ---------- B 的线段树节点 ----------
struct NodeB {
    ll max_val, min_val;
    NodeB() { max_val = -INF; min_val = INF; }
    void set(ll x) { max_val = min_val = x; }
};

NodeB mergeB(const NodeB& a, const NodeB& b) {
    NodeB res;
    res.max_val = max(a.max_val, b.max_val);
    res.min_val = min(a.min_val, b.min_val);
    return res;
}

// ---------- 线段树模板 ----------
template<typename T, typename MergeFunc>
struct SegTree {
    int n;
    vector<T> tree;
    MergeFunc merge;

    SegTree(int n, const vector<ll>& arr, MergeFunc m) : n(n), merge(m) {
        tree.resize(4 * n);
        build(1, 0, n - 1, arr);
    }

    void build(int node, int l, int r, const vector<ll>& arr) {
        if (l == r) {
            tree[node].set(arr[l]);
            return;
        }
        int mid = (l + r) / 2;
        build(node * 2, l, mid, arr);
        build(node * 2 + 1, mid + 1, r, arr);
        tree[node] = merge(tree[node * 2], tree[node * 2 + 1]);
    }

    T query(int node, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return tree[node];
        int mid = (l + r) / 2;
        if (qr <= mid) return query(node * 2, l, mid, ql, qr);
        if (ql > mid)  return query(node * 2 + 1, mid + 1, r, ql, qr);
        return merge(query(node * 2, l, mid, ql, qr),
                     query(node * 2 + 1, mid + 1, r, ql, qr));
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, q;
    cin >> n >> m >> q;

    vector<ll> A(n), B(m);
    for (int i = 0; i < n; i++) cin >> A[i];
    for (int i = 0; i < m; i++) cin >> B[i];

    SegTree<NodeA, NodeA(*)(const NodeA&, const NodeA&)> segA(n, A, mergeA);
    SegTree<NodeB, NodeB(*)(const NodeB&, const NodeB&)> segB(m, B, mergeB);

    while (q--) {
        int l1, r1, l2, r2;
        cin >> l1 >> r1 >> l2 >> r2;
        l1--; r1--; l2--; r2--;

        NodeA na = segA.query(1, 0, n - 1, l1, r1);
        NodeB nb = segB.query(1, 0, m - 1, l2, r2);

        // 收集 A 区间中的候选值
        vector<ll> candA;
        if (na.max_pos != -INF) candA.push_back(na.max_pos);
        if (na.min_pos != INF)  candA.push_back(na.min_pos);
        if (na.max_neg != -INF) candA.push_back(na.max_neg);
        if (na.min_neg != INF)  candA.push_back(na.min_neg);
        if (na.has_zero)        candA.push_back(0);

        ll ans = -INF;
        for (ll ai : candA) {
            // Q 的最优选择
            ll qj = (ai >= 0) ? nb.min_val : nb.max_val;
            ans = max(ans, ai * qj);
        }
        cout << ans << "\n";
    }

    return 0;
}
```

---

## 复杂度分析

- **时间复杂度**：$O((n + m + q) \log n)$。建树 $O(n + m)$，每次查询 $O(\log n + \log m)$，候选值枚举 $O(1)$。
- **空间复杂度**：$O(n + m)$ 存储线段树。

---

## 关键点

1. **博弈分析**：L 先选，Q 后选。L 预判 Q 最小化策略，选择使最坏情况最优的 $A_i$。
2. **候选值剪枝**：$A$ 区间中最优值一定在正数极值、负数极值、$0$ 这 $5$ 个候选中，不需要枚举整个区间。
3. **分情况讨论**：$A_i \ge 0$ 时 Q 选 $\min B$，$A_i < 0$ 时 Q 选 $\max B$。
4. **线段树维护**：分别维护 $A$ 的正数/负数极值和 $B$ 的最值，支持区间查询。
