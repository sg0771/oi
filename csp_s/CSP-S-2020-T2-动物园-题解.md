# P7076 [CSP-S 2020] 动物园 题解

## 题目大意

$2^k$ 种动物（编号 $0 \sim 2^k-1$），动物园现有 $n$ 种。$m$ 条饲料要求：若动物编号第 $p_j$ 位为 1，则需购买饲料 $q_j$。问还能饲养多少种动物（加入后饲料清单不变）。

---

## 解题思路

### 核心观察

一种动物 $x$ 能被加入，当且仅当：$x$ 的每一位 $p$，若该位有饲料要求且当前无动物该位为 1，则 $x$ 该位不能为 1。

换句话说，对每个有饲料要求的位 $p$：
- 若现有动物中存在某动物第 $p$ 位为 1 → 该位饲料已在购买清单中 → 新动物该位为 1 也不影响清单。
- 若现有动物中无动物第 $p$ 位为 1 → 该位饲料未购买 → 新动物该位为 1 会改变清单 → **该位被锁定为 0**。

### 算法

1. 计算现有动物编号的按位或 `mask = a_1 | a_2 | ... | a_n`。
2. 对每个饲料要求 $(p_j, q_j)$：若 `mask` 的第 $p_j$ 位为 0，则该位被锁定。
3. 统计锁定位数 $\text{locked}$。
4. 可饲养总数 = $2^{k - \text{locked}}$，还能增加 = $2^{k - \text{locked}} - n$。

### 注意

$k$ 最大 64，$2^k$ 用 `unsigned long long`。当 $k = 64$ 且 $\text{locked} = 0$ 时，$2^{64}$ 溢出，需特判。

---

## C++ 源代码

```cpp
#include <iostream>
using namespace std;

typedef unsigned long long ull;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, c, k;
    cin >> n >> m >> c >> k;

    ull mask = 0;
    for (int i = 0; i < n; ++i) {
        ull a;
        cin >> a;
        mask |= a;
    }

    // 统计锁定位
    int locked = 0;
    for (int j = 0; j < m; ++j) {
        int p, q;
        cin >> p >> q;
        if (!((mask >> p) & 1ULL)) {
            locked |= (1 << p);  // 标记锁定位
        }
    }

    // 计算锁定位数
    int lockedCount = __builtin_popcount(locked);

    // 可饲养总数 = 2^(k - lockedCount)
    int avail = k - lockedCount;
    ull total;
    if (avail >= 64) {
        total = 0;  // 溢出，但答案 = total - n，n <= 1e6，所以 total >= n
        // 实际上 2^64 溢出为 0，需要特殊处理
        // 当 avail >= 64 时，2^avail > 2^64 > n，答案 = 2^avail - n
        // 用 __int128 计算
        cout << (ull)((__int128)1 << avail) - (ull)n << "\n";
        return 0;
    } else {
        total = (1ULL << avail);
    }

    cout << total - (ull)n << "\n";

    return 0;
}
```

---

## 复杂度分析

- **时间复杂度**：$\mathcal{O}(n + m)$，读入和按位或操作。
- **空间复杂度**：$\mathcal{O}(1)$。

---

## 关键点

1. **按位或**：`mask` 汇总所有现有动物的位信息，判断哪些位的饲料已被购买。
2. **锁定位**：有饲料要求但无现有动物使用的位被锁定，新动物该位必须为 0。
3. **溢出处理**：$k = 64$ 时 $2^{64}$ 超出 `unsigned long long` 范围，用 `__int128` 计算。
