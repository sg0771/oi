# P9752 [CSP-S 2023] 密码锁 题解

## 题目大意

一个 $5$ 位密码锁，每位数字为 $0 \sim 9$。一次操作可以：
- 转动**一个**拨圈，旋转任意幅度（$1 \sim 9$ 格）
- 同时转动**两个相邻**拨圈，同方向同幅度（$1 \sim 9$ 格）

给定 $n$ 个状态（$n \le 8$），这些状态都不是正确密码，但每个状态都可以从正确密码通过恰好一次操作得到。求可能的正确密码数量。

---

## 解题思路

### 核心观察

由于密码只有 $5$ 位，总共 $10^5 = 100000$ 种可能的密码。$n \le 8$，可以暴力枚举。

### 算法

枚举所有 $10^5$ 个可能的正确密码，对每个密码检查它是否能通过恰好一次操作变成所有 $n$ 个给定状态。

一次操作共有 $81$ 种可能：
- 转一个位置：$9$ 种幅度 $\times$ $5$ 个位置 $= 45$ 种
- 转两个相邻位置：$9$ 种幅度 $\times$ $4$ 个相邻对 $= 36$ 种

对于每个候选密码，检查每个给定状态是否能通过一次操作到达（$O(81)$ 检查）。

---

## C++ 源代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
int states[10][5]; // n 个给定状态，每个状态 5 位

// 检查密码 a 能否通过一次操作变成密码 b
bool can_transform(const int a[5], const int b[5]) {
    // 计算每位差值 (b[i] - a[i] + 10) % 10
    int diff[5];
    for (int i = 0; i < 5; i++) {
        diff[i] = (b[i] - a[i] + 10) % 10;
    }

    // 情况 1：只转一个拨圈
    for (int i = 0; i < 5; i++) {
        bool ok = true;
        for (int j = 0; j < 5; j++) {
            if (i == j) {
                if (diff[j] == 0) ok = false; // 幅度必须 >= 1
            } else {
                if (diff[j] != 0) ok = false;
            }
        }
        if (ok) return true;
    }

    // 情况 2：同时转两个相邻拨圈（同幅度同方向）
    for (int i = 0; i < 4; i++) {
        if (diff[i] == 0) continue;       // 幅度必须 >= 1
        if (diff[i] != diff[i+1]) continue; // 同幅度
        bool ok = true;
        for (int j = 0; j < 5; j++) {
            if (j == i || j == i + 1) continue;
            if (diff[j] != 0) { ok = false; break; }
        }
        if (ok) return true;
    }

    return false;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < 5; j++) {
            cin >> states[i][j];
        }
    }

    int ans = 0;
    int cur[5];
    // 枚举所有 10^5 个可能的正确密码
    for (int code = 0; code < 100000; code++) {
        int tmp = code;
        for (int i = 0; i < 5; i++) {
            cur[i] = tmp % 10;
            tmp /= 10;
        }

        // 检查该密码是否能通过一次操作变成所有 n 个状态
        bool all_ok = true;
        for (int i = 0; i < n; i++) {
            if (!can_transform(cur, states[i])) {
                all_ok = false;
                break;
            }
        }
        if (all_ok) ans++;
    }

    cout << ans << "\n";
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(10^5 \times n \times 81)$。$10^5 \times 8 \times 81 \approx 6.48 \times 10^7$，在 C++ 中可以轻松通过。
- **空间复杂度**：$O(n)$，仅存储 $n$ 个状态。

---

## 关键点

1. **暴力枚举**：$5$ 位密码只有 $10^5$ 种可能，完全可以直接枚举。
2. **差值判断**：用模 $10$ 差值判断两个状态之间是否可以通过一次操作到达，分为单拨圈和双拨圈两种情况。
3. **操作分类**：一次操作共 $45 + 36 = 81$ 种，通过遍历 $5$ 个单拨圈位置和 $4$ 个双拨圈位置即可覆盖。
4. **幅度限制**：转动幅度必须为 $1 \sim 9$（不能为 $0$），即差值不能为 $0$。
