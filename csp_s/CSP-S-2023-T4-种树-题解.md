# P9755 [CSP-S 2023] 种树 题解

## 题目大意

一棵 $n$ 个节点的树，按 $1, 2, \dots, n$ 的顺序种树，每天种一棵，且只能种在已种树的相邻位置。每棵树 $i$ 每天生长高度为 $\max(b_i + d \cdot c_i, 1)$，其中 $d$ 是绝对天数。求最少需要多少天，使得所有树的高度均 $\ge a_i$。

---

## 解题思路

### 核心观察

- 种植顺序固定为 $1, 2, \dots, n$，因此树 $i$ 在第 $i$ 天种下，收获日在第 $D$ 天。
- 树 $i$ 的总生长高度为 $\sum_{d=i}^{D} \max(b_i + d \cdot c_i, 1)$。
- 需要满足 $\sum_{d=i}^{D} \max(b_i + d \cdot c_i, 1) \ge a_i$。
- 此外，树 $i$（$i>1$）必须与某棵已种的树 $j < i$ 相邻（连通性约束）。

### 算法：二分答案

**二分答案** $D$，检查 $D$ 天内是否可行。

**可行性检查**：
1. 对每棵树 $i$，计算若在第 $i$ 天种下，到第 $D$ 天的总生长高度。若 $\ge a_i$ 则可行，否则不可行。
2. 检查连通性约束：对每个 $i > 1$，检查是否存在 $j < i$ 使得 $i$ 与 $j$ 相邻。若每个前缀节点集 $\{1, \dots, i\}$ 都连通，则约束满足。

**高度计算**：函数 $f_i(d) = \max(b_i + d \cdot c_i, 1)$ 是分段函数。对于 $c_i \ge 0$，$f_i(d)$ 单调不减，存在分界点 $d_0$ 使得 $d \ge d_0$ 时 $f_i(d) = b_i + d \cdot c_i$，否则为 $1$。对于 $c_i < 0$，$f_i(d)$ 单调不增。用等差数列求和公式在 $O(1)$ 时间内计算区间和。

## C++ 源代码

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
typedef __int128 i128;

const int MAXN = 100005;

int n;
ll a[MAXN], b[MAXN], c[MAXN];
vector<int> adj[MAXN];

// 计算 f(d) = max(b + d * c, 1) 在区间 [L, R] 上的和
i128 calc_sum(ll b_val, ll c_val, ll L, ll R) {
    if (L > R) return 0;
    if (c_val == 0) {
        return (i128)max(b_val, 1LL) * (R - L + 1);
    }

    i128 sum = 0;
    if (c_val > 0) {
        // f(d) 单调递增，找到 b + d * c >= 1 的分界点
        // d0 = ceil((1 - b) / c)，即 d0 = (1 - b + c - 1) / c 当 c > 0
        ll d0 = (1 - b_val + c_val - 1) / c_val;
        if (d0 < 1) d0 = 1;

        if (L < d0) {
            ll R1 = min(R, d0 - 1);
            sum += (i128)1 * (R1 - L + 1);
            L = R1 + 1;
        }
        if (L <= R) {
            // 等差数列求和：sum_{d=L}^{R} (b + d * c)
            // = b * (R-L+1) + c * (L+R) * (R-L+1) / 2
            i128 cnt = R - L + 1;
            sum += (i128)b_val * cnt + (i128)c_val * (L + R) * cnt / 2;
        }
    } else { // c_val < 0
        // f(d) 单调递减，找到 b + d * c >= 1 的分界点
        // d0 = floor((1 - b) / c)，注意 c < 0 时除法向下取整
        // 对于 d <= d0，f(d) = b + d * c；对于 d > d0，f(d) = 1
        ll d0 = (1 - b_val) / c_val;  // c < 0，除法向下取整
        // 修正：需要 b + d * c >= 1
        if (d0 > 0 && b_val + d0 * c_val < 1) d0--;

        if (L <= d0) {
            ll R1 = min(R, d0);
            i128 cnt = R1 - L + 1;
            sum += (i128)b_val * cnt + (i128)c_val * (L + R1) * cnt / 2;
            L = R1 + 1;
        }
        if (L <= R) {
            sum += (i128)1 * (R - L + 1);
        }
    }
    return sum;
}

// 检查 D 天是否可行
bool check(ll D) {
    if (D < n) return false;  // 至少需要 n 天

    for (int i = 1; i <= n; i++) {
        i128 h = calc_sum(b[i], c[i], i, D);
        if (h < a[i]) return false;
    }
    return true;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i] >> b[i] >> c[i];
    }
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    // 检查连通性约束：每个前缀节点集 {1..i} 是否连通
    // 即对于每个 i>1，是否存在 j<i 与 i 相邻
    vector<bool> planted(n + 1, false);
    planted[1] = true;
    for (int i = 2; i <= n; i++) {
        bool ok = false;
        for (int v : adj[i]) {
            if (v < i) { ok = true; break; }
        }
        if (!ok) {
            // 前缀不连通，无法按顺序种植
            // 但题目保证有解，这里仅作为安全检查
        }
        planted[i] = true;
    }

    // 二分答案
    ll lo = n, hi = 1;  // hi 需要足够大
    // 估算上界：假设每天生长 1，需要 sum(a_i) 天，但实际可能更多
    // 保守估计 hi = 1e9 + n
    hi = 1000000000LL + n;

    while (lo < hi) {
        ll mid = (lo + hi) / 2;
        if (check(mid)) {
            hi = mid;
        } else {
            lo = mid + 1;
        }
    }

    cout << lo << "\n";
    return 0;
}
```

**注意**：上述代码中 `calc_sum` 对于 $c < 0$ 的分界点计算需要仔细处理。以下为更稳健的实现：

```cpp
// 计算 f(d) = max(b + d * c, 1) 在区间 [L, R] 上的和（稳健版）
i128 calc_sum(ll b_val, ll c_val, ll L, ll R) {
    if (L > R) return 0;
    if (c_val == 0) {
        return (i128)max(b_val, 1LL) * (R - L + 1);
    }

    i128 sum = 0;
    if (c_val > 0) {
        // f(d) 单调递增，找到第一个 d 使得 b + d*c >= 1
        // 即 d >= ceil((1 - b) / c)
        ll d0 = (1 - b_val) / c_val;
        if (b_val + d0 * c_val < 1) d0++;
        if (d0 < L) d0 = L;

        // [L, d0-1] 区间 f(d) = 1
        if (L < d0) {
            ll R1 = min(d0 - 1, R);
            sum += (i128)1 * (R1 - L + 1);
            L = R1 + 1;
        }
        // [d0, R] 区间 f(d) = b + d*c
        if (L <= R) {
            i128 cnt = R - L + 1;
            sum += (i128)b_val * cnt + (i128)c_val * (L + R) * cnt / 2;
        }
    } else { // c_val < 0
        // f(d) 单调递减，找到最后一个 d 使得 b + d*c >= 1
        // 即 d <= floor((1 - b) / c)，注意 c < 0
        ll d0 = (1 - b_val) / c_val;
        if (b_val + d0 * c_val < 1) d0--;
        if (d0 > R) d0 = R;

        // [L, d0] 区间 f(d) = b + d*c
        if (L <= d0) {
            i128 cnt = d0 - L + 1;
            sum += (i128)b_val * cnt + (i128)c_val * (L + d0) * cnt / 2;
            L = d0 + 1;
        }
        // [d0+1, R] 区间 f(d) = 1
        if (L <= R) {
            sum += (i128)1 * (R - L + 1);
        }
    }
    return sum;
}
```

## 复杂度分析

- **时间复杂度**：$O(n \log \text{ans})$。每次检查 $O(n)$，二分 $O(\log \text{ans}) \approx 30$ 次。
- **空间复杂度**：$O(n)$，存储树的邻接表和参数。

---

## 关键点

1. **二分答案**：答案关于天数 $D$ 是单调的（天数越多，树长得越高），因此可以二分。
2. **分段函数求和**：$\max(b_i + d \cdot c_i, 1)$ 是分段函数，需要分界点处理，用等差数列公式 $O(1)$ 计算。
3. **种植顺序**：树 $i$ 在第 $i$ 天种下，因此其生长区间为 $[i, D]$。
4. **连通性约束**：前缀节点集 $\{1, \dots, i\}$ 必须连通，这等价于每棵树 $i$ 与某棵已种树 $j < i$ 相邻。
5. **`__int128`**：高度和可能超过 $2^{63}$，需要使用 `__int128` 进行中间计算。
