# CSP-S 2024 T4 擂台游戏（洛谷 P11234）题解

## 一、题目大意

小 S 举办擂台游戏。若共有 $2^k$ 名选手，则游戏分 $k$ 轮进行：

- 第 1 轮：编号 $(1,2)$、$(3,4)$、…、$(2^k-1, 2^k)$ 分别对局；
- 第 2 轮：第一轮胜者按顺序两两对局；
- ……
- 第 $k-1$ 轮为半决赛，第 $k$ 轮为决赛。

每位选手有**能力值** $a_i\in[0, 2^{31}-1]$。每场比赛先抽签得到 $d_{R,G}\in\{0,1\}$：

- $d=0$：编号较小的选手为**擂主**；
- $d=1$：编号较大的选手为擂主。

擂主获胜当且仅当**擂主的能力值 $\ge R$（当前轮数）**，与另一位选手的能力值无关；擂主失败则另一位选手直接获胜晋级。

选手按报名顺序编号 $1..n$。小 S 想知道：对于每个前缀长度 $c$，若只保留前 $c$ 位报名的选手、并补充 $(2^k-c)$ 名能力值**可任取**的选手，使总人数为不小于 $c$ 的最小的 $2$ 的幂 $2^k$，进行完整游戏后，**所有可能成为总冠军的选手编号之和** $A_c$ 是多少。

共 $T$ 组测试数据（只改变能力值），每组输出

$$(1\cdot A_{c_1}) \oplus (2\cdot A_{c_2}) \oplus \cdots \oplus (m\cdot A_{c_m})$$

## 二、输入输出格式

### 输入格式

- 第一行两个正整数 $n, m$；
- 第二行 $n$ 个非负整数 $a'_1,\dots,a'_n$；
- 第三行 $m$ 个正整数 $c_1,\dots,c_m$；
- 设 $K$ 为满足 $2^K \ge n$ 的最小非负整数，接下来 $K$ 行，第 $R$ 行是长度为 $2^{K-R}$ 的 0/1 串（无空格），第 $G$ 个字符表示 $d_{R,G}$；
- 接下来一个正整数 $T$；
- 接下来 $T$ 行，每行 4 个非负整数 $X_0,X_1,X_2,X_3$，该组数据能力值为 $a_i = a'_i \oplus X_{i\bmod 4}$。

### 输出格式

共 $T$ 行，每行输出该组数据所有询问的加权异或和。

## 三、样例

### 输入 #1

```text
5 5
0 0 0 0 0
5 4 1 2 3
1001
10
1
4
2 1 0 0
1 2 1 0
0 2 3 1
2 2 0 1
```

### 输出 #1

```text
5
19
7
1
```

### 样例解释

以第一组数据为例：$X=(2,1,0,0)$，真实能力值为 $a=[1,0,0,2,1]$。五个询问分别是前缀长度 $5,4,1,2,3$：

- $c=1$：只有 1 号选手，答案为 $1$；
- $c=2$：$2$ 号当擂主但 $a_2=0<1$，1 号获胜，答案为 $1$；
- $c=3$：补充选手后 1 号与 4 号都有可能夺冠，答案为 $1+4=5$；
- $c=4$：$a_4=2\ge 2$，4 号确定夺冠，答案为 $4$；
- $c=5$：可能夺冠的有 4、7、8 号，答案为 $4+7+8=19$。

故输出 $(1\cdot19)\oplus(2\cdot4)\oplus(3\cdot1)\oplus(4\cdot1)\oplus(5\cdot5)=5$。

## 四、数据范围

- $2 \le n, m \le 10^5$，$0 \le a_i, X_j < 2^{31}$，$1 \le c_i \le n$，$1 \le T \le 256$；
- 时间限制 1s，空间限制 512MB。

特殊性质：

- A：所有询问的 $c_i$ 都是 $2$ 的幂；
- B：所有 $d_{R,G}=0$。

注意：答案可达 $n^2\approx 10^{10}$ 量级，必须使用 64 位整数。

## 五、核心思路

### 5.1 把比赛看成满二叉树

把 $2^K$ 人的完整赛程看成满二叉树：

- 叶子：选手 $1..2^K$（超出 $n$ 的叶子是"补充选手"，能力值未定）；
- 内部结点：一场比赛，其所在轮数 $R$ = 树高（根为第 $K$ 轮）；
- 每个内部结点记录抽签 $d$：$d=0$ 取左儿子胜者当擂主，$d=1$ 取右儿子胜者当擂主。

某个内部结点的胜者只取决于：**擂主一侧的胜者能力值是否 $\ge R$**。

### 5.2 两个关键性质

1. **能夺冠的选手集合随着前缀 $c$ 单调"收缩"**：把后面的选手从"能力值已知"改为"能力值任取"，只会让更多人可能获胜，原来的可能冠军仍然是可能冠军。因此对每个固定的赛程大小 $2^k$，每个选手 $x$ 能夺冠的询问时刻 $c$ 构成一个**前缀区间**。
2. **补充选手可以任意输赢**：补充选手当擂主时，我们总能选择它的能力值使其获胜或失败。因此，只有"擂主是已知选手"的比赛结果才是确定的。

于是可以这样求答案：对每个赛程大小 $2^k$（$1\le k\le K$），用**差分数组**累加"每个选手在哪些询问时刻可能夺冠"，最后对每个 $c$ 取对应赛程大小的累加值。

### 5.3 预处理：每个结点的胜者与"固定时刻"

记：

- $f_p$：结点 $p$ 的胜者编号（补充选手用其位置表示，能力值视为 $+\infty$）；
- $t_p$：结点 $p$ 的**擂主一侧**胜者的"固定时刻"——从该时刻起，$p$ 这场比赛的擂主身份不再变化。

叶子：$f_p = t_p =$ 选手编号。

内部结点 $p$，设轮数为 $r$，左儿子 $lc$、右儿子 $rc$：

$$\begin{cases}
d_p=0\text{ 且 } a_{f_{lc}}\ge r & :\quad t_p=t_{lc},\ f_p=f_{lc} \quad(\text{左方擂主必胜})\\
d_p=1\text{ 且 } a_{f_{rc}} < r & :\quad t_p=t_{rc},\ f_p=f_{lc}\quad(\text{右方擂主必败})\\
\text{其他} & :\quad t_p=t_{rc},\ f_p=f_{rc}
\end{cases}$$

可以统一写成：

```text
t[p] = (d[p]==0 && a[f[lc]] >= r) ? t[lc] : t[rc];
f[p] = ((d[p]==0 && a[f[lc]] >= r) || (d[p]==1 && a[f[rc]] < r)) ? f[lc] : f[rc];
```

直觉：当擂主一侧的胜者已经确定、且它"必胜/必败"都成立时，这一场的结果就确定了；$t$ 记录的是这一"确定性"到达的时刻。

### 5.4 限制沿树下传：`solve(now, dh, l, r)`

定义递归函数 $solve(now, dh, l, r)$：

- $now$：当前子树根结点；
- $dh$：从根到 $now$ 的路径上，$now$ 的胜者**作为擂主时需要达到的最小能力值**（即路径上各轮轮数的最大值）；
- $[l,r]$：当前子树负责贡献的询问时刻区间。

叶子（选手 $x$，即 $now$ 对应叶子）的贡献分两部分：

1. **$x$ 尚未到场**（$c < x$，它是补充选手）：在 $[l, \min(x-1, r)]$ 内，$x$ 一定可能夺冠 → 差分加 $x$；
2. **$x$ 已到场且能力值足够**（$c \ge x$ 且 $a_x \ge dh$）：它可能一路获胜夺冠 → 在 $[x, r]$ 内差分加 $x$。

内部结点按 $d_p$ 分两类下传（设轮数 $h$）：

- $d_p=0$（左方当擂主）：
  - 左子树：$solve(lc, \max(dh, h), l, r)$（左方胜者还要能赢这一场）；
  - 右子树：若左方擂主必胜（$a_{f_{lc}}\ge h$），则右方在 $t_{lc}$ 之后不可能再夺冠，右子树区间截断为 $[l, \min(t_{lc}-1, r)]$；否则右子树正常 $[l, r]$。
- $d_p=1$（右方当擂主）：对称处理（左子树可能被截断，右子树继承 $\max(dh,h)$）。

### 5.5 枚举赛程大小

赛程大小 $2^k$ 对应的根结点是 $1<<k$（$0\le k\le K$），它服务的询问区间是：

- $k=K$：$[1,1]$（整棵树）；
- $k<K$：$[(1<<(K-k-1))+1,\ 1<<(K-k)]$。

对所有 $k$ 调用 $solve(1<<k, 0, l, r)$ 并累加差分数组，最后做前缀和即得到所有 $A_c$。

### 5.6 复杂度

建树 $O(2^K)=O(n)$；$solve$ 中每个结点在每层至多被访问一次，总复杂度 $O(2^K \cdot K)$ 中 $2^K=O(n)$、$K=\lceil\log_2 n\rceil$，整体 $O(n\log n)$；每组数据重新计算能力值并重跑 $O(n\log n)$，$T\le 256$ 可过。空间 $O(2^K)$。

## 六、易错点

1. **异或下标**：能力值 $a_i = a'_i \oplus X_{i\bmod 4}$，下标从 1 开始，即 $i=1$ 对应 $X_1$、$i=4$ 对应 $X_0$；
2. **补充选手能力值**：设成 $+\infty$（$2^{31}-1$），保证它们当擂主时必胜；
3. **严格不等号**：擂主获胜条件是 $a \ge R$，失败条件是 $a < R$；
4. **输入顺序**：$K$ 行抽签串第 $1$ 行是第 $1$ 轮（最底部），读取时按 $k=K-1..0$ 存入 $d[(1<<k)+i]$；
5. **64 位**：答案与异或中间量都要用 `long long`；
6. **差分数组每轮询问都要重新清零**（$T$ 组数据共享预处理，但答案按组计算）。

## 七、参考代码（C++17，已通过样例与随机对拍）

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

const int MAXN = 100005;
const int MAXV = 1 << 19;   // 2 * 2^K + slack，K <= 17

int n, m, K, N;
int A0[MAXN], a[MAXV], c[MAXN];
bool d[MAXV];               // 抽签：0 左方当擂主，1 右方当擂主
int t[MAXV], f[MAXV];       // t：擂主一侧胜者固定时刻；f：结点胜者
ll cf[MAXN];                // 差分数组

inline int getR(int p) {
    // 根（p=1）为第 K 轮，叶子轮次为 0
    return K - (31 - __builtin_clz(p));
}

void init(int now) {
    int r = getR(now);
    if (r == 0) {           // 叶子
        t[now] = f[now] = now - N + 1;
        return;
    }
    init(now << 1);
    init(now << 1 | 1);
    // t：若左方当擂主且必胜，取左，否则取右
    if (!d[now] && a[f[now << 1]] >= r)
        t[now] = t[now << 1];
    else
        t[now] = t[now << 1 | 1];
    // f：胜者
    if ((!d[now] && a[f[now << 1]] >= r) || (d[now] && a[f[now << 1 | 1]] < r))
        f[now] = f[now << 1];
    else
        f[now] = f[now << 1 | 1];
}

// dh：路径上作为擂主时需要达到的最小能力值；[l, r]：询问时刻区间
void solve(int now, int dh, int l, int r) {
    if (l > r) return;
    int h = getR(now);
    if (h == 0) {           // 叶子：选手 x
        int x = now - N + 1;
        // 情形1：x 尚未到场（补充选手），在 [l, min(x-1, r)] 内可能夺冠
        if (l < x) {
            cf[l] += x;
            cf[min(x, r + 1)] -= x;
        }
        // 情形2：x 已到场且能力值足够，在 [x, r] 内可能夺冠
        if (x <= r && a[x] >= dh) {
            cf[max(x, l)] += x;
            cf[r + 1] -= x;
        }
        return;
    }
    if (!d[now]) {          // 左方当擂主
        solve(now << 1, max(dh, h), l, r);
        if (a[f[now << 1]] >= h)
            solve(now << 1 | 1, dh, l, min(t[now << 1] - 1, r));
        else
            solve(now << 1 | 1, dh, l, r);
    } else {                // 右方当擂主
        if (a[f[now << 1 | 1]] >= h)
            solve(now << 1, dh, l, min(t[now << 1 | 1] - 1, r));
        else
            solve(now << 1, dh, l, r);
        solve(now << 1 | 1, max(dh, h), l, r);
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> A0[i];
    for (int i = 1; i <= m; i++) cin >> c[i];

    K = 0;
    while ((1 << K) < n) K++;
    N = 1 << K;

    // 读入抽签：第 1 行是第 1 轮（底部），按 k = K-1..0 存入
    for (int r = K - 1; r >= 0; r--) {
        string s;
        cin >> s;
        for (int i = 0; i < (1 << r); i++)
            d[(1 << r) + i] = (s[i] == '1');
    }

    int T;
    cin >> T;
    while (T--) {
        int X[4];
        for (int i = 0; i < 4; i++) cin >> X[i];

        for (int i = 1; i <= n; i++) a[i] = A0[i] ^ X[i % 4];
        // 补充选手能力值视为 +∞：当擂主必胜
        for (int i = n + 1; i <= N; i++) a[i] = (1u << 31) - 1;

        init(1);
        memset(cf, 0, sizeof(cf));

        for (int k = 0; k <= K; k++) {
            if (k == K)
                solve(1 << k, 0, 1, 1 << (K - k));
            else
                solve(1 << k, 0, (1 << (K - k - 1)) + 1, 1 << (K - k));
        }
        for (int i = 1; i <= n; i++) cf[i] += cf[i - 1];

        ll ans = 0;
        for (int i = 1; i <= m; i++) ans ^= (ll)i * cf[c[i]];
        cout << ans << '\n';
    }
    return 0;
}
```

## 八、正确性说明

**区间前缀性**：固定赛程大小 $2^k$，把某个选手 $x$ 从"能力值未知"改为"已知"，只会减少它夺冠的可能；因此 $x$ 能夺冠的询问集合是一个前缀。差分数组正好用来累加这些前缀。

**$t$ 的语义**：内部结点的比赛结果由擂主一侧决定。若擂主一侧的胜者能力值已知且满足 $\ge R$，则该场必赢；若已知且 $<R$，则必输。无论哪种，该场比赛的结果从"擂主一侧胜者固定"的时刻起就不变了，这正是 $t$。子树的限制可以沿树向下传递（$dh$），叶子的两种情况覆盖了"补充选手"与"已知选手"两种身份。

**复杂度**：每个结点在每一层 $k$ 的 $solve$ 中至多被访问一次，总访问量 $O(2^K \cdot K)$，即 $O(n\log n)$。
