# P7914 [CSP-S 2021] 括号序列 题解

## 题目大意

定义一个"超级括号序列"的规则：

1. `()` 是合法超级括号序列。
2. 若 $A$ 是合法序列，则 `(A)` 也是合法序列。
3. 若 $A, B$ 是合法序列，则 $AB$ 也是合法序列。
4. 若 $A$ 是合法序列，则 `(SA)` 和 `(AS)` 也是合法序列，其中 $S$ 是长度不超过 $k$ 的连续 `*` 串。
5. 若 $A$ 是合法序列，则 `(S)` 是合法序列，其中 $S$ 同定义。

给定一个部分确定的字符串 $s$（含 `(`、`)`、`*`、`?`），`?` 可以是任意字符。求有多少种可能的合法超级括号序列，结果对 $10^9+7$ 取模。

---

## 解题思路

### 核心观察

这是一个典型的**区间 DP** 问题。关键在于如何对合法序列进行分类，避免重复计数。

**状态定义：**

- `S[l][r]`：区间 $[l, r]$ 是否全为 `*` 且长度不超过 $k$（布尔值）。
- `P[l][r]`：区间 $[l, r]$ 是合法序列，且 $s[l] = \text{'('}$ 且 $s[r] = \text{')'}$（即最外层是一对匹配括号）。
- `F[l][r]`：区间 $[l, r]$ 是合法序列（任意形式）。

**转移方程：**

**计算 `S[l][r]`：**
$$S[l][r] = S[l][r-1] \land (s[r] \text{ 可以是 } *) \land (r-l+1 \le k)$$

**计算 `P[l][r]`（前提：$s[l]$ 可以是 `(`，$s[r]$ 可以是 `)`）：**

$P[l][r]$ 由以下情况组成（不重不漏）：
1. `()`：$l+1 > r-1$ 时（空内部），$P[l][r] = 1$。
2. `(S)`：$S[l+1][r-1]$ 为真时，$P[l][r] += 1$。
3. `(A)`：$P[l][r] += F[l+1][r-1]$。
4. `(SA)`：$P[l][r] += \sum_{i=l+1}^{r-2} S[l+1][i] \times F[i+1][r-1]$（$S$ 后接 $A$）。
5. `(AS)`：$P[l][r] += \sum_{i=l+2}^{r-1} F[l+1][i-1] \times S[i][r-1]$（$A$ 后接 $S$）。

**计算 `F[l][r]`：**

$F[l][r]$ 由以下情况组成：
1. 本身是带括号的合法序列：$F[l][r] += P[l][r]$。
2. 两个合法序列拼接：$F[l][r] += \sum_{i=l}^{r-1} P[l][i] \times F[i+1][r]$。

注意：拼接时使用 $P[l][i]$ 而非 $F[l][i]$，是为了避免重复计数（例如 $ABC$ 应被唯一拆分为 $A$ 和 $BC$，其中 $A$ 是不可再拆的最外层括号序列）。

### 复杂度优化

直接计算转移 4 和 5 是 $\mathcal{O}(n^3)$ 的（在每个 $[l,r]$ 区间内枚举 $i$）。总复杂度 $\mathcal{O}(n^3)$，对于 $n \le 500$ 可以通过。

## C++ 源代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MOD = 1000000007;
const int MAXN = 505;

int n, k;
char s[MAXN];

// S[l][r]: 区间[l,r]是否全为*且长度不超过k
bool S[MAXN][MAXN];

// P[l][r]: 合法序列且s[l]='('且s[r]=')'
int P[MAXN][MAXN];

// F[l][r]: 任意合法序列
int F[MAXN][MAXN];

// 检查字符c是否可以匹配目标target
bool can_be(char c, char target) {
    return c == target || c == '?';
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> k;
    cin >> (s + 1); // 1-indexed

    // ---- 预处理 S[l][r] ----
    for (int l = 1; l <= n; ++l) {
        if (!can_be(s[l], '*')) continue;
        S[l][l] = true;
        for (int r = l + 1; r <= n && r - l + 1 <= k; ++r) {
            if (!can_be(s[r], '*')) break;
            S[l][r] = true;
        }
    }

    // ---- 区间 DP ----
    // 按区间长度从小到大处理
    for (int len = 2; len <= n; ++len) {
        for (int l = 1; l + len - 1 <= n; ++l) {
            int r = l + len - 1;

            // ---- 计算 P[l][r] ----
            if (can_be(s[l], '(') && can_be(s[r], ')')) {
                // 情况1: ()
                if (l + 1 > r - 1) {
                    P[l][r] = (P[l][r] + 1) % MOD;
                }
                // 情况2: (S)
                if (l + 1 <= r - 1 && S[l + 1][r - 1]) {
                    P[l][r] = (P[l][r] + 1) % MOD;
                }
                // 情况3: (A)
                if (l + 1 <= r - 1) {
                    P[l][r] = (P[l][r] + F[l + 1][r - 1]) % MOD;
                }
                // 情况4: (SA) -- S在左边，A在右边
                for (int i = l + 1; i <= r - 2; ++i) {
                    if (S[l + 1][i]) {
                        P[l][r] = (P[l][r] + (long long)F[i + 1][r - 1]) % MOD;
                    } else {
                        break; // S必须连续，一旦不是*就停止
                    }
                }
                // 情况5: (AS) -- A在左边，S在右边
                for (int i = r - 1; i >= l + 2; --i) {
                    if (S[i][r - 1]) {
                        P[l][r] = (P[l][r] + (long long)F[l + 1][i - 1]) % MOD;
                    } else {
                        break; // S必须连续，一旦不是*就停止
                    }
                }
            }

            // ---- 计算 F[l][r] ----
            // 情况1: 本身是P
            F[l][r] = P[l][r];

            // 情况2: 拼接 P[l][i] + F[i+1][r]
            for (int i = l; i < r; ++i) {
                F[l][r] = (F[l][r] + (long long)P[l][i] * F[i + 1][r]) % MOD;
            }
        }
    }

    cout << F[1][n] << "\n";
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$\mathcal{O}(n^3)$。三层循环：区间长度 $\mathcal{O}(n)$，左端点 $\mathcal{O}(n)$，内层枚举拆分点（情况 4、5 和拼接）各 $\mathcal{O}(n)$。对于 $n \le 500$，$n^3 = 1.25 \times 10^8$，在优化和取模下可以通过。
- **空间复杂度**：$\mathcal{O}(n^2)$，三个 $n \times n$ 的 DP 数组。

---

## 关键点

1. **状态设计**：区分 `P[l][r]`（最外层是匹配括号）和 `F[l][r]`（任意合法序列），避免拼接时重复计数。
2. **拼接唯一性**：$F[l][r] = \sum P[l][i] \times F[i+1][r]$ 保证了每种拼接方式被唯一计算（最左边的不可拆分块是 $P$）。
3. **S 的连续性**：在情况 4 和 5 中，$S$ 必须是连续的 `*`，一旦遇到非 `*` 就 break，同时利用预处理好的 `S[l][r]` 加速判断。
4. **五种基本形式**：`()`、`(S)`、`(A)`、`(SA)`、`(AS)` 覆盖了所有可能的最外层括号形式，不重不漏。
5. **取模注意**：乘法运算使用 `long long` 中间结果再取模，避免溢出。模数为 $10^9+7$。
