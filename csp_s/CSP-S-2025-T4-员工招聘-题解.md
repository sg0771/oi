# CSP-S 2025 T4 员工招聘 / employ（洛谷 P14364）题解

## 一、题目大意

$n$ 个人应聘，编号 $1 \sim n$，每人有耐心上限 $c_i$。公司希望录用**至少 $m$ 人**。

小 Z 决定面试顺序：选择 $1 \sim n$ 的一个排列 $p$，第 $i$ 天通知 $p_i$ 来面试。第 $i$ 天面试题的难度为 $s_i \in \{0,1\}$：$s_i = 1$ 表示题目简单、来面试者必被录用；$s_i = 0$ 表示题目困难、来面试者必被拒绝。

但如果某人在他之前已经有**不少于 $c_i$ 人**被拒绝或放弃面试，他会直接放弃（不参加面试，也计入"未录用"）。

求能录用至少 $m$ 人的排列 $p$ 的数量，对 $998244353$ 取模。

## 二、输入输出格式

### 输入格式

- 第一行两个正整数 $n, m$；
- 第二行长度为 $n$ 的字符串 $s_1 \dots s_n$；
- 第三行 $n$ 个非负整数 $c_1, \dots, c_n$。

### 输出格式

一行一个非负整数表示答案。

## 三、样例

### 输入 #1

```text
3 2
101
1 1 2
```

### 输出 #1

```text
2
```

样例 1 中只有 $p=[1,2,3]$ 与 $p=[2,1,3]$ 能录用 2 人。

### 输入 #2

```text
10 5
1101111011
6 0 4 2 1 2 5 4 3 3
```

### 输出 #2

```text
2204128
```

## 四、数据范围

- $1 \le m \le n \le 500$；
- $s_i \in \{0,1\}$；
- $0 \le c_i \le n$。

## 五、核心思路

### 5.1 过程模型

记 $j$ 为"目前已未被录用的人数"（被拒 + 放弃）。面试到第 $i$ 天的人：

- 若 $c_x \le j$：他放弃，$j$ 加 1；
- 否则他参加面试：$s_i = 1$ 则被录用，$s_i = 0$ 则被拒绝，$j$ 加 1。

注意 $j$ 只增不减，且一天的结果只依赖于"来面试的人 $c$ 与当前 $j$ 的大小关系"。

### 5.2 状态设计：把"有用的人"的身份延后确定

设

$$f_{i,j,k} = \text{处理完前 } i \text{ 天，未录用人数为 } j\text{，且已面试的人中有 } k \text{ 个"身份尚未确定、满足 } c > j \text{ 的人"}$$

这里的核心 trick 是：**当前 $c > j$ 的人（"有用的人"）先不选具体是谁，只留下空位**，最后再乘一个阶乘确定身份。这样做是因为"有用的人"放在哪一天都合法（任意一天来面试都会参加），不需要在中间记录具体人选。

于是：已确定身份的人共有 $i - k$ 个，他们必然满足 $c \le j$（所有 $c > j$ 的人都在延后空位里），因此"尚未安排、满足 $c \le j$"的人数可算：

$$\text{cnt} = \mathrm{sum}[j] - (i - k), \qquad \mathrm{sum}[x] = \#\{c \le x\}$$

### 5.3 转移（第 $i$ 天，$s_i$）

记 $ton[x] = \#\{c = x\}$。

**情形 A：$s_i = 1$（今天来面试必录用）**

1. 录用：来面试者满足 $c > j$，身份延后，$k \to k+1$，$j$ 不变：
   $$f_{i+1,j,k+1} \mathrel{+}= f_{i,j,k}$$

2. 放弃：来面试者满足 $c \le j$，先选人（$\mathrm{cnt}$ 种），$j \to j+1$；当 $j$ 变为 $j+1$ 后，延后空位中满足 $c = j+1$ 的人要"揭示"出来：
   $$f_{i+1,j+1,k-l} \mathrel{+}= f_{i,j,k}\cdot \mathrm{cnt}\cdot \binom{k}{l}\binom{ton[j+1]}{l}\cdot l!$$

**情形 B：$s_i = 0$（今天无论谁来都多一个未录用者，$j \to j+1$）**

1. 来面试（$c > j$）：身份延后，空位数变为 $k+1$，再揭示 $l$ 个 $c = j+1$ 的人：
   $$f_{i+1,j+1,k+1-l} \mathrel{+}= f_{i,j,k}\cdot \binom{k+1}{l}\binom{ton[j+1]}{l}\cdot l!$$

2. 放弃（$c \le j$）：先选人（$\mathrm{cnt}$ 种），同样揭示 $l$ 个：
   $$f_{i+1,j+1,k-l} \mathrel{+}= f_{i,j,k}\cdot \mathrm{cnt}\cdot \binom{k}{l}\binom{ton[j+1]}{l}\cdot l!$$

组合数 $\binom{k}{l}\binom{ton[j+1]}{l}l!$ 的含义：从 $k$ 个延后空位中挑 $l$ 个，从 $ton[j+1]$ 个"恰好 $c = j+1$"的人中挑 $l$ 个，并做一一匹配——这些人此后身份确定，不再计入 $k$。

### 5.4 统计答案

最终录用人数为 $n - j$，要求 $n - j \ge m \iff j \le n - m$。最终延后空位数必须恰好等于

$$\sum_{x>j} ton[x] = \#\{c > j\}$$

再乘以 $k!$ 为这些空位确定身份：

$$\text{ans} = \sum_{j=0}^{n-m} f_{n,j,\sum_{x>j} ton[x]}\cdot \left(\sum_{x>j}ton[x]\right)!$$

### 5.5 复杂度

状态 $O(n^2)$，转移中 $l$ 的枚举总代价为 $O(n^3)$（$\sum_j ton[j+1] = n$ 提供额外约束），空间用滚动数组 $O(n^2)$。

## 六、正确性说明

1. **大小关系决定结果**：某人最终是录用/拒绝/放弃，只取决于他面试当天 $j$ 与 $c$ 的关系，而 $j$ 的演化只由"每天来的人 $c$ 是否 $\le j$"决定，因此状态 $f_{i,j,k}$ 足以刻画过程；
2. **延后空位合法**：任何 $c > j$ 的人在"当前 $j$ 之前"的任何一天来面试都必然参加（$c > j \ge$ 之前任意时刻的 $j$），所以空位放在哪天都不影响正确性，最后用 $k!$ 任意匹配身份即可；
3. **揭示不重不漏**：$j$ 每增加 1，阈值越过 $c = j+1$ 的人必须立即从延后状态转为确定状态，枚举 $l$ 个并用组合数匹配，恰好覆盖所有情况；
4. **答案条件**：录用 $= n - j \ge m$，且延后人数必须等于可用有用人数，否则无法完成匹配。

## 七、参考代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const ll MOD = 998244353;
const int MAXN = 505;

int n, m;
int ton[MAXN];        // ton[x] = c == x 的人数
int sumv[MAXN];       // sumv[x] = c <= x 的人数
ll frac[MAXN], invf[MAXN];
ll dp[2][MAXN][MAXN];

ll ksm(ll a, ll b) {
    ll r = 1;
    while (b) {
        if (b & 1) r = r * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return r;
}

ll C(int x, int y) {
    if (y < 0 || y > x) return 0;
    return frac[x] * invf[y] % MOD * invf[x - y] % MOD;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m;
    string s;
    cin >> s;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        ton[x]++;
    }
    sumv[0] = ton[0];
    for (int i = 1; i <= n; i++) sumv[i] = sumv[i - 1] + ton[i];

    frac[0] = 1;
    for (int i = 1; i <= n; i++) frac[i] = frac[i - 1] * i % MOD;
    invf[n] = ksm(frac[n], MOD - 2);
    for (int i = n - 1; i >= 0; i--) invf[i] = invf[i + 1] * (i + 1) % MOD;

    // dp[j][k]：处理到第 i 天结束
    //   j = 目前未录用人数；k = 已面试、身份延后且满足 c > j 的人数
    dp[0][0][0] = 1;
    for (int i = 0; i < n; i++) {
        int cur = i & 1, nxt = cur ^ 1;
        for (int j = 0; j <= i; j++) {
            for (int k = 0; k <= i; k++) {
                ll val = dp[cur][j][k];
                if (!val) continue;

                if (s[i] == '1') {
                    // 录用：c > j，身份延后确定
                    dp[nxt][j][k + 1] = (dp[nxt][j][k + 1] + val) % MOD;

                    // 放弃：c <= j，从未安排的 c <= j 的人里选一个
                    ll choose = sumv[j] - (i - k);
                    for (int l = 0; l <= min(k, ton[j + 1]); l++) {
                        ll ways = val * choose % MOD * C(k, l) % MOD
                                * C(ton[j + 1], l) % MOD * frac[l] % MOD;
                        dp[nxt][j + 1][k - l] = (dp[nxt][j + 1][k - l] + ways) % MOD;
                    }
                } else {
                    // s = 0：无论来不来面试，j 都加 1

                    // 来面试（c > j）：延后位变 k+1，再揭示 l 个 c = j+1 的人
                    for (int l = 0; l <= min(k + 1, ton[j + 1]); l++) {
                        ll ways = val * C(k + 1, l) % MOD
                                * C(ton[j + 1], l) % MOD * frac[l] % MOD;
                        dp[nxt][j + 1][k + 1 - l] = (dp[nxt][j + 1][k + 1 - l] + ways) % MOD;
                    }
                    // 放弃（c <= j）：从未安排的 c <= j 的人里选一个
                    ll choose = sumv[j] - (i - k);
                    for (int l = 0; l <= min(k, ton[j + 1]); l++) {
                        ll ways = val * choose % MOD * C(k, l) % MOD
                                * C(ton[j + 1], l) % MOD * frac[l] % MOD;
                        dp[nxt][j + 1][k - l] = (dp[nxt][j + 1][k - l] + ways) % MOD;
                    }
                }
                dp[cur][j][k] = 0;  // 延迟清零（本层只消费一次）
            }
        }
    }

    // 最终：录用 n - j >= m，即 j <= n - m；
    // 延后空位数必须等于 c > j 的人数，再乘 k! 确定身份
    ll ans = 0, need = 0;
    for (int j = n; j >= 0; j--) {
        if (j <= n - m) {
            ans = (ans + dp[n & 1][j][need] * frac[need]) % MOD;
        }
        need += ton[j];
    }
    cout << ans << '\n';
    return 0;
}
```

## 八、易错点

1. **"未录用"包含放弃的人**：$j$ 的增量来自被拒与放弃两类；
2. **$c \le j$ 的人会放弃**：$s_i = 1$ 的天也可能不录用（来人放弃了），不要漏掉这种转移；
3. **延后空位的"揭示"**：$j$ 增加后必须处理恰好 $c = j+1$ 的延后者，否则后续 $\mathrm{sum}[j] - (i-k)$ 会算错；
4. **选人数量可能为 0**：$\mathrm{sum}[j] - (i-k)$ 表示"可选的 $c \le j$ 且未安排"的人数，正确状态中它非负；
5. **答案统计的下标**：最终只统计 $k = \sum_{x>j} ton[x]$ 的状态，并乘 $k!$；
6. **取模**：所有乘法用 `long long`，组合数预处理阶乘与逆元。
