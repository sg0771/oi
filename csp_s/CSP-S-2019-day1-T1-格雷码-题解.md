# P5657 [CSP-S 2019] 格雷码 题解

## 题目大意

给定 $n$ 和 $k$，求按题目描述的递归算法生成的 $n$ 位格雷码中编号为 $k$ 的二进制串。

格雷码的构造规则：$n+1$ 位格雷码的前半部分为 $n$ 位格雷码顺序排列加前缀 0，后半部分为 $n$ 位格雷码逆序排列加前缀 1。

---

## 解题思路

### 方法一：递归分治

观察格雷码的构造过程：对于 $n$ 位格雷码的第 $k$ 个串（$0 \le k < 2^n$）：

1. 若 $k < 2^{n-1}$，则最高位为 `0`，问题转化为求 $n-1$ 位格雷码的第 $k$ 个串。
2. 若 $k \ge 2^{n-1}$，则最高位为 `1`，问题转化为求 $n-1$ 位格雷码的第 $2^n - 1 - k$ 个串（逆序映射）。

从最高位向最低位逐位确定即可，时间复杂度 $\mathcal{O}(n)$。

### 方法二：标准格雷码公式

题目描述的格雷码恰好是**标准格雷码**，其公式为：

$$G(k) = k \oplus \left\lfloor \frac{k}{2} \right\rfloor$$

即 $k$ 与 $k$ 右移一位的结果做异或，再将结果格式化为 $n$ 位二进制串输出。

**注意**：$n$ 最大为 64，$k$ 最大可达 $2^{64}-1$，需要使用 `unsigned long long` 类型。

---

## C++ 源代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    unsigned long long k;
    cin >> n >> k;

    // 标准格雷码公式: G(k) = k ^ (k >> 1)
    unsigned long long g = k ^ (k >> 1);

    // 输出 n 位二进制串（从高位到低位）
    for (int i = n - 1; i >= 0; --i) {
        cout << ((g >> i) & 1ULL);
    }
    cout << "\n";

    return 0;
}
```

---

## 复杂度分析

- **时间复杂度**：$\mathcal{O}(n)$，仅需一次异或运算和 $n$ 次位提取。
- **空间复杂度**：$\mathcal{O}(1)$，只使用常数个变量。

---

## 关键点

1. **数据范围**：$k$ 最大为 $2^{64}-1$，必须用 `unsigned long long`，不能用 `long long`（会溢出）。
2. **公式推导**：题目描述的递归构造与标准格雷码 $G(k) = k \oplus (k \gg 1)$ 完全等价，可直接使用公式一步求解。
3. **输出格式**：需要输出恰好 $n$ 位，前导零不能省略。
