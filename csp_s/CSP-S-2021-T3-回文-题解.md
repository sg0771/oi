# P7915 [CSP-S 2021] 回文 题解

## 题目大意

给定一个长度为 $2n$ 的序列 $a$，其中 $1 \sim n$ 每个数恰好出现两次。每次操作可以从序列的**左端**或**右端**取出一个数，依次放入新序列 $b$ 中。要求 $b$ 是一个回文序列（即 $b_i = b_{2n+1-i}$），求字典序最小的操作序列（用 `L` 表示从左端取，`R` 表示从右端取）。

若不存在合法方案，输出 $-1$。

---

## 解题思路

### 核心观察

**观察 1：首尾确定**

由于 $b$ 是回文，$b_1 = b_{2n}$。第一个操作取出的数必须等于最后一个操作取出的数。第一个操作只能取 $a_1$（左端）或 $a_{2n}$（右端）。不妨先尝试取 $a_1$（字典序优先 L），若失败再尝试取 $a_{2n}$。

**观察 2：匹配对的约束**

假设第一个操作取 $a_1 = x$（L），则 $b_{2n}$ 也必须等于 $x$。找到 $x$ 在序列中的另一个出现位置 $pos$（$a_{pos} = x$）。那么最后一个操作必须取出 $a_{pos}$，且 $a_{pos}$ 必须位于序列的端点（左端或右端）。

由于 $a_{pos}$ 一开始不在端点，在中间的 $(2n-2)$ 次操作中，$a_{pos}$ 会逐渐移动到端点。这要求我们设计操作序列，使得 $a_{pos}$ 在最后一轮恰好位于端点。

**观察 3：双指针模拟**

选定第一个数后，序列被 $pos$ 分成两段：
- 左段：$a[2 \ldots pos-1]$
- 右段：$a[pos+1 \ldots 2n]$（若第一个取的是 $a_{2n}$，则右段为 $a[pos+1 \ldots 2n-1]$）

我们维护两段各自的左右指针 $(l_1, r_1)$ 和 $(l_2, r_2)$。在每一步，我们尝试从当前可用的四个端点中取一个数，使得该数与另一端的某个数匹配（即数值相等）。

**贪心策略**：每次优先尝试 `L`（取左段的左端），再尝试 `R`（取右段的右端），以保证字典序最小。

### 算法

1. 尝试以 $a_1$ 为第一个操作（L 优先）。
2. 找到 $a_1$ 的另一个出现位置 $pos$。
3. 初始化四个指针：`l1=2, r1=pos-1, l2=pos+1, r2=2n`。
4. 进行 $n-1$ 轮匹配：
   - 优先检查 `l1` 是否与 `r1` 或 `l2` 匹配（对应 L...R 或 L...L）。
   - 其次检查 `r2` 是否与 `r1` 或 `l2` 匹配（对应 R...R 或 R...L）。
   - 若无法匹配，该方案失败。
5. 若方案失败，尝试以 $a_{2n}$ 为第一个操作（R），类似处理。
6. 若两种方案都失败，输出 $-1$。

## C++ 源代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 500005;

int n;
int a[MAXN * 2];
char ans[MAXN * 2]; // 操作序列

// 尝试以first_pos作为第一个操作的位置（1表示左端L，2n表示右端R）
// 返回是否成功
bool solve(int first_pos, int& other_pos) {
    int x = a[first_pos];

    // 找到x的另一个位置
    other_pos = -1;
    if (first_pos == 1) {
        for (int i = 2; i <= 2 * n; ++i) {
            if (a[i] == x) { other_pos = i; break; }
        }
    } else {
        for (int i = 1; i < 2 * n; ++i) {
            if (a[i] == x) { other_pos = i; break; }
        }
    }

    // 设置四个指针
    int l1, r1, l2, r2;
    if (first_pos == 1) {
        l1 = 2; r1 = other_pos - 1;
        l2 = other_pos + 1; r2 = 2 * n;
    } else {
        l1 = 1; r1 = other_pos - 1;
        l2 = other_pos + 1; r2 = 2 * n - 1;
    }

    // 回文序列：ans[0] 和 ans[2n-1] 已确定
    ans[0] = (first_pos == 1 ? 'L' : 'R');
    ans[2 * n - 1] = 'L'; // 最后一个操作取另一个x，在左端

    int k = 1; // 当前填充位置（从1到n-1）

    while (k < n) {
        // 尝试 L (从左段左端取)
        if (l1 <= r1) {
            if (l1 < r1 && a[l1] == a[r1]) {
                // 匹配左段的左右两端
                ans[k] = 'L';
                ans[2 * n - 1 - k] = 'R';
                l1++; r1--;
                k++;
                continue;
            }
            if (l2 <= r2 && a[l1] == a[l2]) {
                // 匹配左段左端和右段左端
                ans[k] = 'L';
                ans[2 * n - 1 - k] = 'L';
                l1++; l2++;
                k++;
                continue;
            }
        }

        // 尝试 R (从右段右端取)
        if (l2 <= r2) {
            if (l2 < r2 && a[r2] == a[l2]) {
                // 匹配右段的左右两端
                ans[k] = 'R';
                ans[2 * n - 1 - k] = 'L';
                r2--; l2++;
                k++;
                continue;
            }
            if (l1 <= r1 && a[r2] == a[r1]) {
                // 匹配右段右端和左段右端
                ans[k] = 'R';
                ans[2 * n - 1 - k] = 'R';
                r2--; r1--;
                k++;
                continue;
            }
        }

        // 无法匹配
        return false;
    }

    ans[2 * n] = '\0';
    return true;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        cin >> n;
        for (int i = 1; i <= 2 * n; ++i) {
            cin >> a[i];
        }

        int other_pos;
        bool ok = false;

        // 先尝试L（字典序最小）
        if (solve(1, other_pos)) {
            ok = true;
        }
        // 再尝试R
        else if (solve(2 * n, other_pos)) {
            ok = true;
        }

        if (ok) {
            cout << ans << "\n";
        } else {
            cout << "-1\n";
        }
    }

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$\mathcal{O}(n)$。每组数据中，找到匹配位置需要 $\mathcal{O}(n)$ 扫描，双指针模拟需要 $\mathcal{O}(n)$ 步匹配。总复杂度 $\mathcal{O}(n)$。
- **空间复杂度**：$\mathcal{O}(n)$，存储序列和答案字符串。

---

## 关键点

1. **首尾确定**：回文序列的第一个和最后一个元素必须相等，因此第一个操作只能取 $a_1$ 或 $a_{2n}$。
2. **字典序贪心**：优先尝试 L 方案，失败后再尝试 R 方案。在匹配过程中，优先尝试 `L` 方向的操作。
3. **双指针维护**：将序列分成两段，用四个指针 $(l_1, r_1, l_2, r_2)$ 维护当前可用的区间。
4. **四种匹配方式**：每步有四种可能的匹配：`l1-r1`（L...R）、`l1-l2`（L...L）、`r2-l2`（R...L）、`r2-r1`（R...R），按字典序优先顺序尝试。
5. **答案构造**：同时填充 `ans` 的前半部分和后半部分，保证回文性质。
