# CSP-J 2021 普及组 T3：网络连接 (network)

## 题目描述
TCP/IP 协议是网络通信领域的一项重要协议。今天小明学习了 TCP/IP 协议相关的知识，他想要检验自己的学习成果。

TCP/IP 协议将网络连接分为客户端（Client）和服务端（Server）两种。在一个网络连接中，总是先由服务端监听一个特定地址，然后由客户端发起连接请求，最后二者建立起通信。小明认为，一个有效的网络地址由四部分 IP 地址和一部分端口号组成，它们之间以 `.` 和 `:` 分隔。具体的，一个形如 `a.b.c.d:e` 的字符串，当且仅当它满足以下条件时，才是有效的网络地址：

1. `a, b, c, d` 都是在 $0 \sim 255$ 之间的整数；
2. `e` 是在 $0 \sim 65535$ 之间的整数；
3. `a, b, c, d, e` 都不含有多余的前导零；
4. `.` 和 `:` 的个数和位置必须严格与 `a.b.c.d:e` 的格式匹配，即只能含有恰好 3 个 `.` 和 1 个 `:`，且它们不能相邻，也不能出现在字符串的开头或结尾。

现在，有 $n$ 台计算机，编号从 $1$ 到 $n$。每台计算机可以是客户端，也可以是服务端。小明会依次给每台计算机发出指令。指令的格式是：
- `Server <ad>`：让这台计算机作为服务端，监听地址 `<ad>`。
- `Client <ad>`：让这台计算机作为客户端，向地址 `<ad>` 发起连接。

你需要模拟这个过程，并输出对应的结果：
- 对于**服务端**指令：
  - 如果地址格式不合法，输出 `ERR`。
  - 如果地址合法，且之前已经被其他服务端成功监听，输出 `FAIL`。
  - 如果地址合法，且之前未被监听，输出 `OK`，这台计算机将成功监听该地址。
- 对于**客户端**指令：
  - 如果地址格式不合法，输出 `ERR`。
  - 如果地址合法，且之前已经有服务端成功监听了该地址，输出该服务端的编号。
  - 如果地址合法，但目前没有任何服务端成功监听该地址，输出 `FAIL`。

## 输入格式
第一行包含一个正整数 $n$，表示计算机的数量。
接下来 $n$ 行，每行包含两个字符串 `op` 和 `ad`，分别表示计算机的类型和要操作的网络地址，中间用一个空格隔开。

## 输出格式
输出共 $n$ 行，每行包含一个字符串或一个整数，表示对应指令的执行结果。

## 样例说明
### 样例输入
```text
5
Server 192.168.1.1:8080
Server 192.168.1.1:8080
Client 192.168.1.1:8080
Client 192.168.1.1:80
Client 192.168.1.1:99999
```

### 样例输出
```text
OK
FAIL
1
FAIL
ERR
```

## 题目分析与解题思路
本题的核心在于**字符串处理与哈希表（映射）的应用**。解题可以分为两个关键步骤：

### 1. 判断网络地址是否合法
合法的地址形式必须严格满足 `a.b.c.d:e` 的格式。我们可以通过以下步骤进行校验：
- **字符集校验**：只能包含数字、`.`、`:`。
- **符号数量及顺序校验**：必须有 3 个 `.` 和 1 个 `:`，并且在字符串中的出现顺序必须是 `.` -> `.` -> `.` -> `:`。
- **拆分与取值范围校验**：以符号为分隔符将字符串分为 5 部分。每部分必须非空，且除了单独的 `0` 以外不能有前导 `0`。解析出的整数必须在合法范围内（IP地址段 $0 \sim 255$，端口 $0 \sim 65535$）。

### 2. 模拟服务器与客户端的匹配机制
校验合法性后，需要使用数据结构来记录哪些地址已被服务端成功监听。
由于地址是字符串形式，最方便的方法是使用 `std::map<string, int>`（或 `std::unordered_map`）。
- **如果是 Server**：
  - 在 `map` 中查找该地址。若存在，说明之前已被其他 Server 监听，输出 `FAIL`。
  - 若不存在，将 `(地址, 当前编号)` 存入 `map` 中，输出 `OK`。
- **如果是 Client**：
  - 在 `map` 中查找该地址。若存在，直接输出 `map` 中对应的编号。
  - 若不存在，说明没有对应的 Server 监听，输出 `FAIL`。

## C++ 参考代码
```cpp
#include <iostream>
#include <string>
#include <map>

using namespace std;

// 判断地址合法性函数
bool check(string s) {
    long long a, b, c, d, port;
    int dot_cnt = 0, colon_cnt = 0;
    
    for (char ch : s) {
        if (ch == '.') dot_cnt++;
        else if (ch == ':') colon_cnt++;
        else if (ch < '0' || ch > '9') return false;
    }
    
    if (dot_cnt != 3 || colon_cnt != 1) return false;
    
    // 使用 sscanf 进行格式解析
    char extra[100];
    if (sscanf(s.c_str(), "%lld.%lld.%lld.%lld:%lld%s", &a, &b, &c, &d, &port, extra) != 5) {
        return false;
    }
    
    if (a < 0 || a > 255 || b < 0 || b > 255 || c < 0 || c > 255 || d < 0 || d > 255) return false;
    if (port < 0 || port > 65535) return false;
    
    // 重新构造字符串，验证前导零问题
    string reconstructed = to_string(a) + "." + to_string(b) + "." + to_string(c) + "." + to_string(d) + ":" + to_string(port);
    if (reconstructed != s) return false;
    
    return true;
}

int main() {
    int n;
    cin >> n;
    map<string, int> mp;
    
    for (int i = 1; i <= n; i++) {
        string op, ad;
        cin >> op >> ad;
        
        if (!check(ad)) {
            cout << "ERR\n";
            continue;
        }
        
        if (op == "Server") {
            if (mp.count(ad)) {
                cout << "FAIL\n";
            } else {
                mp[ad] = i;
                cout << "OK\n";
            }
        } else if (op == "Client") {
            if (mp.count(ad)) {
                cout << mp[ad] << "\n";
            } else {
                cout << "FAIL\n";
            }
        }
    }
    return 0;
}
```
