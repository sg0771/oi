# CSP-J 2023 T3 一元二次方程 题解

## 题目背景
本题是 CSP-J 2023 的第三题，主要考察基本数学推导（一元二次方程求根公式）、最大公约数（GCD）的应用、以及极其繁琐的分类讨论与格式化输出。

## 题目解析

给定一元二次方程 $ax^2 + bx + c = 0$ ($a \neq 0$)，求其最大的实数根，并按照题目规定的格式输出。如果无实数根，输出 `NO`。

### 核心公式
根据一元二次方程的求根公式，根为：
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

判别式为 $\Delta = b^2 - 4ac$。
- 如果 $\Delta < 0$，方程无实根，直接输出 `NO`。
- 如果 $\Delta \ge 0$，方程有实根，我们需要输出**较大的根**。

### 关键转化：确保 $a > 0$
题目中 $a$ 有可能小于 $0$。当 $a < 0$ 时，分母 $2a$ 是负数，较大的根对应的是分子较小的部分，这会让后面的分类讨论非常容易出错。
**核心技巧：** 在读取输入后，如果 $a < 0$，我们直接将 $a, b, c$ 同时乘以 $-1$。
这样不仅方程的根不变，而且保证了 $a > 0$。此时，**较大的根永远是**：
$$x = \frac{-b + \sqrt{\Delta}}{2a}$$

### 化简 $\sqrt{\Delta}$
将 $\Delta$ 写成 $d^2 \times r$ 的形式，其中 $r$ 不包含任何大于 1 的平方因子（即 $r$ 不能被任何完全平方数整除）。
这可以通过从 $2$ 到 $\sqrt{\Delta}$ 遍历找出所有的平方因子并提取到 $d$ 中来实现。此时 $\sqrt{\Delta} = d\sqrt{r}$。

根据 $r$ 的不同，分为有理数根和无理数根两种情况：

#### 情况一：$r = 0$ 或 $r = 1$（有理数）
当 $r = 0$ 时，$\Delta = 0$，根为 $\frac{-b}{2a}$。
当 $r = 1$ 时，$\Delta$ 是完全平方数，根为 $\frac{-b + d}{2a}$。
这两种情况根都是有理数，可以直接写成一个分数 $\frac{P}{Q}$ 的形式。

**有理数化简规则（假设分数为 $p/q$）：**
1. 首先求出分子分母的最大公约数 $g = \gcd(|p|, |q|)$，将分数约分：$p /= g, q /= g$。
2. 如果分母 $q = 1$，则该数为整数，直接输出 $p$。
3. 否则，输出分式 `p/q`（因为我们已经保证了初始的 $a > 0$，这里的 $q$ 必然是正数，符号完全由分子 $p$ 决定）。

#### 情况二：$r > 1$（无理数）
此时根由有理数部分 $\frac{-b}{2a}$ 和无理数部分 $\frac{d\sqrt{r}}{2a}$ 组成。

**1. 处理有理数部分 $\frac{-b}{2a}$**
如果 $-b \neq 0$，则先将 $\frac{-b}{2a}$ 按照**情况一**的规则化简并输出。输出后需要紧跟一个加号 `+`（因为 $d\sqrt{r}$ 始终为正数，较大的根中间必然是加号）。

**2. 处理无理数部分 $\frac{d\sqrt{r}}{2a}$**
我们需要将 $\frac{d}{2a}$ 化简。令 $p = d, q = 2a$，求最大公约数 $g = \gcd(p, q)$，约分得 $p /= g, q /= g$。
然后根据 $p$ 和 $q$ 的值进行分类讨论输出格式：
- 如果 $p = 1, q = 1$，输出 `sqrt(r)`
- 如果 $p > 1, q = 1$，输出 `p*sqrt(r)`
- 如果 $p = 1, q > 1$，输出 `sqrt(r)/q`
- 如果 $p > 1, q > 1$，输出 `p*sqrt(r)/q`

## C++ 满分代码实现

```cpp
#include <iostream>
#include <cmath>
#include <numeric>

using namespace std;

// 求最大公约数
int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}

// 打印化简后的有理数分数 p/q
void print_frac(int p, int q) {
    if (p == 0) {
        cout << 0;
        return;
    }
    int g = gcd(abs(p), abs(q));
    p /= g; 
    q /= g;
    // 保证分母为正
    if (q < 0) {
        p = -p;
        q = -q;
    }
    if (q == 1) cout << p;
    else cout << p << "/" << q;
}

void solve() {
    int a, b, c;
    cin >> a >> b >> c;
    
    // 核心技巧：统一转化为 a > 0 的情况，保证大根始终是 (-b + sqrt(delta)) / 2a
    if (a < 0) {
        a = -a;
        b = -b;
        c = -c;
    }
    
    int delta = b * b - 4 * a * c;
    if (delta < 0) {
        cout << "NO\n";
        return;
    }

    // 提取平方因子，使得 delta = d^2 * r
    int d = 1, r = delta;
    for (int i = 2; i * i <= delta; ++i) {
        while (r % (i * i) == 0) {
            d *= i;
            r /= (i * i);
        }
    }

    // 分类讨论
    if (r == 0) {
        // Delta = 0, 根为 -b / 2a
        print_frac(-b, 2 * a);
        cout << "\n";
    } else if (r == 1) {
        // Delta > 0 且为完全平方数，根为 (-b + d) / 2a
        print_frac(-b + d, 2 * a);
        cout << "\n";
    } else {
        // Delta 不是完全平方数，根为无理数
        // 1. 先输出有理数部分
        if (-b != 0) {
            print_frac(-b, 2 * a);
            cout << "+";
        }
        
        // 2. 再输出无理数部分 d*sqrt(r) / 2a
        int p = d, q = 2 * a;
        int g = gcd(p, q);
        p /= g; 
        q /= g;
        
        if (p == 1 && q == 1) {
            cout << "sqrt(" << r << ")\n";
        } else if (p != 1 && q == 1) {
            cout << p << "*sqrt(" << r << ")\n";
        } else if (p == 1 && q != 1) {
            cout << "sqrt(" << r << ")/" << q << "\n";
        } else {
            cout << p << "*sqrt(" << r << ")/" << q << "\n";
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int t, m; 
    cin >> t >> m; // m 在本题逻辑中不需要用到，直接略过
    while (t--) {
        solve();
    }
    return 0;
}
```

## 复杂度分析
- **时间复杂度**：每个查询的主要耗时在于分解 $\Delta$ 的平方因子。最多需要遍历到 $\sqrt{\Delta}$，题目给出 $M \le 10^3$，所以 $\Delta \le 5 \times 10^6$，其平方根不超过 $2500$。因此时间复杂度为 $O(T \sqrt{\Delta})$，对于 $T=10^4$，最高运算次数大约为 $2.5 \times 10^7$，在时间限制以内完全可以承受。
- **空间复杂度**：$O(1)$，仅使用了若干个整数变量，不需要额外的数组空间。
