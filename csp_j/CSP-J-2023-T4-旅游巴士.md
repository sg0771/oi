# 2023年CSP-J T4 旅游巴士 (bus) 题解

## 算法分析
本题可以使用**分层图最短路**结合 **Dijkstra** 算法求解。
由于每条边的边权均为 1，且出发和到达时间必须是 $k$ 的整数倍，我们可以将状态定义为 `(u, j)`，表示当前到达节点 `u`，且当前花费时间 $t \pmod k = j$ 的最早到达时间。

如果在某条边 $u \to v$ 时，当前时间 $t$ 小于道路开放时间 $a_i$，则必须在起点推迟出发。推迟的时间必须是 $k$ 的倍数，因此我们需要计算最小的 $c$ 使得 $t + c \times k \ge a_i$。计算式为 $c = \lceil (a_i - t) / k \rceil$。

## C++ 核心代码实现

```cpp
#include <iostream>
#include <vector>
#include <queue>

using namespace std;

const int INF = 1e9 + 7;

struct Edge {
    int to, a;
};

struct State {
    int u, t;
    bool operator>(const State& other) const {
        return t > other.t;
    }
};

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n, m, k;
    if (!(cin >> n >> m >> k)) return 0;

    vector<vector<Edge>> adj(n + 1);
    for (int i = 0; i < m; ++i) {
        int u, v, a;
        cin >> u >> v >> a;
        adj[u].push_back({v, a});
    }

    // dis[u][j] 记录到达节点 u，且时间模 k 等于 j 的最早时间
    vector<vector<int>> dis(n + 1, vector<int>(k, INF));
    priority_queue<State, vector<State>, greater<State>> pq;

    dis[1][0] = 0;
    pq.push({1, 0});

    while (!pq.empty()) {
        State curr = pq.top();
        pq.pop();

        int u = curr.u;
        int t = curr.t;

        if (t > dis[u][t % k]) continue;

        for (const Edge& edge : adj[u]) {
            int v = edge.to;
            int a = edge.a;
            int next_t = t;
            
            if (next_t < a) {
                int c = (a - next_t + k - 1) / k; // 向上取整
                next_t += c * k;
            }
            
            next_t++; // 边权为 1
            int rem = next_t % k;
            
            if (next_t < dis[v][rem]) {
                dis[v][rem] = next_t;
                pq.push({v, next_t});
            }
        }
    }

    if (dis[n][0] == INF) cout << -1 << "\n";
    else cout << dis[n][0] << "\n";

    return 0;
}
```
