# C++ 实现汉诺塔 (Tower of Hanoi)

汉诺塔是一个非常经典的递归问题。它的核心逻辑是将一个复杂的问题分解为三个更简单的步骤。

## 核心算法逻辑

假设我们要把 $n$ 个盘子从柱子 **A** 移动到柱子 **C**，并借助柱子 **B** 作为辅助：

1. **分解问题**：先将上面 $n-1$ 个盘子从 **A** 移动到辅助柱 **B**（借助 **C**）。
2. **移动底盘**：将最底层最大的第 $n$ 个盘子直接从 **A** 移动到目标柱 **C**。
3. **完成合并**：最后将那 $n-1$ 个盘子从辅助柱 **B** 移动到目标柱 **C**（借助 **A**）。

## C++ 代码实现

以下是完整且带有详细注释的 C++ 代码实现：

```cpp
#include <iostream>

/**
 * 汉诺塔递归函数
 * @param n        当前需要移动的盘子数量
 * @param from_rod 起始柱子名称
 * @param to_rod   目标柱子名称
 * @param aux_rod  辅助柱子名称
 */
void hanoi(int n, char from_rod, char to_rod, char aux_rod) {
    // 递归的基本情况 (Base Case)：当只有一个盘子时，直接移动即可
    if (n == 1) {
        std::cout << "将盘子 1 从柱子 " << from_rod << " 移动到柱子 " << to_rod << std::endl;
        return;
    }

    // 步骤 1：将上面 n-1 个盘子从起始柱移动到辅助柱 (借助目标柱)
    hanoi(n - 1, from_rod, aux_rod, to_rod);

    // 步骤 2：将最底下的第 n 个盘子直接移动到目标柱
    std::cout << "将盘子 " << n << " 从柱子 " << from_rod << " 移动到柱子 " << to_rod << std::endl;

    // 步骤 3：将刚才放在辅助柱上的 n-1 个盘子移动到目标柱 (借助起始柱)
    hanoi(n - 1, aux_rod, to_rod, from_rod);
}

int main() {
    int n = 3; // 设置盘子的数量
    
    std::cout << "解决 " << n << " 个盘子的汉诺塔问题步骤：" << std::endl;
    std::cout << "----------------------------------" << std::endl;
    
    // 调用函数：将 n 个盘子从柱子 'A' 移动到柱子 'C'，借助柱子 'B'
    hanoi(n, 'A', 'C', 'B');
    
    return 0;
}
```

## 复杂度分析

| 指标 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(2^n)$ | 每增加一个盘子，移动的总步数就会翻倍（准确步数为 $2^n - 1$）。这是典型的指数级时间复杂度。 |
| **空间复杂度** | $O(n)$ | 空间开销主要来自于递归调用时的系统函数调用栈。最大递归深度就是盘子的数量 $n$。 |
