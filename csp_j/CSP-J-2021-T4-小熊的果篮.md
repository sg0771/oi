# CSP-J 2021  T4《小熊的果篮》 

洛谷地址

https://www.luogu.com.cn/problem/P7912

## 解题思路

### 题目大意
一排有 $N$ 个水果，要么是苹果（用 0 表示），要么是桔子（用 1 表示）。小熊每次从左往右扫描，每当遇到一连串相同的水果，就只拿走这串水果的第一个。重复这个过程，直到所有水果被拿完。求每一次小熊拿走的水果的原始编号。

### 暴力为什么会超时？

如果每次都直接从头到尾扫一遍数组，拿走水果后用 erase 或者是打标记，每次扫描的代价是 $O(N)$，最坏情况下（比如 0 1 0 1 0 1... 这样交替排列）要扫 $N$ 次，总复杂度为 $O(N^2)$，面对 $N = 2 \times 10^5$ 的数据规模必然超时。

### 高效解法：
块状链表 / 连续段维护我们可以把连续的同种水果看作一个“块”。
每个块记录：这一段水果的起始编号、结束编号、水果类型（0 或 1）。
每一轮小熊拿水果，实际上就是从每一个现存的块的头部拿走一个水果。
如果某个块的水果被拿光了，就从块列表中删掉它。
关键优化：拿走头部水果后，如果前一个块和后一个块的水果类型相同，它们就会“合二为一”合并成一个新块。

<br><br><br><br>

| 解法策略 | 核心数据结构 | 时间复杂度 | 空间复杂度 | $N=2 \times 10^5$ 结果 |
| :--- | :--- | :--- | :--- | :--- |
| **暴力遍历 + 标记** | 数组 / `vector` | $O(N^2)$ | $O(N)$ | TLE（只能拿 70分） |
| **动态数组删除** | `std::vector::erase` | $O(N^2)$（带高常数移动）| $O(N)$ | TLE（只能拿 50-60分） |
| **块状维护 + 队列合并** | 结构体双队列 / 链表 | $O(N)$ | $O(N)$ | **AC (100分)** |



## 代码要点

完美的 C++ AC 代码（基于双队列块维护）
这个做法利用两个队列轮流更替，避免了复杂的指针链表操作，非常清晰高效。

### 1 优化IO速度
ios::sync_with_stdio(false); 

cin.tie(nullptr);

由于该题输出的数据量非常大（最多会输出 $N$ 个带有空格的数字），如果不加这两行关同步，很容易因为 std::cout 频繁的 I/O 导致超时。

### 2 使用std::move
std::move(q2)：直接通过移动语义将下一轮的队列赋给 q1，避免了深度拷贝队列的开销，效率极高。

~~~cpp
#include <iostream>
#include <vector>
#include <queue>

using namespace std;

// 定义一个“块”结构，表示一串连续的同种水果
struct Block {
    int start; // 块的起始位置（在当前块中的真实起点）
    int end;   // 块的终点位置
    int type;  // 水果类型：0 代表苹果，1 代表桔子
};

int main() {
    // 优化输入输出流
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;

    vector<int> a(n + 1);
    queue<Block> q1; // 当前轮次需要处理的块队列

    // 1. 读入数据并进行首次“分块”预处理
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
        if (q1.empty() || a[i] != q1.back().type) {
            // 如果队列为空，或者当前水果与上一个块类型不同，开辟新块
            q1.push({i, i, a[i]});
        } else {
            // 如果类型相同，延长上一个块的终点
            q1.back().end = i;
        }
    }

    // 辅助数组，用来标记哪些水果已经被拿走了
    vector<bool> vis(n + 1, false);

    // 2. 循环模拟每一轮拿水果的过程
    while (!q1.empty()) {
        queue<Block> q2; // 存储下一轮合并后的新块

        // 每一轮中，依次从各个块的头部拿走一个水果
        while (!q1.empty()) {
            Block cur = q1.front();
            q1.pop();

            // 找到当前块中第一个还没被拿走的水果
            while (cur.start <= cur.end && vis[cur.start]) {
                cur.start++;
            }

            // 如果这个块还没被拿完
            if (cur.start <= cur.end) {
                // 拿走队头的水果，输出其原始编号
                cout << cur.start << " ";
                vis[cur.start] = true; // 标记为已拿走
                cur.start++;           // 块的起点向后移

                // 移出当前水果后，如果该块依然有剩余水果，需要放入下一轮重新组合
                while (cur.start <= cur.end && vis[cur.start]) {
                    cur.start++;
                }
                
                if (cur.start <= cur.end) {
                    // 尝试与 q2 尾部的块进行合并
                    if (!q2.empty() && q2.back().type == cur.type) {
                        q2.back().end = cur.end; // 类型相同，直接将当前块拼接到前一块末尾
                    } else {
                        q2.push(cur); // 类型不同，作为独立的块入队
                    }
                }
            }
        }
        cout << "\n";      // 一轮结束，换行
        q1 = move(q2);     // 将下一轮的块转移到 q1 中继续迭代
    }

    return 0;
}
~~~
