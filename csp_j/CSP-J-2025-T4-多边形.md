# CSP-J 2025 T4 多边形 (polygon) 题解

## 题目概述

给定 $n$ 根小木棍，第 $i$ 根小木棍的长度为 $a_i$。要求从这 $n$ 根木棍中任意选出若干根（至少 3 根），使其能够拼接成一个非退化的多边形。问有多少种不同的选择方案？答案对 $998244353$ 取模。

### 数据范围
- $n \le 5000$
- $a_i \le 5000$

---

## 题目分析

### 1. 多边形构成条件
若干根木棍能拼成一个非退化多边形，当且仅当满足以下两个条件：
1. 木棍数量 $\ge 3$。
2. 所有选出木棍的**长度之和**严格大于**最长木棍长度的 $2$ 倍**：
   $$\sum_{i \in S} a_i > 2 \cdot \max_{i \in S} \{a_i\}$$

即除最长边外，其余木棍的长度之和必须严格大于最长边的长度：
$$\sum_{i \in S \setminus \{\text{max}\}} a_i > \max_{i \in S} \{a_i\}$$

### 2. 算法设计与转化
首先将所有木棍按长度从小到大进行排序：$a_1 \le a_2 \le \dots \le a_n$。

若我们**固定第 $i$ 根木棍 $a_i$ 为当前选择集合中的最长木棍**：
- 则其余被选中的木棍必须来自于集合 $\{a_1, a_2, \dots, a_{i-1}\}$。
- 设从 $\{a_1, \dots, a_{i-1}\}$ 中选出的木棍长度之和为 $S$，则需满足：
  $$S > a_i$$
- 关键结论：因为 $a_1, \dots, a_{i-1} \le a_i$，若某个子集的和 $S > a_i$，则该子集的大小**必然 $\ge 2$**（元素个数为 $0$ 时和为 $0 \le a_i$；元素个数为 $1$ 时单个元素 $a_j \le a_i$）。因此无需额外记录选取的木棍数量，只需满足 $S > a_i$ 即可天然满足木棍总数 $\ge 3$ 的限制！

### 3. 动态规划 (0/1 背包)

设 $dp[w]$ 表示在前 $i-1$ 根木棍中选出若干根，长度之和恰好为 $w$ 的方案数。

对于当前的 $a_i$：
1. **统计贡献**：在前 $i-1$ 根木棍构成的所有 $2^{i-1}$ 个子集中，和小于等于 $a_i$ 的方案数为 $\sum_{w=0}^{a_i} dp[w]$。
   因此，和严格大于 $a_i$ 的方案数为：
   $$\text{valid\_cnt} = 2^{i-1} - \sum_{w=0}^{a_i} dp[w] \pmod{998244353}$$
   将该贡献累加至最终答案。
2. **转移状态**：将 $a_i$ 加入背包，更新 $dp$ 数组：
   $$dp[w] = (dp[w] + dp[w - a_i]) \bmod 998244353 \quad (w \text{ 从 } V \text{ 倒序枚举至 } a_i)$$

其中 $V = \max_{1 \le i \le n} \{a_i\} \le 5000$。

## C++ 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

static const int MOD = 998244353;

int main() {
    // 提升输入输出效率
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // 文件输入输出（CSP竞赛标准）
    freopen("polygon.in", "r", stdin);
    freopen("polygon.out", "w", stdout);

    int n;
    if (!(cin >> n)) return 0;

    vector<int> a(n);
    int max_val = 0;
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
        max_val = max(max_val, a[i]);
    }

    // 1. 升序排序，确保枚举 a[i] 时它为当前集合的最长边
    sort(a.begin(), a.end());

    // dp[w] 表示前若干个元素中，和为 w 的子集方案数
    vector<int> dp(max_val + 1, 0);
    dp[0] = 1; // 空集的和为 0，方案数为 1

    long long total_ans = 0;
    long long pow2 = 1; // 维护 2^(i-1) % MOD

    for (int i = 0; i < n; ++i) {
        int cur = a[i];

        // 计算在前 i 个元素中，和 <= cur 的方案数之和
        long long sum_le = 0;
        for (int w = 0; w <= cur; ++w) {
            sum_le = (sum_le + dp[w]) % MOD;
        }

        // 和 > cur 的方案数 = 总子集数 2^i - (和 <= cur 的子集数)
        long long valid = (pow2 - sum_le + MOD) % MOD;
        total_ans = (total_ans + valid) % MOD;

        // 更新背包 DP，将 cur 加入候选集合
        for (int w = max_val; w >= cur; --w) {
            dp[w] = (dp[w] + dp[w - cur]) % MOD;
        }

        // 更新 2^i
        pow2 = (pow2 * 2) % MOD;
    }

    cout << total_ans << "\n";

    return 0;
}
```

---

## 复杂度分析

- **时间复杂度**：
  - 数组排序：$\mathcal{O}(n \log n)$
  - 动态规划：外层循环 $n$ 次，内层维护 DP 数组大小为 $V = \max(a_i)$。总计算量约为 $n \times V \approx 5000 \times 5000 = 2.5 \times 10^7$ 次基本运算。
  - **总时间复杂度**：$\mathcal{O}(n \log n + n \cdot V)$，运行时间约 $0.03$ 秒，轻松通过所有测试点。

- **空间复杂度**：
  - DP 数组仅需记录长度到 $V = \max(a_i) \le 5000$，空间开销仅为几个 $KB$。
  - **总空间复杂度**：$\mathcal{O}(n + V)$，极大地节省了内存空间。
