## 一、 原代码问题分析

给出的代码主要思路是**对每次询问都从目标点出发执行一次 BFS**，试图模拟寻找路径。这种做法在面对本题的数据范围时存在严重的问题：

### 1. 致命缺陷：时间复杂度极高（严重 TLE）
* **原代码做法**：对于 $Q$ 次询问，每次都重新跑一遍 BFS，并且在 BFS 的入队过程中**没有任何访问标记（`vis` 数组）**。
* **数据范围**：$N, M, Q \le 10^5$，$L \le 10^9$。
* **后果**：
  1. 缺乏 `vis` 去重机制会导致队列中的状态呈**指数级爆炸**（在相邻点间无限递归/反复横跳）。
  2. 即便加上 `vis` 限制，对每个询问跑一次 BFS 的总时间复杂度依然高达 $O(Q \times (N + M))$，面对 $10^5$ 级别的数据会直接超时（TLE）。

### 2. 逻辑漏洞：无法处理“重复经过同一节点/边”的情况
* 本题的核心机制是：原材料**可以重复经过同一条边或同一个结点**（即在相邻结点间来回走动消耗步数）。
* 如果 $1$ 号点到点 $a$ 存在一条长度为 $3$ 的路径，那么只要 $L \ge 3$ 且 $(L - 3)$ 是偶数（例如 $L=5, 7, 9\dots$），点 $a$ 就可以在阶段 $L$ 生产零件。
* 原代码只简单匹配步数，忽略了**路径长度的奇偶性**对步数重复利用的关键作用。

---

## 二、 正确解法思路：奇偶最短路

问题的实质是求解：**从 1 号节点出发，到达点 $a$ 的“最短奇数路径”与“最短偶数路径”。**

### 核心结论
若想在第 $L$ 阶段让 $1$ 号点提供原材料给点 $a$：
1. **当 $L$ 为偶数时**：只需 $1$ 号点到点 $a$ 的**最短偶数路径** $\le L$。
2. **当 $L$ 为奇数时**：只需 $1$ 号点到点 $a$ 的**最短奇数路径** $\le L$。

> **原理**：只要目标步数 $L$ 大于等于对应的最短路径且与最短路径的**奇偶性相同**，我们就可以通过在某条邻边上来回走把多余的步数“消耗”掉。

### 算法优化
* **预处理**：仅需**从点 $1$ 出发做一次 BFS**，求出点 $1$ 到所有节点 $i$ 的：
  * 最短偶数路径 `dis[i][0]`
  * 最短奇数路径 `dis[i][1]`
* **复杂度**：
  * **预处理时间复杂度**：$O(N + M)$
  * **单次查询时间复杂度**：$O(1)$
  * **总体时间复杂度**：$O(N + M + Q)$，可以完美通过所有测试点。


## 三、 C++ 规范代码实现
```cpp
#include <bits/stdc++.h>
using namespace std;
// N 和 M 最大为 100000，数组大小开到 100005 即可
const int MAXN = 100005;

// 邻接表存图，mp[u] 保存与点 u 相连的所有邻居节点
vector<int> mp[MAXN];

// 核心状态数组：奇偶最短路
// dis[u][0]: 从 1 号点出发到达 u 号点的【最短偶数路径长度】
// dis[u][1]: 从 1 号点出发到达 u 号点的【最短奇数路径长度】
int dis[MAXN][2]; 

// 定义结构体用于 BFS 队列传递状态（替代 std::pair）
struct Node {
    int u; // 当前所在的节点编号
    int d; // 从 1 号点到达当前节点 u 的路径长度
};

void bfs() {
    // 将 dis 数组中的所有元素初始化为极大值 0x3f3f3f3f (INF)，表示初始时均不可达
    memset(dis, 0x3f, sizeof(dis));
    queue<Node> q;
    // 起点初始化：从 1 号点出发，到达 1 号点本身的初始路径长度为 0（偶数）
    dis[1][0] = 0;
    q.push({1, 0});

    while (!q.empty()) {
        Node now = q.front();
        q.pop();
        int u = now.u;
        int d = now.d;
        // 遍历当前节点 u 的所有邻居节点 v
        for (int v : mp[u]) {
            int next_d = d + 1;      // 到达下一个节点的路径长度
            int parity = next_d % 2; // 计算新路径长度的奇偶性（0 为偶，1 为奇）
            
            // 剪枝与松弛操作：
            // 如果发现了到达节点 v 的更短的【奇数/偶数】路径，则更新并入队
            if (dis[v][parity] > next_d) {
                dis[v][parity] = next_d;
                q.push({v, next_d});
            }
        }
    }
}

int main() {
    // 优化标准 C++ 输入输出流，提高解题代码的运行效率
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, q;
    cin >> n >> m >> q;

    // 读取 m 条无向边建立无向图
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        mp[u].push_back(v);
        mp[v].push_back(u);
    }

    // 预处理：从 1 号点跑一次奇偶最短路，求出到达每个点的奇偶最短路径
    bfs();

    // 预处理完成后，$O(1)$ 回答每次询问
    while (q--) {
        int a, l;
        cin >> a >> l;
        int parity = l % 2; // 判断询问阶段 L 的奇偶性
        // 核心原理判断：
        // 只要 1 号点到达点 a 且【奇偶性一致】的最短路径存在，并且【最短路径长度 <= L】，
        // 原材料就能通过在邻近节点间“来回消耗步数”刚好在第 L 阶段到达点 a。
        if (dis[a][parity] <= l) {
            cout << "Yes\n";
        } else {
            cout << "No\n";
        }
    }
    return 0;
}
```
## 四、 关键细节说明
### 1. **状态拆分**：
将图上的点拆分为“到达该点时路径长度为奇数”和“路径长度为偶数”两种状态，即 `dis[u][0]` 和 `dis[u][1]`。

### 2. **初始状态**：
`dis[1][0] = 0`，其余全部初始化为 `INF`。注意 $1$ 号点的奇数最短路径初始也是 `INF`，若 $1$ 号点有邻居 $v$，则经过 $1 \to v$ 后，会更新出 `dis[v][1] = 1`，再回到 $1$ 时更新出 `dis[1][0] = 2` 等。
