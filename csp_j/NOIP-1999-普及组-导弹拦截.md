# NOIP 普及组 导弹拦截（经典双题：P1020）

## 题目简述（NOIP1999 普及组）
某国发明一种导弹拦截系统。这套系统第一发能打到任意高度导弹，之后每一发导弹高度不能超过前一发（非上升序列）。

现在依次飞来若干枚导弹，给出每枚导弹高度。

问题 1：一套系统最多拦截多少枚导弹？

问题 2：至少需要多少套系统才能拦截全部导弹？

输入样例：
389 207 155 300 299 170 158 65
输出：
6
2

## 数学转化（核心定理：Dilworth 定理）
设序列 $a_1,a_2\dots a_n$

最多拦截导弹数量 = 最长不上升子序列长度（LNIS）

最少系统数量 = 最长上升子序列长度（LIS）

样例验证：

序列：389,207,155,300,299,170,158,65

最长不上升子序列：389,300,299,170,158,65 → 长度 6

最长上升子序列：155,300 → 长度 2，和样例输出一致。

## 两种写法

### 写法 1：

O (n²) DP（普及组入门，好理解）

定义：

$f[i]$：以第 i 枚导弹结尾的最长不上升子序列长度

$f[i]=\max_{j<i,a_j\ge a_i}\{f[j]\}+1$

$g[i]$：以第 i 枚导弹结尾的最长上升子序列长度

$g[i]=\max_{j<i,a_j< a_i}\{g[j]\}+1$

~~~cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int N = 1005;
int a[N], f[N], g[N];
int n;

int main()
{
    n = 0;
    while (cin >> a[++n]);
    n--;

    int ans1 = 0, ans2 = 0;
    for (int i = 1; i <= n; i++)
    {
        f[i] = 1;
        g[i] = 1;
        for (int j = 1; j < i; j++)
        {
            if (a[j] >= a[i])
                f[i] = max(f[i], f[j] + 1);
            if (a[j] < a[i])
                g[i] = max(g[i], g[j] + 1);
        }
        ans1 = max(ans1, f[i]);
        ans2 = max(ans2, g[i]);
    }
    cout << ans1 << endl << ans2 << endl;
    return 0;
}
~~~

### 写法 2：
O (n log n) 贪心 + 二分（大数据版本，P1020 标准满分写法）
原理：维护序列末尾数组，二分查找优化

求最长不上升子序列：二分找第一个小于当前数，替换

求最长上升子序列：二分找第一个大于等于当前数，替换

~~~cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

vector<int> a, up, down;
int x;

int main()
{
    while (cin >> x) a.push_back(x);
    for (int h : a)
    {
        // 最长不上升子序列
        auto it = upper_bound(down.begin(), down.end(), h, greater<int>());
        if (it == down.end()) down.push_back(h);
        else *it = h;

        // 最长上升子序列
        it = lower_bound(up.begin(), up.end(), h);
        if (it == up.end()) up.push_back(h);
        else *it = h;
    }
    cout << down.size() << "\n" << up.size() << endl;
    return 0;
}
~~~

## ⚠️ 二分边界极易写错：

不上升序列：upper_bound(..., greater<int>())

严格上升序列：lower_bound

### 常见易错点

混淆上升 / 不上升、严格 / 非严格，二分函数选错直接 WA

Dilworth 定理适用条件一定要理解：

将导弹划分成最少个不上升子序列 ⇔ 最长上升子序列长度

O (n²) DP 只能过 n≤1000；
原题数据范围扩大后必须用 nlogn 二分贪心
