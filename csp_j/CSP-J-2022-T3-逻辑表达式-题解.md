
# CSP-J 2022 普及组 T3：逻辑表达式 (expr)

## 题目描述
逻辑表达式是计算机科学中的重要概念和工具，包含逻辑值、逻辑运算、逻辑运算优先级等内容。

在一个逻辑表达式中，元素的值只有 $0$ 和 $1$ 两种，可能出现的逻辑运算符有 `&`、`|` 和括号 `()`。其中 `&` 的优先级高于 `|`。二者的结合性均为从左到右。

这两种运算符的运算规则如下：
- `&` 运算：如果两边均为 $1$，结果为 $1$；否则为 $0$。
- `|` 运算：如果两边至少有一个 $1$，结果为 $1$；否则为 $0$。

由于计算机运算逻辑表达式时往往采用“短路”运算，所以可能会对这两种运算符进行短路操作：
- 对于 `a & b`，如果 `a = 0`，则发生一次短路，不对 `b` 进行运算。
- 对于 `a | b`，如果 `a = 1`，则发生一次短路，不对 `b` 进行运算。

给定一个逻辑表达式，请计算出它的结果，以及在运算中 `&` 和 `|` 分别发生了多少次短路。

## 输入格式
输入仅包含一行，表示给定的逻辑表达式。表达式中只包含字符 `0`, `1`, `&`, `|`, `(`, `)`。

## 输出格式
输出两行。
第一行包含一个字符，表示表达式最终的结果（$0$ 或 $1$）。
第二行包含两个空格隔开的非负整数，分别表示运算过程中 `&` 和 `|` 发生的短路次数。

## 样例说明
### 样例输入 1
```text
0&(1|0)|(1|1|1&0)
```

### 样例输出 1
```text
1
1 2
```

### 样例解释
该逻辑表达式的计算过程如下：
- 整个表达式由 `|` 连接两个部分，首先计算左侧的 `0&(1|0)`。
- 在计算 `0&(1|0)` 时，遇到 `0&`，左侧结果为 $0$，发生一次 `&` 短路，后面的 `(1|0)` 不被计算，该部分结果为 $0$。
- 继续计算右侧 `(1|1|1&0)`，先计算括号内表达式。
- 括号内表达式可视为 `((1|1)|(1&0))`（左结合性），先计算 `1|1` 发生一次 `|` 短路返回 $1$；再计算 `1|(1&0)` 再次发生一次 `|` 短路返回 $1$。因此产生 $2$ 次 `|` 短路，括号内结果为 $1$。
- 最终外层计算为 `0|1`，结果为 $1$。
- 整个过程中共发生了 $1$ 次 `&` 短路和 $2$ 次 `|` 短路。

## 数据范围
- 对于 $20\%$ 的数据，表达式中不含括号。
- 对于 $50\%$ 的数据，表达式的长度不超过 $10^4$。
- 对于 $100\%$ 的数据，表达式的长度不超过 $10^6$。保证给定的逻辑表达式合法。

## 题目分析与解题思路
本题的核心难点在于**运算优先级**和**短路计算特性的精准模拟**。由于包含括号且可能存在深层嵌套，我们推荐使用**递归下降解析（Recursive Descent Parsing）**。

为了正确统计短路次数，可以给解析函数传入一个参数 `eval`，表示**当前子表达式是否需要进行真实计算**。
如果前面的运算触发了短路（比如遇到 `0 & ...` 或者 `1 | ...`），我们在向后递归解析时就传入 `eval = false`。这样程序依然可以正常消耗掉相应的字符串结构（跳过短路部分），但不会去累加其内部产生的短路次数。

基于优先级我们定义三个解析函数：
1. `expr(eval)`：解析 `|` 运算（优先级最低）。它由一个或多个 `term` 组成。
2. `term(eval)`：解析 `&` 运算（优先级较高）。它由一个或多个 `factor` 组成。
3. `factor(eval)`：解析括号 `(...)` 内的 `expr` 或基础的数值 `0`, `1`（优先级最高）。

这种写法能天然契合运算符的优先级与从左往右的结合性，每个字符被遍历常数次，总时间复杂度为 $O(N)$，空间复杂度取决于递归调用栈深度 $O(N)$，足以顺利通过所有测试点。

## C++ 参考代码
```cpp
#include <iostream>
#include <string>

using namespace std;

string s;
int pos_idx = 0;
int cnt_and = 0, cnt_or = 0;

// 提前声明三个层次的解析函数
int expr(bool eval);
int term(bool eval);
int factor(bool eval);

// 解析由 '|' 连接的表达式项
int expr(bool eval) {
    int val = term(eval);
    while (pos_idx < (int)s.length() && s[pos_idx] == '|') {
        pos_idx++;
        if (val == 1) {
            // 左边为1，发生 '|' 短路
            if (eval) cnt_or++;
            term(false); // 丢弃后半部分的计算，跳过字符串
            val = 1;
        } else {
            // 左边为0，需继续计算右边
            int nxt = term(eval);
            val = val | nxt;
        }
    }
    return val;
}

// 解析由 '&' 连接的表达式项
int term(bool eval) {
    int val = factor(eval);
    while (pos_idx < (int)s.length() && s[pos_idx] == '&') {
        pos_idx++;
        if (val == 0) {
            // 左边为0，发生 '&' 短路
            if (eval) cnt_and++;
            factor(false); // 丢弃后半部分的计算，跳过字符串
            val = 0;
        } else {
            // 左边为1，需继续计算右边
            int nxt = factor(eval);
            val = val & nxt;
        }
    }
    return val;
}

// 解析括号内部表达式或单个操作数
int factor(bool eval) {
    if (pos_idx < (int)s.length() && s[pos_idx] == '(') {
        pos_idx++; // 消耗 '('
        int val = expr(eval);
        pos_idx++; // 消耗 ')'
        return val;
    } else {
        int val = s[pos_idx] - '0';
        pos_idx++;
        return val;
    }
}

int main() {
    // 优化输入输出
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    if (cin >> s) {
        int ans = expr(true);
        cout << ans << "\n";
        cout << cnt_and << " " << cnt_or << "\n";
    }
    
    return 0;
}
```
