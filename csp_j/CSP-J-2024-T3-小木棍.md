# 2024 CSP-J T3 小木棍 (Sticks) 

## 解题思路

为了拼出的数字尽可能小，我们需要满足两个条件：
1. **位数尽可能少**：拼出一个数字最少需要 2 根火柴（数字 `1`），最多 7 根（数字 `8`）。为了使总位数最少，我们应尽可能多用 `8`。对于给定的 $n$，其最小位数一定是 $\lceil \frac{n}{7} \rceil$，即 `(n + 6) / 7`。
2. **高位数字尽可能小**：在确定了总位数后，从最高位开始，采用贪心策略，从小到大（最高位从 1 开始，其他位从 0 开始）枚举数字 `0-9`。若选择某个数字后，剩余的火柴数刚好足够拼满剩下的位数，则该数字就是当前位的最优解。

## C++ 源码

```cpp
#include <iostream>
#include <string>

using namespace std;

// 0-9 每个数字需要的火柴棍数量
const int cost[10] = {6, 2, 5, 5, 4, 5, 6, 3, 7, 6};

void solve() {
    int n;
    cin >> n;
    
    // 如果火柴数量小于等于 1，无法拼成任何数字
    if (n <= 1) {
        cout << -1 << "\n";
        return;
    }
    
    // 计算结果数字的总长度 (相当于 ceil(n / 7.0))
    int len = (n + 6) / 7;
    string ans = "";
    
    // 贪心确定每一位的数字
    for (int i = 1; i <= len; ++i) {
        // 最高位不能为 0，所以第一位从 1 开始枚举，其余从 0 开始
        for (int d = (i == 1 ? 1 : 0); d <= 9; ++d) {
            int rem = n - cost[d];
            
            // 判断剩余的火柴数是否能刚好填满剩下的 (len - i) 个位置
            // 每个位置最少需要 2 根火柴，最多需要 7 根火柴
            if (rem >= 2 * (len - i) && rem <= 7 * (len - i)) {
                ans += to_string(d);
                n = rem;     // 更新剩余火柴数
                break;       // 找到满足条件的最小数字即跳出枚举，处理下一位
            }
        }
    }
    
    cout << ans << "\n";
}

int main() {
    // 优化 I/O 速度
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    int t;
    if (cin >> t) {
        while (t--) {
            solve();
        }
    }
    
    return 0;
}
```
