# C++ 实现八皇后问题 (Eight Queens Puzzle)

八皇后问题是一个以国际象棋为背景的问题：如何能够在 8×8 的国际象棋棋盘上放置八个皇后，使得任何一个皇后都无法直接吃掉其他的皇后？为了达到此目的，任两个皇后都不能处于同一条横行、纵行或斜线上。

## 算法思路
解决八皇后问题最常见的方法是**回溯法（Backtracking）**。
我们从第一行开始，尝试在每一列放置一个皇后。如果在某一个位置放置皇后后，它不与之前放置的任何皇后冲突（即不在同一列，也不在两条对角线上），我们就继续递归地到下一行放置皇后。如果某一行无法找到合法的位置，我们就回溯到上一行，改变前一个皇后的位置。

## C++ 代码实现

```cpp
#include <iostream>
#include <vector>
#include <string>

using namespace std;

class Solution {
public:
    // 主函数，返回所有可能的棋盘布局
    vector<vector<string>> solveNQueens(int n) {
        vector<vector<string>> res;
        vector<string> board(n, string(n, '.'));
        backtrack(res, board, 0, n);
        return res;
    }

private:
    // 回溯函数
    void backtrack(vector<vector<string>>& res, vector<string>& board, int row, int n) {
        // 如果成功放置了 n 个皇后，记录当前棋盘
        if (row == n) {
            res.push_back(board);
            return;
        }
        // 遍历当前行的每一列
        for (int col = 0; col < n; ++col) {
            if (isValid(board, row, col, n)) {
                board[row][col] = 'Q'; // 放置皇后
                backtrack(res, board, row + 1, n); // 递归放置下一行
                board[row][col] = '.'; // 回溯，撤销选择
            }
        }
    }

    // 检查在 (row, col) 放置皇后是否合法
    bool isValid(const vector<string>& board, int row, int col, int n) {
        // 检查同一列是否有皇后
        for (int i = 0; i < row; ++i) {
            if (board[i][col] == 'Q') return false;
        }
        // 检查左上对角线是否有皇后
        for (int i = row - 1, j = col - 1; i >= 0 && j >= 0; --i, --j) {
            if (board[i][j] == 'Q') return false;
        }
        // 检查右上对角线是否有皇后
        for (int i = row - 1, j = col + 1; i >= 0 && j < n; --i, ++j) {
            if (board[i][j] == 'Q') return false;
        }
        // 注：不需要检查同一行，因为我们每次递归都进入新的一行
        return true;
    }
};

int main() {
    Solution sol;
    int n = 8; // 8皇后
    vector<vector<string>> results = sol.solveNQueens(n);
    
    cout << "8皇后问题总共有 " << results.size() << " 种解法。" << endl << endl;
    
    // 打印前三种解法作为示例展示
    for (int i = 0; i < min(3, (int)results.size()); ++i) {
        cout << "解法 " << i + 1 << ":" << endl;
        for (const string& row : results[i]) {
            cout << row << endl;
        }
        cout << endl;
    }
    
    return 0;
}
```

## 代码解析
1. **`solveNQueens`**: 初始化一个大小为 $N \times N$ 的空棋盘（用 `.` 表示空，`Q` 表示皇后），并开始回溯。
2. **`backtrack`**: 核心逻辑。如果当前行号 `row == n`，说明 8 个皇后都已成功放置，将结果保存。否则，尝试在当前行的每一列放置皇后。
3. **`isValid`**: 用于验证放置位置是否合法。由于我们是从上往下按行放置皇后，所以只需检查正上方、左上方和右上方是否有皇后即可。不需要检查同行或下方。
